> 对应《计算机程序设计艺术》第 2 卷《半数值算法》第三版中文译本，§4.3，书内第 239-289 页，包含经典算法、模算术和快速乘法。第 289 页同时开始 §4.4。

一个整数超过机器字长以后，并不需要立刻变成近似值。可以把它分成许多块，逐块执行准确的算术。

困难在于：中间值需要多宽，进位何时传递，除法的估计何时必须修正？这些问题解决之后，才轮到“能否比小学乘法更快”。

## 1. 多个机器字，也是一种进制表示

选定基数 $B\ge2$，把非负整数写成

```math
U=\sum_{i=0}^{m-1}u_iB^i,\qquad 0\le u_i\lt B.
```

一个 $u_i$ 可以是一整个机器字，也可以只占字的一部分。本文把这样的数字块称为“块”。数组采用低位在前，便于进位从索引 0 向后传播。

固定基数以后，需要保持三个约定：每个块在合法范围内，最高位不保留多余零，零使用统一表示。符号可以另存；下面的主要推导都针对非负整数。

选择 $B$ 时不能只问一个块能否装下。乘法还需要装下两个块的乘积，以及已有结果和进位的和。

## 2. 加法和乘法的边界可以直接证明

加法每一步计算

$$
t=u_i+v_i+c,
\qquad w_i=t\bmod B,
\qquad c=\lfloor t/B\rfloor.
$$

若输入数字合法且 $`c\in\{0,1\}`$，则 $0\le t\le2B-1$，所以新的进位仍然只有 0 或 1。减法也应建立对应的借位不变量，而不是凭几组算例判断。

经典乘法把各项 $u_iv_jB^{i+j}$ 累加到结果。一个内循环步骤可以写成

```math
t=u_iv_j+w_{i+j}+c,
\qquad (c,w_{i+j})=\mathop{\mathrm{divmod}}\nolimits(t,B).
```

只要进入这一步时 $0\le c<B$，就有

$$
t\le(B-1)^2+(B-1)+(B-1)=B^2-1.
$$

因此中间值需要容纳两个块，新的进位仍小于 $B$。这个界既支持正确性证明，也指导机器字宽的选择。

两个分别有 $m,n$ 块的数，经典乘法要进行 $mn$ 次块乘法，工作量为 $\Theta(mn)$。这里计数的是固定宽度块操作；如果每个块本身越来越长，就必须重新计算代价。

## 3. 除法最难的地方是估商

长除法的每一步，把旧余数乘以 $B$，再接入被除数的下一块。若旧余数小于除数 $V$，新的部分被除数 $U$ 就满足 $U<BV$，因此下一块商在 $0$ 到 $B-1$ 之间。

用除数的最高位和部分被除数的最高两位，可以先得到一个试商。以十进制的 $176\div59$ 为例，只看 $17\div5$ 会估出 3，但

$$
3\cdot59=177>176.
$$

必须把试商减为 2，余数才是合法的 58。

原书算法 D 的核心是给这种估计建立误差界。把被除数和除数一起乘以合适的正规化因子，使除数首位足够大之后，最高位估计最多只比真实商大 2；再利用下一位筛选，缩小可能的误差。乘减后若仍出现负余数，就把商再减一，并把除数加回。

“很少需要加回”不能成为删掉这个分支的理由。实现的正确性必须包含那些少见输入。正规化结束后，还要把余数除以正规化因子恢复原尺度。

检验任何整数除法程序，都应同时核对

```math
U=QV+R,\qquad 0\le R\lt V.
```

只检查第一个等式不够：错误的商仍可能配出一个错误范围的余数。

## 4. 模表示把一次大运算分散到多个小模数

另一条路线，是选取两两互素的模数 $m_1,\ldots,m_k$，用余数向量表示整数：

$$
(U\bmod m_1,\ldots,U\bmod m_k).
$$

加、减、乘都可逐分量计算。每个分量独立，不需要像定位表示那样跨块传递进位。

但这些余数只确定模

$$
M=\prod_{i=1}^k m_i
$$

的剩余类。若已知 $0\le U<M$，才能唯一恢复这个整数；若可能超出范围，还需要更大的模数乘积或额外的范围信息。

令 $M_i=M/m_i$，选取 $t_i$ 使 $M_it_i\equiv1\pmod{m_i}$，则

$$
U\equiv\sum_i r_iM_it_i\pmod M.
$$

每一项在本分量上提供所需余数，在其他分量上为零，因此这条恢复式可以逐模验证。唯一性来自：两个解之差被所有互素模数整除，也就被它们的乘积整除。

例如模数 5、7、11 的乘积为 385，余数向量 $(3,5,8)$ 在 $[0,385)$ 内对应 173。它也对应 558 等其他整数，所以恢复范围必须与数据一起说明。

模表示的代价在比较大小、检测范围和除法时显现。各分量都小，不代表原数小；模逆元也不是普通整数除法。来回转换的开销必须计入整个任务。

## 5. 三次乘法为什么能代替四次

把整数各拆成两半：

$$
U=Aq+B,\qquad V=Cq+D,
$$

其中 $q$ 是合适的基数幂。直接展开需要 $AC,AD,BC,BD$ 四个乘积，但交叉项满足

$$
AD+BC=(A+B)(C+D)-AC-BD.
$$

所以只需计算三个乘积，再组合为

$$
UV=ACq^2+\bigl((A+B)(C+D)-AC-BD\bigr)q+BD.
$$

递归使用这个办法，就得到 Karatsuba 方法的基本结构。把加法、移位和进位的线性代价算进去，递推约为

$$
T(n)=3T(n/2)+O(n),
$$

因而得到 $O(n^{\log_2 3})$ 的量级，指数约为 1.585。和式可能比原来的半段多一位，实现时需要为它留空间；这个小变化不改变渐近量级。

原书继续研究更细的分块、求值与插值，以及模方法和傅里叶变换。共同思想是把数字看成多项式系数，把乘法改写成卷积，再寻找更便宜的计算方式。

不能只看到卷积计算完毕：最终还要恢复准确系数并传播进位。若使用近似算术完成变换，还必须保证误差不会使整数系数恢复错误。渐近上更快的算法，也不保证在每个输入长度上都更快。

## 6. Python：明确实现块运算，再用大整数交叉检查

下面实现经典乘法、单块除法和中国剩余恢复。单块除法是长除法的基础特例，**不是算法 D 的完整实现**。数组均为低位在前，除数要求 $1\le d<B$。

```python
from math import prod


def trim(a):
    while len(a) > 1 and a[-1] == 0:
        a.pop()
    return a


def split(n, base=1000):
    if n < 0 or base < 2:
        raise ValueError("invalid number or base")
    a = []
    while n:
        n, r = divmod(n, base)
        a.append(r)
    return a or [0]


def join(a, base=1000):
    value = 0
    for digit in reversed(a):
        value = value * base + digit
    return value


def multiply(u, v, base=1000):
    w = [0] * (len(u) + len(v))
    for i, ui in enumerate(u):
        carry = 0
        for j, vj in enumerate(v):
            t = ui * vj + w[i + j] + carry
            assert 0 <= t < base * base
            carry, w[i + j] = divmod(t, base)
        w[i + len(v)] = carry
    return trim(w)


def divide_digit(u, d, base=1000):
    if not 1 <= d < base:
        raise ValueError("divisor must fit one digit")
    q = [0] * len(u)
    r = 0
    for i in range(len(u) - 1, -1, -1):
        q[i], r = divmod(r * base + u[i], d)
    return trim(q), r


def restore(residues, moduli):
    if len(residues) != len(moduli) or not moduli:
        raise ValueError("invalid residue vector")
    # The moduli must be >= 2 and pairwise coprime.
    modulus = prod(moduli)
    total = 0
    for r, m in zip(residues, moduli):
        part = modulus // m
        total += r * part * pow(part, -1, m)
    return total % modulus


u, v = 100023, 40007
answer = join(multiply(split(u), split(v)))
assert answer == u * v
quotient, remainder = divide_digit(split(u), 97)
assert (join(quotient), remainder) == divmod(u, 97)
print(answer)
print(join(quotient), remainder)
print(restore([3, 5, 8], [5, 7, 11]))
```

输出：

```text
4001620161
1031 16
173
```

乘法内循环只把块相乘；完整大整数乘法用于程序末尾的独立核对。单块除法中的中间值也有上界：旧余数 $r<d<B$，所以 $rB+u_i<B^2$。

更完整的测试应包括零、全为最大数字的输入、长度悬殊的乘数、长串进位，以及除法刚好整除和余数接近除数的情况。

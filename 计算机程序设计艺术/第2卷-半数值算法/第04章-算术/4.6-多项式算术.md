# 【计算机程序设计艺术 TAOCP】卷2·4.6 多项式算术：除法、因子分解与求值怎样连起来

把整数的数位换成系数，看起来就得到了多项式。这个类比能帮助理解加法与卷积乘法，却不能直接照搬所有整数算法：多项式没有数位进位，系数所在的代数系统还会决定“除得动吗”。

本文对应《计算机程序设计艺术》第 2 卷第 3 版 **4.6 多项式算术，书页 380-480**，按 4.6.1 多项式除法、4.6.2 因子分解、4.6.3 求幂值和 4.6.4 多项式求值展开。原节内容很长，本文选择能相互连接的主要算法，并用有理数系数验证。

## 1. 一串系数之外，还必须说明系数属于哪里

用从低次到高次的数组表示

$$
P(x)=a_0+a_1x+\cdots+a_nx^n.
$$

例如 $2-3x+x^2$ 对应 `[2, -3, 1]`。加法逐项进行；乘法是卷积：

```math
[x^k](PQ)=\sum_{i+j=k}a_i b_j.
```

这里没有进位。系数可能是整数、有理数，也可能是模素数 $p$ 的剩余类。

| 系数系统 | 非零系数一定能做除法吗 | 一个需要留意的例子 |
| --- | --- | --- |
| 有理数域 $\mathbb Q$ | 能 | $1/2$ 是合法系数 |
| 整数环 $\mathbb Z$ | 不能 | $1/2$ 不再是整数 |
| 有限域 $\mathbb F_p$，$`p`$ 为素数 | 能 | 除法通过模逆实现 |
| 模合数的剩余类环 | 不能保证 | 模 $6$ 的 $2$ 没有乘法逆元 |

另外，数组末尾的零必须去掉，否则 `[1, 2, 0]` 会被误判为二次多项式。本文将零多项式规范为 `[0]`，对它单独处理，不用数组长度冒充其数学次数。

## 2. 多项式长除法：每轮准确消去最高次项

在域上，对 $B\ne0$，存在唯一的 $Q,R$ 满足

$$
A=BQ+R,\qquad R=0\ \text{或}\ \deg R<\deg B.
$$

若当前余式的最高项为 $r_mx^m$，除式最高项为 $b_nx^n$，就从商中取出

$$
\frac{r_m}{b_n}x^{m-n},
$$

并从余式减去它乘以 $B$ 的结果。最高项精确消失，次数严格下降，因此循环终止。

例如

$$
x^3-2x+4=(x-1)(x^2+x-1)+3.
$$

为什么商余式唯一？假设两组答案都成立，则

$$
B(Q_1-Q_2)=R_2-R_1.
$$

若 $Q_1-Q_2\ne0$，左边次数至少为 $\deg B$，右边却更小，矛盾。

在整数系数中，问题可能卡在 $r_m/b_n$。例如 $x$ 除以 $2x+1$，在有理数系数下商为 $1/2$、余数为 $-1/2$，但这组结果不属于 $\mathbb Z[x]$。原书进一步讨论伪除法和本原部分等技术，以避免直接引入大量分数。

有了域上的除法，欧几里得算法也就能迁移过来：反复取多项式余式，直到余式为零。最后的非零余式除以首项系数，得到首一 gcd；首一的约定消除了“相差一个非零常数”的不唯一性。

## 3. 因子分解：先找重因子，再看系数域

多项式 gcd 不等于完整因子分解，但它能处理一个重要入口：重因子。

若 $P=H^2K$，则

$$
P'=2HH'K+H^2K'
$$

也被 $H$ 整除。所以可以从 $\gcd(P,P')$ 入手分离重复因子。在有理数域上，非零多项式无平方因子当且仅当这个 gcd 是常数。

有限域中还要额外检查导数是否整个变成零。例如在 $\mathbb F_p$ 上，

$$
(x^p+1)'=0,\qquad x^p+1=(x+1)^p.
$$

这不是“没有重复因子”，而是特征 $p$ 使指数系数消失了。原书专门把这种情况单独处理。

对首一、无平方因子的 $P\in\mathbb F_p[x]$，Berlekamp 方法寻找满足

$$
V^p\equiv V\pmod P
$$

的低次多项式 $V$。在 $\mathbb F_p$ 上，映射 $V\mapsto V^p$ 对系数向量是线性的，因此可以用线性代数求解这个条件。再计算

$$
\gcd(P,V-s),\qquad s\in\mathbb F_p,
$$

就有机会把不同的不可约因子分开。这里又出现了“用 gcd 提取隐藏结构”的思路。

一定要记住因子分解依赖系数域。例如 $x^2+1$ 在 $\mathbb Q[x]$ 中不可约；在 $\mathbb F_2[x]$ 中却等于 $(x+1)^2$。不能把一次模 $p$ 的分解原样当成整数多项式的分解结果。

整数多项式还可以先提取所有系数的最大公因子，留下本原部分。例如 $6x^2+9x+3=3(2x^2+3x+1)$。这一步把系数的共同整数因子与多项式结构分开，也有助于控制后续中间结果。

## 4. 求幂值：二进制方法很有效，但未必乘法最少

计算 $x^{16}$ 不必连乘十五次，只需

$$
x\longrightarrow x^2\longrightarrow x^4\longrightarrow x^8\longrightarrow x^{16}.
$$

从左到右读取正整数 $n$ 的二进制位：最高位对应初值 $x$；每读一位先平方，若该位为 $1$，再乘一次 $x$。

若 $n$ 的位长为 $L$，二进制中有 $w$ 个 $1$，这个版本恰好使用

$$
(L-1)+(w-1)=L+w-2
$$

次乘法。$`n=1`$ 时为零次；$`n=0`$ 单独返回乘法单位元。

但二进制方案不是每个指数的最短方案。对 $n=15$，二进制法需要六次乘法，而加法链

$$
1,2,3,5,10,15
$$

只需要五次：每个新指数都由前面两个指数相加得到，对应把已经算出的两个幂相乘。

乘法次数也不是全部运行时间。大整数、矩阵和多项式的乘法成本不同；保存中间幂还会消耗内存。原书讨论这些方法时，先明确计算模型，才能有意义地比较“更少”。

## 5. Horner 法，把求值写成一个短递推

将多项式改写为

$$
P(x)=((a_nx+a_{n-1})x+\cdots)x+a_0.
$$

从 $a_n$ 开始，对每个剩余系数执行一次乘法和一次加法，总共 $`n`$ 次乘法、$`n`$ 次加法。它不必分别生成每个幂。

长除法还有一个直接联系：

$$
P(x)=(x-c)Q(x)+P(c).
$$

用 $x-c$ 做综合除法时，最后的余数就是 $P(c)$，递推结构与 Horner 求值相同。

同一遍遍历还能得到导数。若已有的高次部分记为 $H$，加入一个系数后变成 $xH+a$，则

$$
(xH+a)'=H+xH'.
$$

因此在点 $c$ 上同时更新

$$
d\leftarrow cd+v,\qquad v\leftarrow cv+a.
$$

第一式必须使用旧的 $v$。顺序写反，就会把新值误代进导数递推。Python 的元组赋值可以清楚地保留这个语义。

Horner 法在精确算术下给出代数上完全相同的结果；换成浮点数后，舍入与问题条件数仍需要另外分析。代数变形减少操作数，并不自动保证所有输入上的数值误差都最小。

## 6. Python：让除法恒等式和求值相互核验

下面以 `Fraction` 保存系数，避免浮点残差让“最高项已消去”的判断变得含糊。代码实现的是有理数域上的除法、首一 gcd、求值与二进制求幂，并非完整因子分解系统。

```python
from fractions import Fraction as F


def poly(a):
    a = list(map(F, a)) or [F(0)]
    while len(a) > 1 and a[-1] == 0:
        a.pop()
    return a


def divide(a, b):
    r, b = poly(a), poly(b)
    if b == [0]:
        raise ZeroDivisionError("zero polynomial")
    q = [F(0)] * max(1, len(r) - len(b) + 1)
    while r != [0] and len(r) >= len(b):
        k = len(r) - len(b)
        c = r[-1] / b[-1]
        q[k] += c
        for j, bj in enumerate(b):
            r[j + k] -= c * bj
        r = poly(r)
    return poly(q), r


def poly_gcd(a, b):
    a, b = poly(a), poly(b)
    while b != [0]:
        a, b = b, divide(a, b)[1]
    return [c / a[-1] for c in a] if a != [0] else a


def value_and_derivative(a, x):
    a, x = poly(a), F(x)
    v, d = a[-1], F(0)
    for c in reversed(a[:-1]):
        d, v = x * d + v, x * v + c
    return v, d


def power(x, n):
    if n < 0:
        raise ValueError("nonnegative exponent required")
    if n == 0:
        return 1, 0
    result, count = x, 0
    for bit in bin(n)[3:]:
        result *= result
        count += 1
        if bit == "1":
            result *= x
            count += 1
    return result, count


a = [4, -2, 0, 1]  # x**3 - 2*x + 4
q, r = divide(a, [-1, 1])
print(list(map(str, q)), list(map(str, r)))
print(*value_and_derivative(a, 2))
print(list(map(str, poly_gcd([-1, 0, 1], [2, -3, 1]))))
print(*power(2, 15))

for c in range(-4, 5):
    av, _ = value_and_derivative(a, c)
    qv, _ = value_and_derivative(q, c)
    rv, _ = value_and_derivative(r, c)
    assert av == (c - 1) * qv + rv
assert power(7, 0) == (1, 0)
```

输出为：

```text
['-1', '1', '1'] ['3']
8 10
['-1', '1']
32768 6
```

有限个点上的相等可以发现不少实现错误，但一般不能代替系数恒等式的验证。完整测试还应逐项重建 $BQ+R$，检查余式次数，并与直接求幂求和得到的 $P(c)$、$`P'(c)`$ 对照。

## 7. 同一套运算怎样长出不同算法

卷积提供乘法，长除法提供余式，余式提供 gcd；gcd 又用于检查重因子和拆分有限域上的多项式。求幂与求值则关注如何复用已经算过的中间结果。

真正需要守住的边界是系数系统。明确它以后，哪些除法合法、什么叫规范形式、何时次数严格下降，才都有确定答案。后面的幂级数运算会继续使用这些工具，只是关注点从最高次项转到需要保留的低次项。

# 【计算机程序设计艺术 TAOCP】卷2·4.7 幂级数的操作：只算有限项，怎样处理无限表达式

一个幂级数有无限多个系数，计算机却只能保存有限数据。4.7 节的出发点很实用：如果只需要前 $N$ 个系数，就在模 $x^N$ 的意义下运算。后面尚未计算的高次项，不应影响已经确定的低次项。

本文对应《计算机程序设计艺术》第 2 卷第 3 版 **4.7 幂级数的操作，书页 480-491**。从卷积和除法出发，介绍乘方、复合、反演及迭代，再用精确分数实现截断求逆与指数级数。

## 1. 这里的“精度”指保留多少项

设

$$
F(x)=f_0+f_1x+f_2x^2+\cdots.
$$

写成

$$
F(x)\equiv f_0+f_1x+\cdots+f_{N-1}x^{N-1}\pmod{x^N},
$$

表示从常数项到 $x^{N-1}$ 的系数全部确定。它不是说某个实数近似值保留了 $N$ 位有效数字。

形式幂级数关注系数之间的代数关系，不要求先给 $x$ 赋值，也不需要先证明级数在哪个实数区间收敛。例如

$$
\frac1{1-x}=1+x+x^2+\cdots
$$

可以作为形式恒等式理解。若想进一步代入数值求和，就需要另行满足分析意义上的条件。

本文使用有理数系数。更一般的系数环也能做许多操作，但除法、积分和反演所需的可逆性条件必须重新检查。

## 2. 乘法为什么可以随算随截断

若 $H=FG$，则

$$
h_n=\sum_{k=0}^{n}f_kg_{n-k}.
$$

第 $n$ 项只依赖输入的前 $n+1$ 项。次数超过目标的项，不可能再通过普通乘法回到低次项，因此每次乘法后立即丢掉 $x^N$ 及更高项是合法的。

这正是模 $x^N$ 运算的意义。我们是在一个确定的代数系统中计算，并非每一步随意丢掉“小量”。

直接卷积计算前 $N$ 项需要 $O(N^2)$ 次系数运算。采用更快的多项式乘法，才能进一步加快大规模级数计算；只把外层循环换个名字，并不会自动改变这一成本。

## 3. 除法是一条从低次项向前推进的递推

要求 $H=F/G$，先假设 $g_0\ne0$。由 $GH=F$，有

$$
g_0h_n+\sum_{k=1}^{n}g_kh_{n-k}=f_n,
$$

所以

$$
h_n=\frac{f_n-\sum_{k=1}^{n}g_kh_{n-k}}{g_0}.
$$

先算 $h_0=f_0/g_0$，再依次算后续项。每个新系数只需要已经确定的结果，这就是原书所说的在线计算方式。

常数项条件不可省略。在有理数系数中，$G$ 有乘法逆元当且仅当 $g_0\ne0$；在一般环中则需要 $g_0$ 是单位元。例如 $2$ 在有理数中可逆，在整数中却不可逆。

若分母常数项为零，不代表任何商都不存在。例如 $x/x=1$，可以先约去共同的 $x$ 次幂；但 $1/x$ 就不是只含非负整数次幂的普通形式幂级数。

## 4. 牛顿求逆：一次修正为什么能使精度翻倍

设已经找到 $G$，使得

$$
FG\equiv1\pmod{x^m}.
$$

令误差 $E=1-FG$，则 $E$ 被 $x^m$ 整除。取新近似

$$
G_{\mathrm{new}}=G(2-FG).
$$

直接展开得到

$$
1-FG_{\mathrm{new}}=(1-FG)^2=E^2.
$$

因此新误差被 $x^{2m}$ 整除，正确系数从前 $m$ 项增加到前 $2m$ 项。初值只需 $G=1/f_0$，随后按 $1,2,4,8,\ldots$ 的精度扩展，最后一次截到目标 $N$ 即可。

这是形式幂级数中的精度翻倍，不是实数浮点迭代中的“小数越来越接近”。所有低阶系数可以用分数精确保存。

原书在幂级数反演中讨论牛顿方法，习题也引导把它用于倒数。这里选倒数作为最容易直接证明的例子。代码仍使用普通卷积，所以总成本保持在 $O(N^2)$ 量级；快速算法的收益取决于底层乘法。

## 5. 微分方程可以变成系数递推

设 $F(0)=0$，定义 $H=\exp F$ 且 $h_0=1$。由

$$
H'=F'H
$$

比较 $x^{n-1}$ 的系数，得到

$$
nh_n=\sum_{k=1}^{n}k f_kh_{n-k}.
$$

所以每一步除以整数 $n$，就得到新的精确系数。对 $F=x$，这给出 $h_n=1/n!$。

原书对一般乘方也采用类似思路。若 $F(0)=1$，$H=F^a$ 且 $h_0=1$，从

$$
FH'=aF'H
$$

可以推得

$$
nh_n=\sum_{k=1}^{n}\bigl((a+1)k-n\bigr)f_kh_{n-k}.
$$

取 $a=-1$ 得到倒数，取 $a=1/2$ 可以求常数项为 $1$ 的平方根分支。这里在有理数系数下取有理数 $a$，各步除法都有明确含义；不能不加检查地把公式搬到任意有限特征的域，因为某些 $n$ 会变成零。

截断精度在微分时也会改变：只知道 $F\bmod x^N$，一般只能确定 $F'\bmod x^{N-1}$。未知的 $x^N$ 系数会在微分后影响 $x^{N-1}$ 项。

## 6. 复合、乘法逆元与反演是三种不同的操作

对无限形式级数，若内层 $G(0)=0$，则

$$
F(G(x))=\sum_{k\ge0}f_kG(x)^k
$$

的每个系数只会收到有限多项的贡献。因此可以通过有限运算确定前 $N$ 项。若内层常数项不为零，任意高次的外层项都可能影响常数项，一般就不能只凭有限截断进行复合。外层本来就是多项式时，则没有这个无限求和问题。

乘法逆元满足 $FG=1$；幂级数的反演求的是复合逆：

$$
F(G(x))=G(F(x))=x.
$$

在有理数系数中，若 $F(0)=0$ 且一次项系数不为零，就有唯一的常数项为零的复合逆。

例如 $F(t)=t-t^2$，要求 $x=G-G^2$。写成 $G=x+G^2$，逐项比较就得到

$$
G(x)=x+x^2+2x^3+5x^4+14x^5+\cdots.
$$

这里出现的是卡特兰数。也可以用原书讨论的拉格朗日反演表达为

$$
[x^n]G(x)=\frac1n[t^{n-1}](1-t)^{-n}
=\frac1n\binom{2n-2}{n-1},\quad n\ge1.
$$

表达式描述的是复合逆的系数，而不是 $(t-t^2)^{-1}$ 的乘法倒数。把这两个“逆”混淆，后续公式就会完全不同。

## 7. 迭代：反复代入不等于普通乘方

原书还研究把一个级数反复与自身复合。记 $U^{[m]}$ 为复合 $m$ 次，并令 $U^{[0]}(x)=x$，那么

$$
U^{[m+n]}=U^{[m]}\circ U^{[n]}.
$$

一个容易手算的例子是

$$
U(x)=\frac{x}{1-x}.
$$

直接代入可得

$$
U(U(x))=\frac{x}{1-2x},\qquad
U^{[m]}(x)=\frac{x}{1-mx}.
$$

而普通乘方 $U(x)^2=x^2/(1-x)^2$，连最低次项都不同。

更一般时，原书尝试通过变量替换把复合变成较简单的形式，例如寻找 $V$ 使 $V(U(x))=uV(x)$。这会把迭代转换成乘上 $u^m$，但相应方程并非总能解，尤其要检查一次项及单位根等特殊情形。这里不把一个可行例子的规律扩大为任意级数的结论。

## 8. Python：截断乘法、求逆、指数与反演系数

数组的第 $k$ 项表示 $x^k$ 的系数。函数接受的短数组按多项式解释，省略部分视为零；若数据来自未知级数，就必须提供目标精度所需的输入系数。

```python
from fractions import Fraction as F
from math import factorial


def prefix(a, n):
    if n < 0:
        raise ValueError("negative precision")
    return (list(map(F, a)) + [F(0)] * n)[:n]


def multiply(a, b, n):
    a, b = prefix(a, n), prefix(b, n)
    out = [F(0)] * n
    for i, ai in enumerate(a):
        for j in range(n - i):
            out[i + j] += ai * b[j]
    return out


def inverse(a, n):
    if n < 1:
        raise ValueError("positive precision required")
    a = prefix(a, n)
    if a[0] == 0:
        raise ZeroDivisionError("constant coefficient is zero")
    g = [1 / a[0]]
    while len(g) < n:
        size = min(2 * len(g), n)
        correction = [-c for c in multiply(a, g, size)]
        correction[0] += 2
        g = multiply(g, correction, size)
    return g


def exponential(a, n):
    if n < 1:
        raise ValueError("positive precision required")
    a = prefix(a, n)
    if a[0] != 0:
        raise ValueError("constant coefficient must be zero")
    h = [F(1)]
    for degree in range(1, n):
        h.append(sum(k * a[k] * h[degree - k]
                     for k in range(1, degree + 1)) / degree)
    return h


def inverse_of_x_minus_x2(n):
    g = [F(0)] * n
    if n > 1:
        g[1] = F(1)
    for degree in range(2, n):
        g[degree] = sum(g[k] * g[degree - k]
                        for k in range(1, degree))
    return g


g = inverse([1, -1, -1], 8)
print(list(map(str, g)))
e = exponential([0, 1], 6)
print(list(map(str, e)))
r = inverse_of_x_minus_x2(7)
print(list(map(str, r)))

assert multiply([1, -1, -1], g, 8) == [1] + [0] * 7
assert e == [F(1, factorial(k)) for k in range(6)]
square = multiply(r, r, 7)
assert [a - b for a, b in zip(r, square)] == [0, 1, 0, 0, 0, 0, 0]
```

输出为：

```text
['1', '1', '2', '3', '5', '8', '13', '21']
['1', '1', '1/2', '1/6', '1/24', '1/120']
['0', '1', '1', '2', '5', '14', '42']
```

第一个结果来自 $(1-x-x^2)^{-1}$，系数满足斐波那契型递推；第二个结果与阶乘倒数对照；第三个通过代回 $G-G^2=x$ 检验。它们分别检查乘法逆元、指数级数和复合反演，避免只用一条实现路径互相证明。

第四章从数的表示出发，经过浮点误差、多精度整数、分数和多项式，最后到达无限表达式的有限计算。精确系数、运算条件与可验证的不变量贯穿其中。

幂级数把这些工具接回了生成函数与算法分析：一个系数可能代表计数问题的答案，也可能代表递推式的解。先明确需要哪些系数、哪些运算合法，再选择逐项递推或精度翻倍的方法，程序才能既有限又精确。

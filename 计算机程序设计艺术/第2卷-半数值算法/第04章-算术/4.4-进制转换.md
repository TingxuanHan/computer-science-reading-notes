# 【计算机程序设计艺术 TAOCP】卷2·4.4 进制转换：整数取余，小数为什么要追踪余数

> 对应《计算机程序设计艺术》第 2 卷《半数值算法》第三版中文译本，§4.4，书内第 289-299 页。第 299 页同时开始 §4.5。本文以精确整数和分数说明转换方法，不依赖浮点近似。

把十进制 43 写成二进制，是改变表示，不是改变数值。把十进制 0.1 写成有限二进制小数，却通常必须接受一个近似结果。

这两类任务的区别，是进制转换最值得先弄清的地方。整数可以精确地转换到任意整数基数；有限小数换一个基数后，可能变成循环小数。

## 1. 整数：除以目标基数，依次取得低位

要把非负整数 $N$ 转成 $B$ 进制，使用

```math
N=BQ+r,\qquad 0\le r\lt B.
```

余数 $r$ 是最低位，商 $Q$ 中还包含其余数字。继续处理商，直到它为零；最后反转所得余数序列。

例如把 43 转为二进制，余数从低到高依次为 $1,1,0,1,0,1$，所以

$$
43=(101011)_2.
$$

处理 $k$ 位以后，可以保持不变量

$$
N=Q_kB^k+\sum_{i=0}^{k-1}r_iB^i.
$$

它说明已经输出的低位与尚未处理的商如何拼回原数。结束时 $Q_k=0$，整个表示随之得到证明。

## 2. 整数也可以从高位向低位读入

若给定的是 $b$ 进制数字 $a_m\cdots a_0$，可用嵌套形式计算它的值：

$$
N=(\cdots((a_mb+a_{m-1})b+a_{m-2})b+\cdots)b+a_0.
$$

这就是每读一个新数字，先把当前值乘以原基数，再加上新数字。

原书强调这里有两种不同的工作环境：可以使用原进制的算术，反复除以目标基数；也可以使用目标进制的算术，反复乘以原基数。数学表达相近，具体程序依赖的基础运算却不同。

输入解析还必须检查数字合法性。例如 `102` 不是合法的二进制整数。把字符解析成一个整数之后，不检查它是否小于基数，会把输入错误悄悄变成另一个数。

## 3. 小数：乘以目标基数，依次取得高位

设 $0\le x<1$。定义

$$
x_0=x,\qquad d_i=\lfloor Bx_{i-1}\rfloor,
\qquad x_i=Bx_{i-1}-d_i.
$$

因为 $0\le x_i<1$，数字始终满足 $0\le d_i<B$。处理 $k$ 位后有

$$
x=\sum_{i=1}^{k}d_iB^{-i}+x_kB^{-k}.
$$

因此前 $k$ 位截断的误差为 $x_kB^{-k}$，满足

```math
0\le x-\sum_{i=1}^{k}d_iB^{-i}\lt B^{-k}.
```

整数转换从低位取数，小数转换从小数点后的第一位开始取数。两者方向相反，是因为一个在移除整数低位，另一个在把小数高位推到整数部分。

若输入小数本来就是一串有限的 $b$ 进制数字，也可以从最右边向左递推：先把当前值加上下一位，再除以 $b$。原书据此给出整数、小数各两种基本转换方法。

## 4. 有限展开的条件，取决于约分后的分母

把有理数写成最简分数 $p/q$，其中 $q>0$。它在 $B$ 进制下有有限展开，当且仅当存在 $k\ge0$ 使

$$
q\mid B^k.
$$

必要性：如果有限展开等于 $A/B^k$，约分后的分母必须整除 $B^k$。充分性：若 $q\mid B^k$，则 $pB^k/q$ 是整数，直接以 $B^k$ 为分母就得到有限展开。

等价地，$`q`$ 的每个素因子都必须也是 $B$ 的素因子。例如：

| 分数 | 二进制 | 十进制 |
|---|---|---|
| $1/8$ | 有限 | 有限 |
| $1/10$ | 循环 | 有限 |
| $1/3$ | 循环 | 循环 |

分母必须先约分。$`3/6=1/2`$ 在二进制下可以终止，不能看到原分母含有 3 就判定它循环。

## 5. 余数既决定下一位，也决定整个循环

对 $0\le p<q$，不用浮点数就能生成展开。令初始余数 $r_0=p$，每一步做

```math
Br_{i-1}=qd_i+r_i,\qquad 0\le r_i\lt q.
```

若余数变成零，展开终止。若一个非零余数再次出现，从这一刻起，后续数字就会完全重复，因为下一步只由当前余数决定。

余数最多只有 $q$ 种，所以有理数展开一定终止或最终循环。记录“余数第一次出现的位置”，就能准确分离非循环前缀和循环节。

例如

$$
\frac1{10}=(0.0\overline{0011})_2,
\qquad
\frac1{12}=(0.08\overline3)_{10}.
$$

不能通过“某一段数字看起来重复了”就宣布找到循环节；重复的完整状态，也就是这里的余数，才给出确定依据。

当 $\gcd(q,B)=1$ 且分数非零并已约分时，循环从第一位开始，其长度是使 $B^t\equiv1\pmod q$ 成立的最小正整数 $t$。分母与基数不互素时，通常还要先经过非循环前缀。

## 6. 舍入不是直接丢掉后面的数字

输出固定 $k$ 位小数时，截断误差小于 $B^{-k}$；最近舍入的绝对误差可控制在 $\tfrac12B^{-k}$ 内，但必须处理恰好居中时的规则和进位传播。

例如十进制 0.999 舍入到两位小数，应得到 1.00，而不只是把最后一位单独加一。原书还提醒：用“先加半个单位再截断”的写法时，那个半单位本身若已被错误近似，最终方向也可能出错。

采用精确分数时，可以直接比较余数与分母的一半，从而判断是否需要进位。若最终还要转换回原格式，则必须明确是恢复原始数学值、恢复原浮点数，还是仅保证显示误差；这些要求不同。

## 7. Python：输出精确循环节

程序用整数执行所有状态更新。`fraction_digits` 返回非循环前缀与循环节两个列表，空循环节表示有限展开。为了便于展示，函数只接受 $[0,1)$ 内的分数，整数部分可以先用 `divmod` 分开。

```python
from fractions import Fraction


def read_digits(digits, base):
    if base < 2 or not digits:
        raise ValueError("invalid input")
    value = 0
    for digit in digits:
        if not 0 <= digit < base:
            raise ValueError("digit outside base")
        value = value * base + digit
    return value


def write_digits(n, base):
    if base < 2 or n < 0:
        raise ValueError("invalid input")
    digits = []
    while n:
        n, r = divmod(n, base)
        digits.append(r)
    return digits[::-1] or [0]


def fraction_digits(p, q, base):
    if q <= 0 or not 0 <= p < q or base < 2:
        raise ValueError("expected 0 <= p/q < 1")
    value = Fraction(p, q)
    remainder, denominator = value.numerator, value.denominator
    seen, digits = {}, []
    while remainder and remainder not in seen:
        seen[remainder] = len(digits)
        digit, remainder = divmod(base * remainder, denominator)
        digits.append(digit)
    if not remainder:
        return digits, []
    start = seen[remainder]
    return digits[:start], digits[start:]


def restore_fraction(prefix, cycle, base):
    def value(ds):
        return read_digits(ds, base) if ds else 0
    answer = Fraction(value(prefix), base ** len(prefix))
    if cycle:
        answer += Fraction(value(cycle),
                           base ** len(prefix) * (base ** len(cycle) - 1))
    return answer


print(write_digits(read_digits([1, 0, 1, 0, 1, 1], 2), 10))
for p, q, base in [(1, 8, 2), (1, 10, 2), (1, 12, 10)]:
    prefix, cycle = fraction_digits(p, q, base)
    assert restore_fraction(prefix, cycle, base) == Fraction(p, q)
    print(prefix, cycle)
```

输出：

```text
[4, 3]
[0, 0, 1] []
[0] [0, 0, 1, 1]
[0, 8] [3]
```

恢复循环小数使用几何级数：长度为 $t$、数字值为 $C$ 的纯循环部分，值为 $C/(B^t-1)$；前面有 $s$ 位前缀时，再乘以 $B^{-s}$。

这个逆向恢复使用另一条数学关系，能检查循环起点和数字序列是否正确。周期本身可能很长，程序也可能需要保存大量余数，不能把它当作不受输入规模影响的常数时间操作。

## 8. 转换也是计算成本的一部分

大整数逐位读入时，当前值会越来越长；逐位输出时，也要反复执行长除法。不能仅数“处理了多少个字符”，就认定总成本一定线性。

大规模转换可以按数字块或分治组织，复用基数幂和更快的长整数运算。原书对不同机器上的单精度实现和手算方法也有讨论，阅读时应把算法正确性与具体机器的速度比较分开。

下一节研究有理算术：把分子、分母都保留下来，可以让许多计算始终保持精确，而最大公因子将决定如何避免它们不必要地膨胀。

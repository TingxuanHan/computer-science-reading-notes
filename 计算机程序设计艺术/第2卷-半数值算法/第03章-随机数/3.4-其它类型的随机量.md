# 【计算机程序设计艺术 TAOCP】卷2·3.4 其它类型的随机量：从均匀数到分布、洗牌与抽样

> 对应原书：第2卷《半数值算法》第3版，§3.4，书页104至131，包含数值分布、随机抽样和洗牌。以下概率推导假设输入随机量具备所要求的独立性与分布；有限精度实现另行说明。

应用很少只需要一串0与1之间的数。模拟需要等待时间，随机算法需要整数索引，抽样需要固定大小的子集，洗牌需要一种排列。

§3.4 讨论的是转换：给定一致随机数，怎样使输出对象具有指定的概率？这一层如果写错，即使底层生成器很好，结果仍然会偏。

## 1. 从16种等可能输入，不能直接取余得到6种等可能输出

假设整数 $R$ 在0至15之间等概率取值。想模拟0至5，直接计算 `R % 6`，各结果的原像个数为

```text
结果：0  1  2  3  4  5
个数：3  3  3  3  2  2
```

0至3的概率都是 $3/16$，4和5却只有 $2/16$。问题不是取余运算失灵，而是16无法被6整除。

在理想连续模型中，$`\lfloor6U\rfloor`$ 的确均匀，因为六个区间等长。但如果 $U$ 实际只来自16个网格点，区间中包含的网格点数也无法全部相同。有限精度与连续证明之间需要补上这一层。

一个可精确分析的办法是拒绝末尾多出来的输入。一般地，已知 $R$ 在 $`\{0,\ldots,M-1\}`$ 上均匀，要输出 $`\{0,\ldots,n-1\}`$，且 $1\leq n\leq M$，令

$$
L=M-(M\bmod n).
$$

若 $R\geq L$，重新取一个；否则输出 $R\bmod n$。区间 $[0,L)$ 中，每个余数恰有 $L/n$ 个原像，条件分布便严格均匀。

单轮接受概率为 $L/M$。在独立重复抽取的模型下，平均尝试次数为 $M/L$。上例只接受0至11，每种余数各出现两次，平均尝试 $4/3$ 次。

这里的公平性依赖输入分布。把一个低位有短周期的生成器套进拒绝框架，不会自动消除其相关性。

## 2. 按累计概率切分区间

若离散结果 $x_1,\ldots,x_k$ 的概率为 $p_1,\ldots,p_k$，可以把 $[0,1)$ 切成长度依次为这些概率的区间。

例如概率为 $1/2,1/3,1/6$ 时：

$$
X=\begin{cases}
x_1,&0\leq U<1/2,\\
x_2,&1/2\leq U<5/6,\\
x_3,&5/6\leq U<1.
\end{cases}
$$

这也解释了加权抽样。如果权重为非负整数 $(3,2,1)$，可先公平生成0至5的整数，再按三个区间的长度分配结果，避免不必要的浮点边界误差。

顺序查找累计概率适合类别较少的情况；类别很多时，可以二分查找累计表。原书还介绍别名法：先做预处理，再借助表项与一次比较完成选择。它改变的是重复抽取的代价，目标分布仍需由表的构造保证。

## 3. 逆分布函数把均匀坐标变成目标坐标

设目标随机量的分布函数为 $F(x)$。在连续且严格递增的情形，令

$$
X=F^{-1}(U).
$$

因为

$$
\Pr(X\leq x)=\Pr(U\leq F(x))=F(x),
$$

输出就具有目标分布。更一般的分布需要使用广义逆，离散累计区间法也可以放进这一思路。

以速率为 $\lambda>0$ 的指数分布为例：

$$
F(x)=1-e^{-\lambda x},\qquad x\geq0.
$$

解出反函数得到

$$
X=-\frac{\ln(1-U)}{\lambda}.
$$

若接口提供 $0\leq U<1$，这个写法包含 $U=0$ 对应的0，却不会在 $U=1$ 处取对数。程序中可用 `log1p(-u)` 计算 $\ln(1-u)$，改善很小的 $u$ 附近的数值计算。

也常见 $-\ln U/\lambda$，但它要求处理 $U=0$。两式在理想连续分布下等价，实际接口的端点却不相同。不要只复制公式而不核对输入范围。

有限网格还会限制尾部。例如 $U$ 距离1至少为 $1/M$ 时，上式的最大值不会超过 $\ln M/\lambda$。极端尾部事件是否重要，要由应用决定。

## 4. 反函数不好算时，可以换一种构造

标准正态分布的反函数不易直接用简单初等运算表示。原书详细讨论了多种方法，其中极坐标法很适合展示几何转换。

先独立生成 $U_1,U_2$，令 $V_i=2U_i-1$，再计算 $S=V_1^2+V_2^2$。保留 $0<S<1$ 的点，输出

$$
Z_1=V_1\sqrt{\frac{-2\ln S}{S}},\qquad
Z_2=V_2\sqrt{\frac{-2\ln S}{S}}.
$$

在连续理想模型下，保留下来的点均匀落在单位圆内；半径平方 $S$ 在0至1之间均匀，角度均匀且与半径独立。变换后的联合密度分解成两个标准正态密度，因此两个输出独立。

这里写成拒绝 $S=0$，避免有限网格上原点造成除零。连续模型中单点概率为0，离散程序中却可能真的产生原点。若缓存第二个正态输出，缓存是否为空以及缓存值也属于可复现状态的一部分。

更一般的拒绝法假设目标密度为 $f$，易抽取的候选密度为 $g$，并找到常数 $C$ 使

$$
f(x)\leq Cg(x).
$$

先按 $g$ 生成候选 $X$，再以 $f(X)/(Cg(X))$ 的概率接受。被接受的候选密度正比于

$$
g(x)\frac{f(x)}{Cg(x)}=\frac{f(x)}C,
$$

归一化后就是 $f$。接受率为 $1/C$，所以包络松紧直接影响成本；如果包络不满足不等式，正确性证明也就失效。

本节还介绍正态分布的其他生成方法，以及指数、伽马、贝塔和若干整数分布。它们常把简单分布组合起来。例如独立指数变量的和给出整数形状参数的伽马分布；有限次独立 Bernoulli 试验中的成功次数给出二项分布。组合中的“独立”是条件，不能只看每一项的边缘分布。

## 5. 洗牌要让每一种排列等可能

对 $n$ 个互不相同的对象，目标是让 $n!$ 种排列各以 $1/n!$ 的概率出现。

Fisher-Yates 洗牌从末尾开始：在当前尚未固定的 $i+1$ 个位置中公平选一个 $j$，与位置 $i$ 交换，然后把 $i$ 减1。

为什么要逐步缩小选择范围？最后一个位置从 $n$ 个对象中等概率确定，倒数第二个从剩余 $n-1$ 个中确定，依此类推。给定一个目标排列，恰好有一条选择路径得到它，因此概率为

$$
\frac1n\cdot\frac1{n-1}\cdots\frac12=\frac1{n!}.
$$

每次都从整个数组选一个位置交换，并没有这个证明。以3个对象为例，若进行3轮、每轮都从3个位置中均匀选择，就有 $3^3=27$ 条等概率路径。27不能被6整除，因此六种排列不可能等概率。

这是一种很实用的检查方法：先数随机选择路径，再检查它们怎样映射到最终对象。

## 6. 不知道总长度，也能保留公平样本

原书的水库抽样处理另一个问题：数据一条条到来，总长度预先未知，但只想保留 $k$ 条。

先把前 $k$ 条放进水库。读到第 $t$ 条时，公平生成 $`J\in\{0,\ldots,t-1\}`$。如果 $J<k$，用新记录替换水库的第 $J$ 项；否则丢弃新记录。

新记录的入选概率为 $k/t$。一条旧记录若在前 $t-1$ 条中以 $k/(t-1)$ 的概率被保留，这一步被替换的概率为 $1/t$，因此继续留在水库的概率为

$$
\frac{k}{t-1}\left(1-\frac1t\right)=\frac kt.
$$

这证明了各记录的边缘入选概率相同。完整目标还包括所有 $k$ 元子集等概率。可以继续做归纳：对不含第 $t$ 条的固定子集，它必须在上一步被选中并且这一步不替换；对含第 $t$ 条的子集，则对上一步可能被替换的旧记录求和。两类最后都得到

$$
\frac1{\binom tk}.
$$

只证明“每条记录一样容易入选”还不够。例如总从四条记录中选`{1,2}`或`{3,4}`，每条的入选概率虽为1/2，六种二元子集却没有同等机会。

## 7. 把随机选择接口注入算法，便于检查

下面用 `draw_below(n)` 表示一个应返回0至 $n-1$ 的公平整数接口。示例传入固定选择只是为了重现某一条执行路径；公平性来自前面的概率证明，以及对所有小规模路径的枚举检查。

```python
from math import isfinite, log1p


def randbelow_reject(n, draw, source_size):
    if not 1 <= n <= source_size:
        raise ValueError("require 1 <= n <= source_size")
    limit = source_size - source_size % n
    while True:
        r = draw()
        if not isinstance(r, int) or not 0 <= r < source_size:
            raise ValueError("source returned an invalid integer")
        if r < limit:
            return r % n


def shuffle(items, draw_below):
    result = list(items)
    for i in range(len(result) - 1, 0, -1):
        j = draw_below(i + 1)
        if not isinstance(j, int) or not 0 <= j <= i:
            raise ValueError("invalid shuffle choice")
        result[i], result[j] = result[j], result[i]
    return result


def reservoir(stream, k, draw_below):
    if not isinstance(k, int) or k < 0:
        raise ValueError("k must be a nonnegative integer")
    if k == 0:
        return []
    pool = []
    for t, item in enumerate(stream, 1):
        if t <= k:
            pool.append(item)
        else:
            j = draw_below(t)
            if not isinstance(j, int) or not 0 <= j < t:
                raise ValueError("invalid reservoir choice")
            if j < k:
                pool[j] = item
    if len(pool) < k:
        raise ValueError("stream is shorter than k")
    return pool


def exponential_from_u(u, rate):
    if not isfinite(u) or not 0 <= u < 1:
        raise ValueError("u must lie in [0, 1)")
    if not isfinite(rate) or rate <= 0:
        raise ValueError("rate must be finite and positive")
    return -log1p(-u) / rate


source = iter([15, 14, 13, 12, 11])
print(randbelow_reject(6, lambda: next(source), 16))
choices = iter([2, 0])
print(shuffle("ABC", lambda n: next(choices)))
choices = iter([0, 3, 1])
print(reservoir("ABCDE", 2, lambda n: next(choices)))
print(f"{exponential_from_u(0.5, 2):.6f}")
assert exponential_from_u(0, 2) == 0
```

输出：

```text
5
['B', 'A', 'C']
['C', 'E']
0.346574
```

数组内容不同不妨碍验证洗牌结构；但若有重复值，判断等概率时应先把对象按原位置标识，不能直接把不同对象产生的同值排列混为一类。

把随机接口作为参数还有一个好处：测试可以准确指定“先拒绝四次，再接受”的分支，而不必等待某个种子偶然走到这里。

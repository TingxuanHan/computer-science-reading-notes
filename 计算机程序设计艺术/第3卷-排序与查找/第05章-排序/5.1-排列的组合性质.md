# 【计算机程序设计艺术 TAOCP】卷3·5.1 排列的组合性质：排序之前，先量一量输入有多乱

同样是八个数，有的只把最后两个位置放反，有的完全倒序，有的由两段很长的递增序列拼成。它们的长度相同，排序所需的工作却可能差很多。

第五章先讨论排列，就是要把这些差别写成能够计算的量。逆序数描述元素之间错开的关系，路段描述局部有序的连续区间，图表则把一个排列转换成另一种有结构的对象。理解这些量，后面分析插入排序和合并排序时就有了具体的抓手。

## 1. 逆序数：需要纠正多少对相对次序

先考虑 $1,2,\ldots,n$ 的一个排列 $a_1,a_2,\ldots,a_n$。若

$$
i<j,\qquad a_i>a_j,
$$

就称这一对元素构成反序，通常也叫逆序。记总数为

$$
I(a)=\sum_{1\le i<j\le n}[a_i>a_j].
$$

例如，自拟排列 $3,1,4,2$ 有三对逆序：$`3`$ 与 $1$、$`3`$ 与 $2$、$`4`$ 与 $2$。完全递增的排列没有逆序，完全递减的排列有 $\binom n2$ 对。

交换一对相邻元素时，它们同其他元素的相对次序都没有改变，只有这一对的次序改变。因此，相邻交换使 $I$ 恰好增加或减少 1。

这立即给出一个精确结论：**仅允许相邻交换时，把排列排好至少需要 $I(a)$ 次交换，而每次交换相邻逆序对恰好能达到这个数。**

这里的操作限制不能省略。如果允许任意两个位置交换，完全倒序也可以很快改正；逆序数就不再是交换次数的下界。直接插入排序的右移次数等于逆序数，也是在特定实现和计数方式下成立的，不能把它直接当作所有排序程序的运行时间。

## 2. 反序表：把一个排列变成一组独立的选择

原书按**元素的值**定义反序表：$`b_j`$ 表示出现在元素 $j$ 左边、又大于 $j$ 的元素个数。注意，下标 $j$ 是元素值，不是它在排列中的位置。

因此

$$
0\le b_j\le n-j,\qquad
I(a)=\sum_{j=1}^n b_j.
$$

$3,1,4,2$ 的反序表是 $(1,2,0,0)$。元素 1 左边有一个更大的数，元素 2 左边有两个更大的数。

反序表可以唯一还原排列：从 $n$ 开始，按 $n,n-1,\ldots,1$ 的顺序插入；轮到 $j$ 时，已经放好的全是比它大的元素，把 $j$ 放在恰好 $b_j$ 个已有元素之后即可。后来插入的更小元素不会影响这个计数。

这解释了为什么满足上述范围的每张表都有效，也重新得到了

$$
n(n-1)\cdots1=n!.
$$

还可以把逆序数的分布压缩成一个生成多项式：

$$
\sum_{a\in S_n}q^{I(a)}
=\prod_{j=1}^n(1+q+\cdots+q^{n-j}).
$$

每个因子对应一个 $b_j$ 的选择，乘积中 $q^r$ 的系数就是恰有 $r$ 个逆序的排列数量。例如 $n=4$ 时，系数依次为

$$
1,3,5,6,5,3,1.
$$

在均匀随机排列模型下，每一张反序表等概率，因而各 $b_j$ 独立且在其允许范围上均匀分布。于是

$$
\mathbb E[I]=\sum_{j=1}^n\frac{n-j}{2}
=\frac{n(n-1)}4,
$$

```math
\mathop{\mathrm{Var}}\nolimits(I)
=\sum_{m=0}^{n-1}\frac{m(m+2)}{12}
=\frac{n(n-1)(2n+5)}{72}.
```

平均值也可以用“每对元素各有一半概率颠倒”得到；方差则不能把不同元素对的逆序指示量一概当成独立变量。反序表提供了更直接的独立分解。

## 3. 重复元素改变了哪些计数

如果键码来自一个多重集合，第 $i$ 类元素有 $n_i$ 个，总数 $n=\sum_i n_i$，不同键码序列的数量是

$$
\frac{n!}{n_1!n_2!\cdots n_r!}.
$$

证明可以先给同类元素加上临时编号。这样有 $n!$ 种排列；去掉编号后，每个键码序列恰好被重复计入 $\prod_i n_i!$ 次。

比如两个 A、一个 B、一个 C 共有 $4!/2!=12$ 种键码序列。这里“键码相同”和“记录相同”必须分开：两名成绩相同的学生仍是两条不同记录。若要求稳定排序，就要保留同键记录在输入中的先后次序。

严格逆序仍按 $>$ 判断，相等键码不贡献逆序。若在固定重数的不同键码序列中均匀抽样，每对不同类别的记录，其较大者在前的概率为一半，因此

$$
\mathbb E[I]
=\frac12\sum_{i<j}n_i n_j
=\frac{n^2-\sum_i n_i^2}{4}.
$$

它随着重复程度提高而下降。这说明，分析互异键码得到的平均成本不能未经说明就套到大量重复值上。

## 4. 路段：连续有序和整体有序是两回事

对于互异元素，在每个下降位置 $a_i>a_{i+1}$ 后切开，得到若干极大的递增连续段。原书把它们叫作“路段”。

例如

$$
1,3,5\mid2,4,6
$$

只有两个路段，却仍有若干跨段逆序。另一方面，相邻交换几对元素可能产生很多短路段，却只有很少的逆序。**逆序数与路段数衡量的是不同结构，不能互相替代。**

记 $D(a)$ 为下降次数。对非空排列，路段数 $R(a)=D(a)+1$。均匀随机排列中，每个相邻位置下降的概率也是 $1/2$，所以

$$
\mathbb E[R]=1+\frac{n-1}{2}=\frac{n+1}{2}.
$$

这里同样不需要假设相邻位置的下降事件独立。

令 $A(n,k)$ 表示有 $k$ 个下降的排列数。把最大元素 $n$ 插进一个长度 $n-1$ 的排列，可以得到欧拉数递推

$$
A(n,k)=(k+1)A(n-1,k)+(n-k)A(n-1,k-1),
$$

其中 $A(0,0)=1$，范围外的项为 0。第一部分把 $n$ 放到已有下降处或末尾，保持下降数；第二部分来自插入后新增一个下降的位置。

自然合并排序可以直接利用已有路段。若输入本来就由少量长路段组成，识别它们再合并，常常比忽略结构、从单个元素开始处理更合适。这是后面讨论自适应性的一个入口。

## 5. 图表与对合：换一种方式记录排列

原书的图表是各行左对齐、行长不增，并且每行、每列都严格递增的整数数组。对 $1,\ldots,n$ 的排列，逐个进行行插入：

1. 在第一行找到第一个大于待插入数的元素，用新数替换它。
2. 把被替换的数带到下一行，重复同样的操作。
3. 某行找不到更大的元素时，把数加到该行末尾；必要时新建一行。

把得到的图表记作 $P$；另用同形图表 $Q$ 记录每一步新增格子的编号。这里必须保留 $Q$：单独的 $P$ 一般不能唯一确定原排列。

原书建立了排列与同形图表对 $(P,Q)$ 的一一对应，并证明排列取逆对应交换 $P,Q$。因此，对合，即满足 $\pi^{-1}=\pi$ 的排列，对应于 $P=Q$ 的情形。

对合的个数也有直接递推。记它为 $t_n$，考察元素 $n$：它或者固定不动，或者与其余 $n-1$ 个元素之一配成一个二循环。于是

$$
t_n=t_{n-1}+(n-1)t_{n-2},\qquad t_0=t_1=1.
$$

例如 $t_4=10$。若形状为 $\lambda$ 的标准图表数量为 $f^\lambda$，上述对应给出

$$
n!=\sum_{\lambda\vdash n}(f^\lambda)^2,
\qquad
t_n=\sum_{\lambda\vdash n}f^\lambda.
$$

第一式数同形的有序图表对，第二式只数一张图表。这里给出对应关系的用途，完整可逆构造及证明可接着读 §5.1.4；它比单纯记住一个计数公式更有价值。

## 6. Python：还原反序表，并观察图表对

下面的实现只接受 $1,\ldots,n$ 的排列。校验输入后，反序表还原与图表插入分别用直接方法完成，便于逐步检查，而不是追求最快实现。

```python
from bisect import bisect_right

def check_permutation(a):
    if sorted(a) != list(range(1, len(a) + 1)):
        raise ValueError("需要 1..n 的排列")

def inversion_table(a):
    check_permutation(a)
    b = [0] * len(a)
    for i, value in enumerate(a):
        b[value - 1] = sum(x > value for x in a[:i])
    return b

def restore(b):
    n = len(b)
    if any(not isinstance(x, int) or not 0 <= x <= n-j
           for j, x in enumerate(b, 1)):
        raise ValueError("反序表越界")
    a = []
    for value in range(n, 0, -1):
        a.insert(b[value - 1], value)
    return a

def tableaux(a):
    check_permutation(a)
    p, q = [], []
    for step, value in enumerate(a, 1):
        for row_index, row in enumerate(p):
            j = bisect_right(row, value)
            if j == len(row):
                row.append(value)
                q[row_index].append(step)
                break
            row[j], value = value, row[j]
        else:
            p.append([value])
            q.append([step])
    return p, q

def eulerian_row(n):
    if n < 0:
        raise ValueError("n 不能为负")
    row = [1]
    for size in range(1, n + 1):
        prev = row
        row = [(k+1)*(prev[k] if k < len(prev) else 0)
               + (size-k)*(prev[k-1] if k else 0)
               for k in range(size)]
    return row

a = [3, 1, 4, 2]
b = inversion_table(a)
print(b, sum(b))
print(restore(b))
print(tableaux(a))
print(eulerian_row(4))
```

输出：

```text
[1, 2, 0, 0] 3
[3, 1, 4, 2]
([[1, 2], [3, 4]], [[1, 3], [2, 4]])
[1, 11, 11, 1]
```

可以枚举小规模排列，检查还原是否一致、反序表总和是否等于直接数出的逆序数、$`P,Q`$ 是否同形，以及排列取逆后两张图表是否交换。这些检查能发现实现错误；一般性结论仍由前面的构造与原书证明支持。

## 使用方式

每篇保留节号、所用版本和阅读定位，包含解释、推导或示例程序。页码按相应卷册分别计算，部分节的起止页与习题或相邻小节共用；应以篇内说明为准。

在仓库根目录运行全部检查：

```sh
python 计算机程序设计艺术/verification/verify_all.py
```

需要Python 3.10或更新版本，依赖均为标准库。程序会执行51篇中的61个Python代码块，并运行保留的独立对照检查。有限测试用于复现示例和发现边界错误，不能替代一般性证明。

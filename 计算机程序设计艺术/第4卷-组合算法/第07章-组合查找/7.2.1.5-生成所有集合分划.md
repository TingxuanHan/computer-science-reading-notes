# 【计算机程序设计艺术 TAOCP】卷4·7.2.1.5 生成所有集合分划：受限增长串、Bell数与按编号定位

> 阅读位置：第4卷第3册双语版，§7.2.1.5，中文书页212—237（PDF第219—244页）；正文至书页228，随后为习题。本文关注普通有标号集合的分划，源节中的鞍点分析与多重集合分划作为扩展方向说明。

## 1. 元素有身份，块没有名字

把集合`{0,1,2}`分成若干非空、互不相交、并集为全集的块，共有五种：

`{012}`、`{01}{2}`、`{02}{1}`、`{0}{12}`、`{0}{1}{2}`。

每个元素有身份，所以`{01}{2}`与`{02}{1}`不同；块的排列没有意义，所以`{01}{2}`与`{2}{01}`相同。这同时要求我们保留元素身份，又消除块标签造成的重复。

若随意给每个元素填一个0至n−1的标签，虽然能表达分组，却会把“只是给块改名”的结果重复生成。例如`001`、`110`、`223`表达同一个相等关系。

## 2. 受限增长串给块规定唯一的名字

按照元素0、1、2……的顺序扫描，第一次看到的新块依次命名为0、1、2……。得到的序列满足

$$
a_0=0,\qquad 0\le a_i\le1+\max(a_0,\ldots,a_{i-1}).
$$

这就是受限增长串（RGS）。对`{0,2}{1,4}{3}`，编码为`01021`。某个元素可以进入此前任一块，也可以创建唯一一个新块；不能跳过尚未出现的标签。

从集合分划到RGS，按首次出现顺序命名；从RGS到集合分划，把相同标签的元素放在一起。两步互逆，所以它既保留全部对象，又为每个对象提供唯一编码。

这里的“受限增长”限制的是标签首次出现的方式，并不要求整个串单调。`01021`显然会上下变化。

## 3. 生成器只需要知道已经有几个块

假设前缀已经出现k个块，下一元素可取标签`0,…,k−1`，或新标签k。选择旧标签后仍有k块，选择新标签后变为k+1块。

每个选择唯一确定下一前缀，所有合法RGS又都能按此前缀规则还原，因此深度优先遍历不会重复也不会遗漏。下面代码按标签从小到大尝试，输出字典序。

若只要恰好K块，还能剪枝：当前块数超过K时立即停止；若当前k块加上全部剩余元素仍不足K，也立即停止。每个剩余元素最多只能新建一块，这个上界是剪枝正确性的依据。

空集合有一个分划，即没有任何块的空分划。n=0、K=0应该返回一个空编码；n>0、K=0没有结果。处理好它们，后续计数递推就不需要“补丁式”例外。

## 4. 第二类Stirling数与Bell数

记$S(n,k)$为n个元素分成k块的数量。考虑最后一个元素：它要么独占一个新块，要么加入原来k个块之一，因此

$$
S(n,k)=S(n-1,k-1)+kS(n-1,k).
$$

边界为$S(0,0)=1$，其他不合法下标取0。总分划数为Bell数

$$
B_n=\sum_{k=0}^nS(n,k).
$$

前几项为$1,1,2,5,15,52,203,877$。例如5个元素分为任意数量的块共有52种，恰好3块为25种。

另一个独立的组织方式是观察含元素0的块：若它还有j个同伴，选择这些同伴有$\binom{n-1}{j}$种，其余元素可以任意分划。因此

$$
B_n=\sum_{j=0}^{n-1}\binom{n-1}{j}B_{n-1-j},\qquad n\ge1.
$$

这些式子是计数的工具，不会自动交付全部52个分划。生成器与计数程序的输出需求仍然不同。

## 5. 为什么仅知道当前块数就能按编号定位

令F(r,k)表示已有k个不同块、还有r个有标号元素待放置时的合法续写数量。下一步可加入k个旧块中的任一个，或创建新块，所以

$$
F(r,k)=kF(r-1,k)+F(r-1,k+1),\qquad F(0,k)=1.
$$

注意F不是$S(r,k)$：这里已有k个可区分的旧块，而且最终块数不固定。起点没有旧块，因此$F(n,0)=B_n$。

反排名时，依次考虑下一个标签。每个旧标签后面有$F(r-1,k)$个续写，新标签后面有$F(r-1,k+1)$个续写。若目标编号不在当前这块，就减去其大小继续；否则固定这个标签并进入下一位置。

这能直接跳到某个分划，也能用均匀整数编号来精确采样。相反，若在每一步均匀选择一个可用标签，最终分划并不均匀，因为不同前缀拥有的续写数量不同。均匀采样必须按分支的完成数量加权。

## 6. 块大小模式不是集合分划本身

对于n=4，整数分划`2+2`只描述大小，却对应三种集合分划：`{01}{23}`、`{02}{13}`、`{03}{12}`。一般地，若有$m_j$个大小为j的块，满足$\sum j m_j=n$，则对应的集合分划数量为

$$
\frac{n!}{\prod_{j\ge1}(j!)^{m_j}m_j!}.
$$

分母中的$j!$消除每个块内部的排列，$m_j!$消除同大小块之间的交换。这个公式也说明：随机集合分划的块大小，通常不会均匀分布在所有整数分划模式上。

原节后半部分进一步研究Bell数和Stirling数的渐近行为，以鞍点法寻找主导贡献。这解决的是规模增长和典型块数，而不是给RGS生成器多加一个循环。阅读时应先确认生成函数与参数含义，再进入近似分析。

## 7. 格雷顺序和多重集合的边界

原书还讨论一次只改变一个受限增长串位置的生成方式，以及固定块数的格雷顺序。这里需要关注编码约定：改变一个数字后，若重新命名所有块，显示出的数字变化可能扩散，所以要把“对象的局部变化”和“规范化后的字符串变化”分别说明。

若原始集合本身有重复类型，则普通RGS会把同类型元素的身份也保留下来。想把它们视作不可区分对象时，需要额外的规范形式；直接生成全部带标签分划再粗暴去重，常常会把输出规模放大许多倍。本文实现只承诺普通有标号集合。

## 8. 完整Python实现

程序对n≤7逐个核验RGS、块数和反排名，并对n≤5穷举全部标签赋值再规范化，作为不同生成路线的参照。它不会仅凭Bell数相等就判定“肯定没有重复”。

```python
from functools import lru_cache
from itertools import product


def set_partitions_rgs(n, blocks=None):
    if n < 0 or (blocks is not None and not 0 <= blocks <= n):
        raise ValueError('invalid n or block count')
    a = []

    def visit(k):
        remaining = n - len(a)
        if blocks is not None and (k > blocks or k + remaining < blocks):
            return
        if remaining == 0:
            yield tuple(a)
            return
        for label in range(k + 1):
            a.append(label)
            yield from visit(max(k, label + 1))
            a.pop()
    yield from visit(0)


@lru_cache(None)
def completions(remaining, blocks):
    if remaining == 0:
        return 1
    return blocks * completions(remaining - 1, blocks) + completions(remaining - 1, blocks + 1)


def rgs_unrank(n, r):
    if n < 0 or not 0 <= r < completions(n, 0):
        raise ValueError('invalid n or rank')
    result, k = [], 0
    for i in range(n):
        for label in range(k + 1):
            next_k = max(k, label + 1)
            size = completions(n - i - 1, next_k)
            if r < size:
                result.append(label)
                k = next_k
                break
            r -= size
    return tuple(result)


def stirling_row(n):
    row = [1]
    for _ in range(n):
        new = [0] * (len(row) + 1)
        for k in range(1, len(new)):
            new[k] = row[k - 1] + (k * row[k] if k < len(row) else 0)
        row = new
    return row


def canonical_labels(a):
    names = {}
    result = []
    for x in a:
        if x not in names:
            names[x] = len(names)
        result.append(names[x])
    return tuple(result)


def verify():
    total = 0
    for n in range(8):
        rows = list(set_partitions_rgs(n))
        counts = stirling_row(n)
        assert len(rows) == len(set(rows)) == sum(counts) == completions(n, 0)
        assert rows == sorted(rows)
        for k in range(n + 1):
            assert len(list(set_partitions_rgs(n, k))) == counts[k]
        for rank, a in enumerate(rows):
            assert rgs_unrank(n, rank) == a
            assert canonical_labels(a) == a
        if n <= 5:
            brute = {canonical_labels(a) for a in product(range(n), repeat=n)}
            assert set(rows) == brute
        total += len(rows)
    return {'set_partitions_checked': total, 'brute_force_max_n': 5}


if __name__ == '__main__':
    print(verify())
```

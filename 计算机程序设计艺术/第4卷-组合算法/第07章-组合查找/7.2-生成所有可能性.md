## 1. 先分清：生成、判定、计数、优化

假设我们面对一个有限对象集合 $\mathcal S$。

| 任务 | 需要返回什么 | 能否找到一个就结束 |
| --- | --- | --- |
| 生成 | 每个对象恰好一次 | 不能 |
| 存在性判定 | 是否至少有一个满足条件的对象 | 找到后可以 |
| 计数 | 满足条件的对象总数 | 通常不能 |
| 优化 | 目标值最优的对象或最优值 | 需要最优性依据 |

这会影响整个算法。SAT 求解器找到一个赋值就能证明可满足；若要求所有赋值，只返回这个赋值显然不够。优化搜索提前停止，也必须有界或其他证据证明不会遗漏更优结果。

输出成本同样需要单独计算。若有 $N$ 个结果，每个结果要完整写出 $n$ 个符号，仅输出就需要 $\Omega(nN)$ 次符号写入。有些算法所谓“每个结果常数时间”，说的是内部状态转移的均摊成本，或者只报告发生变化的位置，而不是免费复制完整结果。

## 2. §7.2.1.1：元组与 Gray 码，顺序也能节省工作

若第 $i$ 个位置可取 $0,\ldots,r_i-1$，元组总数为

$$
\prod_{i=1}^n r_i.
$$

把各位置视为不同进制的计数器，就能按字典序生成：最低位加一，满了归零并向前进位。这种顺序适合与排序后的结果比较，但一次进位可能改变许多位置。

二进制反射 Gray 码换了一个目标：相邻对象只改变一位。第 $i$ 个码字可以写成

$$
g(i)=i\oplus(i\gg1),\qquad 0\le i<2^n.
$$

例如三位序列是 `000, 001, 011, 010, 110, 111, 101, 100`。

为什么相邻只变一位？设 $i$ 末尾有 $t$ 个连续的 1，则从 $i$ 加到 $i+1$，其异或差为 $d=2^{t+1}-1$。于是

$$
g(i)\oplus g(i+1)=d\oplus(d\gg1)=2^t,
$$

结果只有一个 1 位。无重复则可以从可逆性得到：知道 Gray 码后，从最高位向低位累积异或，能够恢复唯一的二进制数。

如果每个子集都需要维护一个元素权重和，相邻只增删一个元素，就能增量更新这个和。它改变的是访问顺序以及后续计算的复用机会，没有减少 $2^n$ 个子集本身。

## 3. §7.2.1.2：下一个排列，为什么是这三个动作

设当前排列为 $a_0,\ldots,a_{n-1}$。按字典序寻找后继，需要保留尽可能长的前缀，并让第一个改变的位置增加得尽可能小。

具体可以这样做：

1. 从右向左找到最大的 $j$，使 $a_j<a_{j+1}$；若不存在，当前已经是最后一个排列。
2. 在右侧找到最右的、严格大于 $a_j$ 的元素并交换。
3. 反转 $j$ 后面的后缀，使它回到最小顺序。

第一步保证原后缀非递增，所以它本身已经不能再增大；第二步选择的就是右侧可用的最小增量；第三步把其余部分降到最小。三步一起保证“比当前大，并且没有跳过中间排列”。

从排序后的输入开始，这个方法也适用于重复元素，不需要先生成重复排列再用集合去重。若不同元素的重复次数为 $m_1,\ldots,m_k$，总数为

$$
\frac{n!}{m_1!\cdots m_k!}.
$$

例如多重集合 `aab` 只生成 `aab, aba, baa`。实现时的严格与非严格比较不能随意互换，否则重复键会破坏后继规则。

## 4. §7.2.1.3：组合用递增索引消除排列重复

从 $n$ 个带编号对象中取 $k$ 个，可以表示成

$$
0\le c_0<c_1<\cdots<c_{k-1}<n.
$$

每个子集只有一种递增表示，因此不再需要处理同一子集的 $k!$ 种排列。寻找后继时，从右侧找还能增加的索引 $c_i$；它的上界是

$$
c_i\le n-k+i.
$$

选定位置增加一后，后缀依次填成相邻递增值。这与排列的思路相同：增加最右边仍可增加的位置，然后把后缀恢复为最小合法形式。

组合数递推

$$
\binom nk=\binom{n-1}k+\binom{n-1}{k-1}
$$

还提供了生成之外的工具。按是否包含某个元素拆分后，可以计算一个分支有多少对象，据此跳过整段结果、计算排名或按排名还原。排名必须说明所用顺序；字典序与其他组合顺序的编号不能混用。

边界也属于定义：$k=0$ 时有且只有一个空组合；$k>n$ 时没有结果。

## 5. §7.2.1.4—§7.2.1.5：整数分划与集合分划是不同对象

整数分划把一个数拆成正整数之和，并忽略各项顺序。例如 5 的整数分划有 7 个：

$$
5,\quad4+1,\quad3+2,\quad3+1+1,\quad
2+2+1,\quad2+1+1+1,\quad1+1+1+1+1.
$$

为了避免把 $3+2$ 和 $2+3$ 算两次，可以要求各项非递增。若剩余总和为 $r$，上一项为 $b$，下一项就只需考虑 $1$ 到 $\min(r,b)$。每次选定一项后，剩余和变小，得到一个有限的递归生成过程。

集合分划则把有身份的元素划成若干个非空、互不相交的块。`{0,1}|{2}` 与 `{0,2}|{1}` 是不同结果，即使两者块大小都为 2 和 1。仅记录块大小会丢失信息。

一个紧凑表示是受限增长串：

$$
a_0=0,\qquad
0\le a_i\le1+\max(a_0,\ldots,a_{i-1}).
$$

标签相同的元素属于同一块，新块按首次出现的顺序编号。这样 `001` 表示 `{0,1}|{2}`，`010` 表示 `{0,2}|{1}`；交换块名不会再创造一个新结果。

若有 $k$ 个已有块，下一个元素可以加入任一旧块，也可以独立开新块。这给出第二类 Stirling 数的递推

$$
S(n,k)=kS(n-1,k)+S(n-1,k-1),
$$

所有块数相加就是 Bell 数 $B_n$。生成结果的数量可以和这个独立递推核对，但数量相等仍不能代替“不重复”的检查。

## 6. §7.2.1.6—§7.2.1.7：树的编码与生成方法的选择

树首先要讲清楚是哪一种树：是否有根、孩子是否有顺序、结点是否带标签。不同约定对应不同对象集合，不能共享一个未经说明的计数公式。

这里选有序根树。遍历每条边时，向子结点走记一个左括号，返回父结点记一个右括号。具有 $n$ 条边的树对应长度 $2n$ 的平衡括号串。任一前缀的左括号数不能少于右括号数，最终两者相等。

生成时，只在左括号不足 $n$ 时加左括号，只在右括号少于左括号时加右括号。这把全局合法性转成了便宜的前缀条件。

按第一个左括号对应的右括号拆分，得到 Catalan 递推

$$
C_0=1,\qquad C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}
=\frac{1}{n+1}\binom{2n}n.
$$

对 $n=3$，有 5 个括号串，对应 5 棵有序根树，每棵有 3 条边、4 个结点。这里的编码约定与“每个结点输出一对括号”的记法相差一个外层根括号，要先统一再比较数量。

原书 §7.2.1.7 收束于生成方法的历史及进一步参考。读这一部分时，可以同时记录算法保证的顺序、每次改变多少位置、辅助存储和是否需要递归栈。字典序、最小变化顺序、无循环生成等方法解决不同的使用需求，不能仅凭代码长短给出统一排名。本文没有把书后列举的文献都当作已逐篇核读的来源。

## 7. 先运行几个小生成器

以下代码演示上述不变量。整数分划、集合分划和括号串使用直接递归，优先展示结构；它们不是原书各类高效生成算法的逐行移植。输出元组或字符串时会复制当前结果，所以完整输出成本仍然存在。

```python
def permutations_lex(items):
    a = sorted(items)
    while True:
        yield tuple(a)
        j = len(a) - 2
        while j >= 0 and a[j] >= a[j + 1]:
            j -= 1
        if j < 0:
            return
        k = len(a) - 1
        while a[k] <= a[j]:
            k -= 1
        a[j], a[k] = a[k], a[j]
        a[j + 1:] = reversed(a[j + 1:])


def combinations_lex(n, k):
    if n < 0 or k < 0:
        raise ValueError("negative size")
    if k > n:
        return
    a = list(range(k))
    while True:
        yield tuple(a)
        i = k - 1
        while i >= 0 and a[i] == n - k + i:
            i -= 1
        if i < 0:
            return
        a[i] += 1
        for j in range(i + 1, k):
            a[j] = a[j - 1] + 1


def integer_partitions(n):
    if n < 0:
        raise ValueError("negative size")

    def walk(left, bound, prefix):
        if left == 0:
            yield prefix
        for x in range(min(left, bound), 0, -1):
            yield from walk(left - x, x, prefix + (x,))

    yield from walk(n, n, ())


def set_partitions_rgs(n):
    if n < 0:
        raise ValueError("negative size")

    def walk(prefix, maximum):
        if len(prefix) == n:
            yield prefix
            return
        for label in range(maximum + 2):
            yield from walk(prefix + (label,), max(maximum, label))

    yield from walk((), -1)


def parentheses(n):
    if n < 0:
        raise ValueError("negative size")

    def walk(left, right, word):
        if right == n:
            yield word
            return
        if left < n:
            yield from walk(left + 1, right, word + "(")
        if right < left:
            yield from walk(left, right + 1, word + ")")

    yield from walk(0, 0, "")


print([format(i ^ (i >> 1), "03b") for i in range(8)])
print(["".join(p) for p in permutations_lex("aab")])
print(list(combinations_lex(4, 2)))
print(len(list(integer_partitions(5))))
print(len(list(set_partitions_rgs(4))))
print(list(parentheses(3)))
```

输出：

```text
['000', '001', '011', '010', '110', '111', '101', '100']
['aab', 'aba', 'baa']
[(0, 1), (0, 2), (0, 3), (1, 2), (1, 3), (2, 3)]
7
15
['((()))', '(()())', '(())()', '()(())', '()()()']
```

这些生成器在规模为 0 时都保留一个空对象，而不是没有对象。这与乘法计数的单位元、$C_0=1$ 和 $S(0,0)=1$ 一致，也是递归能够自然结束的原因。

## 8. §7.2.2：回溯的核心，是证明一段前缀不可能成功

设完整解是 $x_1,\ldots,x_n$，用 $P_l(x_1,\ldots,x_l)$ 表示前 $l$ 个选择满足的必要条件。安全剪枝需要保证

$$
P_{l+1}\Longrightarrow P_l.
$$

若当前 $P_l$ 为假，就不可能通过添加后缀变成合法完整解，可以跳过其下的整棵子树。一个前缀“看上去不太好”并不是正确性依据；若只是启发式估计，直接剪掉可能漏解。

以 $n$ 皇后为例，每行放一个皇后，用 $q_r$ 记录第 $r$ 行的列号。除列不能重复外，还要保证

$$
q_r-r\ne q_s-s,\qquad q_r+r\ne q_s+s\quad(r\ne s).
$$

冲突一旦发生，后续再放皇后也不能修复已经存在的攻击关系，因此可以立即剪枝。

用位掩码保存当前列和两类斜线的攻击位置，就能一次算出本行允许的位置。走到下一行时，两类斜线掩码分别左移、右移一位。低位提取技巧 `free & -free` 则逐个取出候选。

原书还强调更新与撤销：进入子树时改过哪些状态，退出时就必须准确恢复。下面的皇后程序把三个掩码当作不可变整数传给下一层，因此父层状态自然保留；若采用共享数组或链表，就需要显式执行逆向恢复。

## 9. §7.2.2.1：精确覆盖与舞蹈链分别解决什么

精确覆盖的输入是一组必须满足的项目，以及若干候选行；每行包含它能够同时满足的项目。目标是选出若干行，使每个项目恰好被覆盖一次。

例如全集为 $\{0,1,2,3\}$，候选行为

$$
A=\{0,1\},\ B=\{2,3\},\
C=\{0,2\},\ D=\{1,3\}.
$$

解为 $\{A,B\}$ 与 $\{C,D\}$。选择 A 后，C 和 D 都因重复覆盖而被排除。

Algorithm X 的递归结构是：选择一个尚未覆盖的项目，对能覆盖它的候选行逐一分支；每次选择一行，就删除它覆盖的项目以及与它冲突的行，然后递归。项目全部覆盖时输出一个解；某个未覆盖项目已经没有候选行时，当前分支失败。

优先选择候选行最少的项目，常能尽早发现矛盾。它是减少搜索量的启发式，不改变解集，也不保证每个实例都最快。

舞蹈链 DLX 的重点在数据结构：用可恢复的链接变化实现删除与撤销，避免每个结点复制整个稀疏矩阵。被临时摘下的结点保留恢复所需的邻接信息；撤销必须遵守与删除匹配的逆序。它改善更新成本，不会把一般精确覆盖变成多项式时间问题。

提供的 5C 文件是 2017-04-15 的早期预稿，正文仍有未完成段落。这里以其精确覆盖定义及 5B 中的恢复思想为基础讲解；下面用集合过滤实现搜索逻辑，明确不把它称为完整 DLX。示例限定每行非空且所有项目均为必选项目，不包含带颜色或可选项目的扩展。

## 10. 运行回溯与精确覆盖

```python
def queens_count(n):
    if n < 0:
        raise ValueError("negative size")
    mask = (1 << n) - 1

    def search(columns, left, right):
        if columns == mask:
            return 1
        free = mask & ~(columns | left | right)
        total = 0
        while free:
            bit = free & -free
            free ^= bit
            total += search(columns | bit,
                            ((left | bit) << 1) & mask,
                            (right | bit) >> 1)
        return total

    return search(0, 0, 0)


def exact_covers(universe, rows):
    universe = frozenset(universe)
    rows = tuple(frozenset(row) for row in rows)
    if any(not row or not row <= universe for row in rows):
        raise ValueError("rows must be nonempty subsets")

    def search(remaining, active, chosen):
        if not remaining:
            yield chosen
            return
        column = min(sorted(remaining),
                     key=lambda c: sum(c in rows[i] for i in active))
        for i in active:
            if column not in rows[i]:
                continue
            rest = tuple(j for j in active if rows[j].isdisjoint(rows[i]))
            yield from search(remaining - rows[i], rest, chosen + (i,))

    yield from search(universe, tuple(range(len(rows))), ())


print([queens_count(n) for n in range(9)])
rows = [{0, 1}, {2, 3}, {0, 2}, {1, 3}]
print(list(exact_covers(range(4), rows)))
```

输出：

```text
[1, 1, 0, 0, 2, 10, 4, 40, 92]
[(0, 1), (2, 3)]
```

八皇后的 92 包括旋转、反射后的不同棋盘布置，没有合并对称解。精确覆盖程序输出的是行编号；不同编号即使包含相同项目，也被视为不同候选行。

集合过滤版在每层创建新状态，容易检查但有复制和扫描成本。它适合先验证问题建模，再与采用可逆更新的实现比较。数独也可建模为精确覆盖，但必须把“格子、行数字、列数字、宫数字”等约束正确编码，不能只验证每个格子填了一个数。

## 11. §7.2.2.2：SAT 把选择写成统一的布尔约束

SAT 的 CNF 输入是若干子句的合取，每个子句是若干文字的析取；文字是变量或变量的否定。目标是找出一个使全部子句为真的赋值。

若决定文字 $l$ 为真，可以删除所有含 $l$ 的子句，并从其余子句中删除 $\neg l$。之后会出现三个关键状态：

- 没有剩余子句：全部约束已经满足。
- 某个子句为空：这个子句不可能为真，当前分支失败。
- 某个子句只剩一个文字：这个文字必须为真，可以继续传播。

“空公式为真”和“公式含空子句为假”是两件不同的事，不能都用一个没有解释的空列表代表。

单位传播不能解决全部实例。传播停止后仍可能需要选择一个变量，尝试两个值，并在冲突时回溯。下面实现这个基本框架，返回一个满足赋值或 `None`。

```python
def solve_sat(raw_clauses):
    clauses = tuple(frozenset(c) for c in raw_clauses)
    variables = sorted({abs(lit) for c in clauses for lit in c})
    if 0 in variables:
        raise ValueError("literal 0 is not a variable")
    # 同时含 x 与非 x 的子句恒真，可以移除。
    clauses = tuple(c for c in clauses if not any(-lit in c for lit in c))

    def assign(formula, literal):
        return tuple(c - {-literal} for c in formula if literal not in c)

    def search(formula, values):
        while True:
            if any(not c for c in formula):
                return None
            if not formula:
                return values
            unit = next((next(iter(c)) for c in formula if len(c) == 1), None)
            if unit is None:
                break
            values = dict(values)
            values[abs(unit)] = unit > 0
            formula = assign(formula, unit)
        clause = min(formula, key=len)
        literal = min(clause, key=lambda x: (abs(x), x < 0))
        for choice in (literal, -literal):
            branch = dict(values)
            branch[abs(choice)] = choice > 0
            answer = search(assign(formula, choice), branch)
            if answer is not None:
                return answer
        return None

    answer = search(clauses, {})
    if answer is None:
        return None
    return {v: answer.get(v, False) for v in variables}


formula = [(1, 2), (-1, 3), (-2, -3)]
answer = solve_sat(formula)
print(tuple(int(answer[v]) for v in (1, 2, 3)))
print(solve_sat([(1,), (-1,)]))
print(solve_sat([]), solve_sat([()]))
```

输出：

```text
(1, 0, 1)
None
{} None
```

代码用正负整数表示正文字和负文字。求解成功后，尚未赋值的变量可任意填值；这里统一填 False，因为全部子句已经由先前赋值满足。它只返回一个解，不能直接拿返回次数当作满足赋值总数。

更高效的 SAT 求解还涉及监视文字、冲突分析、学习子句、分支启发式等。学习子句的关键是保留由原约束推出的后果，使搜索不必一再重走同类冲突；任意添加一个“看起来有用”的条件可能删掉合法解。本文的程序没有实现这些机制，也没有据此声称达到工业求解器的性能。

编码本身同样影响规模。若把大布尔表达式直接分配展开成 CNF，可能指数膨胀；可用辅助变量表示中间结点。例如 $y\leftrightarrow(a\land b)$ 可以编码成

$$
(\neg y\lor a)\land(\neg y\lor b)\land
(y\lor\neg a\lor\neg b).
$$

再要求输出变量为真。每个门只引入常数个子句，便能建立与电路规模成比例的编码。这里讨论的是加入辅助变量后的可满足性对应；它改变了变量集合，若做模型计数，还必须明确辅助变量的扩展是否唯一。

## 12. 怎样核对“所有可能性”没有悄悄少一块

小规模测试可以同时采用三类独立证据：

1. **对象检查。**每个排列的元素多重集正确，每个分划不含空块，括号的每个前缀平衡非负，每个精确覆盖解逐列覆盖一次。
2. **数量与去重。**分别对照阶乘、组合数、分划数动态规划、Stirling 数和 Catalan 数，再检查完整结果集合中没有重复。
3. **独立穷举。**用标准库排列筛选小棋盘皇后，用候选行的全部子集核对精确覆盖，用所有布尔赋值逐个核对小 CNF 的可满足性及返回见证。

三者作用不同：计数正确可能是“漏一个、重一个”，每个输出合法也不能证明没漏解。真正的一般性保证来自对象与编码的一一对应、后继规则以及剪枝条件的证明。

从这些例子回看 7.2，会发现生成与搜索共享一个基础：先选定不会混淆对象的表示，再明确哪些前缀仍可能完成，最后让状态转移和恢复准确反映这种结构。优化的空间往往就在表示、顺序、增量检查与恢复成本之间。

## 1. SAT问的是存在性，返回值必须有明确含义

布尔可满足性问题问：是否存在一组变量赋值，使给定公式为真？若存在，最好返回一份可检查的赋值；若不存在，需要完整搜索或可靠证明，而不能把“暂时没找到”当成无解。

本文输入采用合取范式CNF：子句内部是文字的或，子句之间是与。文字可以是变量x，也可以是其否定。代码用正整数表示正文字，用负整数表示负文字，0不作文字。

例如`[(1,2),(-1,3),(-2,-3)]`表示

$$
(x_1\lor x_2)\land(\neg x_1\lor x_3)\land(\neg x_2\lor\neg x_3).
$$

两个边界一定要分清：空公式没有任何待满足要求，为真；空子句没有一个可使其为真的文字，为假。因此`[]`可满足，而`[()]`不可满足。代码用`None`表示UNSAT，用字典表示SAT，空字典也可能是有效解，不能写成`if model:`来区分。

## 2. 把组合问题翻译成子句

以图着色为例，为每个顶点v和颜色c创建变量$x_{v,c}$，表示v采用c。

每个顶点至少选一种颜色：

$$
\bigvee_c x_{v,c}.
$$

每个顶点至多选一种颜色，对任意不同颜色c、d加入

$$
\neg x_{v,c}\lor\neg x_{v,d}.
$$

对每条边(u,v)和每个颜色c，再加入

$$
\neg x_{u,c}\lor\neg x_{v,c}.
$$

三角形用两种颜色不可满足，用三种颜色可满足，适合作为小型端到端检查。必须同时验证建模和求解：一个正确求解器也会忠实求解错误的CNF。

这里“至多一个”的两两排斥编码使用二次数量的子句。变量很多时可引入辅助变量，使用序贯或其他基数约束编码。选择编码不能只比较子句少不少，还应比较传播强度、辅助变量数量和求解器的处理方式。原节对此投入了大量篇幅。

## 3. 辅助变量带来的是可满足性保持，不总是原变量上的同式

对逻辑门$z\leftrightarrow(a\land b)$，可以用三个子句表示：

$$
(\neg z\lor a)\land(\neg z\lor b)\land(z\lor\neg a\lor\neg b).
$$

前两个保证z为真时a、b都真；第三个保证a、b都真时z也真。逐门引入辅助变量，可以避免把一般电路直接分配展开成指数规模的CNF。

比较时要说明变量空间：扩展公式包含额外的z；原公式与扩展公式经过辅助变量存在量化后的关系，才是需要证明的关系。某些变换只保持SAT/UNSAT，不保持模型数量。做模型计数、均匀采样或枚举时，不能把这些目标混为一谈。

程序会穷举a、b、z的全部8种赋值核对这个门编码。实际模型的检查还应把求得的赋值翻回原问题，验证每条原始约束。

## 4. 赋值化简和单位传播

将文字l设为真后，包含l的子句已经满足，可以删除；其他子句中的¬l变为假，可以删掉该文字。若出现空子句，就发生冲突。

若某子句只剩一个文字，它必须为真，这就是单位传播。例如

`(a)`、`(¬a∨b)`、`(¬b∨c)`、`(¬c)`

从a为真开始，依次迫使b、c为真，最后与¬c冲突，不需要任意分支。

单位传播必须反复进行到没有新的单位子句，而不是只扫描一次初始输入。传播产生的新赋值可能继续缩短其他子句。

若没有冲突，也没有单位子句，就选一个尚未确定的变量，分别探索真假两个分支。两个分支覆盖了该变量的全部取值，因此穷尽搜索可以判定UNSAT。这是DPLL的基本结构。纯文字消除也是可用规则，但本文为了让代码与证明更短，没有加入它。

## 5. 两个被观察的文字为什么能减少扫描

朴素实现每次赋值都遍历许多子句，成本很高。双观察文字方法为一个非单位子句维护两个观察位置；只在某个观察文字变假时，才检查能否把观察位置移到另一个尚未为假的文字。

如果能移动，子句暂时不必继续处理；如果不能，而另一个观察文字未赋值，它成为单位；如果另一个也为假，就发现冲突；若另一个为真，子句已经满足。

观察位置无需固定在原始子句开头，也不要求回溯时移回原位置。回溯让一些文字从假恢复为未赋值，不会因这种放宽而破坏已保持的观察条件。不过赋值轨迹和传播队列仍需正确恢复。

本文代码采用复制简化后的子句集合，便于审查；没有实现观察列表。它能说明逻辑正确性，无法据此推断工业求解器的性能。

## 6. 冲突学习把“这次失败”变成以后可复用的条件

考虑以下子句：

$$
\begin{aligned}
&\neg a\lor b,\qquad \neg a\lor c,\\
&\neg b\lor\neg c\lor d,\\
&\neg d\lor e,\qquad \neg d\lor\neg e.
\end{aligned}
$$

若决定a为真，会传播出b、c、d都真，随后e被要求同时真和假。只回到a再尝试另一边，已经能继续搜索；但记录冲突原因可以得到更有用的结论。

从最后两个子句对e作归结，得到¬d；再与第三个子句归结，得到¬b∨¬c；继续利用前两个原因，可以推出¬a。这些都是原公式的逻辑后果，因此作为学习子句加入不会删掉原本合法的解。

归结规则为

$$
(A\lor x),\ (B\lor\neg x)\ \Longrightarrow\ (A\lor B).
$$

这个完整推导用于说明原因追踪，不表示实际CDCL一定学习到最后的¬a。若按首次唯一蕴含点（1-UIP）停止分析，这个例子可以更早停在¬d。学习何种子句、回跳到哪一层，要结合决策层和蕴含图，而不是机械地把所有原因归结到底。

学习、非顺序回跳、变量活动度、重启和学习子句删除共同构成CDCL的重要机制。重启并不意味着忘掉一切；学习子句常被保留，以便新的搜索顺序利用已有信息。删除部分学习子句则是管理内存和传播成本的选择，不能把原始约束随意删除。

## 7. 前瞻与局部搜索解决不同的成本问题

原节比较轻量分支、单位传播、前瞻及子句学习等路线。前瞻会试探候选赋值后的传播结果，用额外工作换取更好的分支选择；子句学习则利用已经发生的冲突。哪种更有效，依赖实例结构，不能仅看变量或子句数量。

局部搜索从一个完整赋值出发，反复改变变量，试图减少未满足子句。找到满足赋值就给出了可验证的SAT证据；达到步数上限却没找到，只能说这次搜索未成功，不能据此报告UNSAT。

随机k-SAT还带来子句密度、实例分布与相变附近难度等问题。书中某一生成分布下的实验不能直接推广到电路验证、规划或图问题编码。本文也不把2015年草稿中的性能比较写成当前求解器排名。

## 8. 局部引理、预处理和对称性破除

局部引理提供另一种思路：把“某个子句不满足”视为坏事件，利用低概率和有限依赖证明存在一个同时避开全部坏事件的赋值。在对称形式的适用假设下，若每个坏事件概率至多p、最多依赖d个其他事件，$ep(d+1)\le1$是一个充分条件。

这只是充分条件，不满足它不表示公式UNSAT。要使用构造性的重采样算法，还需明确独立随机变量模型、事件依赖及重采样规则，不能把局部引理当成任意CNF的通用快速求解证明。

预处理则尝试消除冗余、固定变量或改变表示。若消除了变量，输出SAT模型时必须恢复它们；若只保证可满足性保持，模型计数可能改变。

对称性破除在一组等价解中选代表。例如颜色名称完全可互换时，可规定某个顶点使用第一种颜色。但一旦颜色带有不同业务含义，这个约束就未必合法。正确依据是已证明的对称变换，而不是“感觉差不多”。

## 9. 一个能审查的DPLL实现

下面实现进行重文字去除、重言子句去除、单位传播和二分搜索，返回原始输入变量上的完整赋值。它没有CDCL、观察文字、重启或证明日志，适合验证小模型和学习逻辑流程。

核验包含：3变量、至多3个不同规范子句的全部3304个CNF；200个固定随机种子生成的小CNF；空公式、空子句、重言式；三角形着色与AND门编码。每个SAT结果再次代回原始公式检查，SAT/UNSAT结果还与真值表穷举比较。

```python
from itertools import combinations, product
from random import Random


def satisfies(clauses, model):
    return all(any(model[abs(lit)] == (lit > 0) for lit in clause) for clause in clauses)


def dpll(raw):
    raw = [tuple(c) for c in raw]
    if any(lit == 0 for c in raw for lit in c):
        raise ValueError('literal 0 is not allowed')
    variables = {abs(lit) for c in raw for lit in c}
    clauses = []
    for c in raw:
        c = frozenset(c)
        if not any(-lit in c for lit in c):
            clauses.append(c)           # tautologies can be discarded

    def assign(formula, literal):
        return [c - {-literal} for c in formula if literal not in c]

    def search(formula, model):
        while True:
            if any(not c for c in formula):
                return None
            if not formula:
                return model
            unit = next((next(iter(c)) for c in formula if len(c) == 1), None)
            if unit is None:
                break
            variable, value = abs(unit), unit > 0
            if variable in model and model[variable] != value:
                return None
            model = model | {variable: value}
            formula = assign(formula, unit)
        clause = min(formula, key=lambda c: (len(c), tuple(sorted(c))))
        literal = min(clause, key=lambda x: (abs(x), x < 0))
        for choice in (literal, -literal):
            result = search(assign(formula, choice), model | {abs(choice): choice > 0})
            if result is not None:
                return result
        return None

    result = search(clauses, {})
    if result is not None:
        result = {v: result.get(v, False) for v in variables}
        assert satisfies(raw, result)
    return result


def exactly_one(literals):
    literals = tuple(literals)
    return [literals] + [(-a, -b) for a, b in combinations(literals, 2)]


def coloring_cnf(vertices, edges, colors):
    def variable(v, color):
        return v * colors + color + 1
    clauses = []
    for v in range(vertices):
        clauses.extend(exactly_one(variable(v, c) for c in range(colors)))
    for u, v in edges:
        for c in range(colors):
            clauses.append((-variable(u, c), -variable(v, c)))
    return clauses


def brute(clauses):
    variables = sorted({abs(lit) for c in clauses for lit in c})
    for values in product((False, True), repeat=len(variables)):
        model = dict(zip(variables, values))
        if satisfies(clauses, model):
            return model
    return None


def verify():
    atoms = [tuple(sign * (i + 1) for i, sign in enumerate(signs) if sign)
             for signs in product((-1, 0, 1), repeat=3)]
    checked = 0
    for size in range(4):
        for formula in combinations(atoms, size):
            got = dpll(formula)
            assert (got is None) == (brute(formula) is None)
            if got is not None:
                assert satisfies(formula, got)
            checked += 1
    rng = Random(7222)
    for _ in range(200):
        formula = [tuple(rng.choice((-1, 1)) * rng.randint(1, 6) for _ in range(rng.randint(0, 5)))
                   for _ in range(rng.randint(0, 12))]
        assert (dpll(formula) is None) == (brute(formula) is None)
    triangle = [(0, 1), (1, 2), (2, 0)]
    assert dpll(coloring_cnf(3, triangle, 2)) is None
    assert dpll(coloring_cnf(3, triangle, 3)) is not None
    assert dpll([]) == {} and dpll([()]) is None
    assert dpll([(1, -1)]) is not None
    and_gate = [(-3, 1), (-3, 2), (3, -1, -2)]
    for a, b, z in product((False, True), repeat=3):
        assert satisfies(and_gate, {1: a, 2: b, 3: z}) == (z == (a and b))
    return {'exhaustive_cnf_instances': checked, 'random_cnf_instances': 200,
            'encoding_tests': ['triangle coloring', 'AND gate', 'empty cases']}


if __name__ == '__main__':
    print(verify())
```

## 10. 怎样把结果带回真实任务

用SAT解决问题时，应保留三层证据：原始约束如何映射为子句，求解器给出的状态和赋值是什么，赋值翻回原问题后是否满足要求。SAT答案可直接代入检查；UNSAT需要信任完整求解过程，或进一步检查适当的不可满足性证明。超时则是未知结果。

这一节也把7.2的主线连接起来：先确定要生成或搜索什么，再用正确编码消除重复，用前缀约束减少无效分支，用可逆状态降低每步成本，最后利用冲突信息改善后续搜索。代码只是其中一层，模型、逻辑和证据同样决定结果是否可信。

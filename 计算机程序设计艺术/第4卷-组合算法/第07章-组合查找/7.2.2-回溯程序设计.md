## 1. 回溯把无效答案的后代一起排除

前七篇生成器尽量让每条完整路径对应一个目标对象。实际问题往往还有约束：某些排列不能出现，某些位置会互相冲突，某个局部选择会让后面无处可放。

把解写成$`(x_1,\ldots,x_n)`$，定义前缀判定$`P_l(x_1,\ldots,x_l)`$。正确剪枝需要满足：任何完整合法解的前l项，一定通过$`P_l`$。等价地，一旦某前缀被拒绝，其所有扩展都不可能成为合法解。

这不要求$`P_l`$足够强。它可以放过一些最终无解的前缀，只是搜索会变慢；但不能错拒一个可扩展前缀，否则答案就会永久遗漏。

回溯的一轮操作是：列出当前选择，作选择，更新状态，进入下一层，返回后恢复状态，再试下一个选择。递归只是表达控制流的一种方式，正确性来自前缀条件、分支覆盖和恢复不变式。

## 2. n皇后把冲突压缩为三类索引

第r行放一个皇后，列为$`c_r`$。同列冲突要求列值不重复；两种对角线分别由$`r-c_r`$与$`r+c_r`$标识。因此合法条件是

$$
c_i\ne c_j,\quad i-c_i\ne j-c_j,\quad i+c_i\ne j+c_j\qquad(i\ne j).
$$

若每放一个皇后都扫描此前所有皇后，检测成本随深度增长。维护三个占用集合，就能把“当前候选是否合法”变成三个成员查询。

这没有改变搜索空间，只改变每个节点的处理成本。优化回溯时应分别记录搜索节点数量和每个节点的更新工作；节点少的实现不一定更快，因为更强的判断也可能很贵。

## 3. 恢复是算法的一部分

进入子问题前，程序把列、两条对角线和路径写入状态；回来时按相反方向撤销。下一分支看到的状态必须与作本次选择之前完全一致。

“把刚才写成True的位置改回False”只有在该位置此前必定为False时才正确。若同一项可能被多条约束重复修改，简单清零会抹掉祖先状态。通用做法是记录旧值：进入一层时保存撤销栈长度，更新时压入地址和旧值，退出时弹回那个长度。

若在一层内同一位置被多次写入，可只保存第一次写之前的值，但需要精确区分同层与不同分支。使用时间戳时，不应把反复复用的深度直接当作永不重复的事务标识；要么使用单调增长的帧编号，要么把时间戳本身也纳入恢复机制。

下面集合版使用`try/finally`，确保普通异常返回时也执行清理。位集合计数版则把状态作为整数参数传递，不共享可变容器，天然简化恢复。

## 4. 位集合为什么能一次找到所有可用列

在当前行，把已占用列、两种对角线攻击位置分别记为C、L、R。棋盘掩码为$`M=2^n-1`$，则可用列为

```math
A=M\mathbin{\&}\neg(C\lor L\lor R).
```

取`A & -A`得到最低可用位，移除后继续处理其余候选。选中位b进入下一行时，列占用变为$`C\lor b`$；两组攻击位向相反方向移一格。

Python的按位取反采用无限符号扩展，因此必须与M相与，把有效位限制在棋盘宽度内。左右移位表达的是“下一行受到攻击的列”，不是在整张棋盘上移动已经放置的皇后。

这种表示很紧凑，但不意味着一般回溯问题都能压成几个机器字。状态表示必须匹配约束结构。

## 5. 动态选择与前瞻：既要早失败，也要算得便宜

在一般约束问题中，可以优先选择剩余可选值最少的变量。这让无解分支更容易提前暴露。选择某值后，还可以删除其他变量中被冲突排除的候选；若任何未完成变量候选数变成0，立即回退。

关键是维护成本。每次为了找到最少候选变量而重新扫描全部问题，也许比省下的节点更贵。书中通过多种例子比较不同表示和动态顺序，强调搜索树形状和数据更新需要一起设计。

剪枝、分支顺序和对称消除还应分开：改变尝试顺序通常不改变解集；删除对称分支则可能只保留等价类代表。若最终要恢复原始解数量，必须处理轨道大小和具有额外对称性的特殊解，不能简单乘一个固定常数。

## 6. 不跑完整棵树，能否估计它多大

原节还讨论随机路径估计。设从根出发，每层在当前节点的b个孩子中均匀选一个，沿途分支数为$`b_0,b_1,\ldots`$。对访问节点数，可构造

$$
\widehat T=1+b_0+b_0b_1+b_0b_1b_2+\cdots.
$$

为什么期望正确？深度d的某个节点被选中的概率是其路径分支数乘积的倒数；一旦到达它，估计器给这一层的权重正好是该乘积。二者相乘为1，对全部节点相加得到真实节点数。

这个结论不表示一次估计就准确。若树的分支非常不均匀，少数罕见路径会带来极大权重，方差可能很高。应用时应重复抽样、报告波动，并确保分支选择概率与权重公式一致。

若要估计的是运行时间，还要把每个节点的实际处理成本乘进去；不能把节点数估计直接称为秒数估计。下面程序用一个小树穷举所有随机路径，以有理数精确核验期望为9，避免拿一次随机运行碰巧接近真值作为证据。

## 7. 完整代码与验证

集合版交付所有解及各深度的访问数量；位集合版只计数。n≤8时，再用所有列排列筛选对角线约束作为独立参照，既比较数量，也比较具体解集。

```python
from fractions import Fraction
from itertools import permutations


def queens(n):
    if n < 0:
        raise ValueError('n must be nonnegative')
    cols, down, up, path = set(), set(), set(), []
    profile = [0] * (n + 1)
    answers = []

    def visit(row):
        profile[row] += 1
        if row == n:
            answers.append(tuple(path))
            return
        for col in range(n):
            if col in cols or row - col in down or row + col in up:
                continue
            cols.add(col)
            down.add(row - col)
            up.add(row + col)
            path.append(col)
            try:
                visit(row + 1)
            finally:
                path.pop()
                up.remove(row + col)
                down.remove(row - col)
                cols.remove(col)
    visit(0)
    assert not cols and not down and not up and not path
    return answers, profile


def queens_bit_count(n):
    if n < 0:
        raise ValueError('n must be nonnegative')
    mask = (1 << n) - 1

    def visit(cols, left, right):
        if cols == mask:
            return 1
        available = mask & ~(cols | left | right)
        total = 0
        while available:
            bit = available & -available
            available ^= bit
            total += visit(cols | bit, ((left | bit) << 1) & mask, (right | bit) >> 1)
        return total
    return visit(0, 0, 0)


def exact_path_estimate(tree):
    # tree[node] is a tuple of children; absence means a leaf.
    def paths(node, probability, weight, estimate):
        children = tree.get(node, ())
        if not children:
            return probability * estimate
        b = len(children)
        return sum(paths(child, probability / b, weight * b, estimate + weight * b)
                   for child in children)
    return paths('root', Fraction(1), 1, 1)


def verify():
    known = [1, 1, 0, 0, 2, 10, 4, 40, 92]
    for n in range(9):
        rows, profile = queens(n)
        brute = {a for a in permutations(range(n))
                 if len({i - a[i] for i in range(n)}) == n
                 and len({i + a[i] for i in range(n)}) == n}
        assert len(rows) == len(set(rows)) == known[n] == queens_bit_count(n)
        assert set(rows) == brute
        assert profile[-1] == len(rows)
    tree = {'root': ('a', 'b'), 'a': ('c', 'd', 'e'), 'b': ('f',), 'd': ('g', 'h')}
    assert exact_path_estimate(tree) == 9
    return {'queens_counts': known, 'n8_profile': queens(8)[1],
            'path_estimator_exact_expectation': str(exact_path_estimate(tree))}


if __name__ == '__main__':
    print(verify())
```

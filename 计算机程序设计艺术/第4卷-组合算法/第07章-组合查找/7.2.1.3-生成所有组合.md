# 【计算机程序设计艺术 TAOCP】卷4·7.2.1.3 生成所有组合：字典序、组合数编号与转门顺序

> 阅读位置：第4卷第3册双语版，§7.2.1.3，中文书页154—187（PDF第161—194页，源节含习题；习题从书页177开始）。本文重点讨论表示、后继、编号和固定重量格雷码；源节的影子集合与极值定理作为扩展导读。

## 1. 组合必须消除选择顺序

从n个不同元素中选择k个，目标是一个集合，不关心先选谁。用严格递增下标表示它：

$$
0\le a_0<a_1<\cdots<a_{k-1}<n.
$$

这样每个集合恰好对应一个元组，对象总数为$`\binom nk`$。例如从`0,1,2,3`中选2个，`(0,2)`与`(2,0)`不应被当成两项。

另一种表示是长度n、恰有k个1的位串。二者通过“第i位为1当且仅当i被选中”对应。选中的元素很多时，可改存n−k个未选中的元素，因为$`\binom nk=\binom n{n-k}`$。但补集变换也会改变所观察到的顺序，不能只换计数而默认排序不变。

## 2. 字典序后继怎样保证还留得下后面的元素

位置j最多能取到$`n-k+j`$。若它已经达到这个上限，就必须向左找还能增加的位置。找到后加一，把所有后续位置重置为连续递增的最小合法后缀。

例如n=7、k=3，从`(1,4,6)`出发：末位6已满，前一位4还能增加到5，后缀重置为6，得到`(1,5,6)`；再下一步只能增加第一位，得到`(2,3,4)`。

证明仍是“尽量晚改、最小增加、后缀最小”。区别在于每个坐标的上界受到后面还要放几个元素的限制。若忽略这个限制，就会产生重复下标或越界。

原书部分算法使用倒序坐标或位串来表达字典序。本文统一用递增元组、从左到右比较。因此这里的`lex_combinations`不能仅凭名字就和书中倒序坐标表逐行对照，必须先转换表示。

## 3. 余字典序与组合数系统

普通字典序先比较最小元素；余字典序（colex）先比较最大不同元素，即从元组右边往左比较。n=5、k=3时，它的开头是`012,013,023,123,014`，与普通字典序不同。

余字典序有一个整洁的从0开始编号公式：

$$
R(a)=\sum_{i=1}^{k}\binom{a_{i-1}}{i}.
$$

以最大元素m分块：最大元素小于m的k元集合共有$`\binom mk`$个。最大元素固定为m以后，只需继续给前k−1个元素编号。反复展开就得到上式。这也说明编号为什么不是普通字典序排名。

例如`(1,3,5)`的排名是$`\binom11+\binom32+\binom53=1+3+10=14`$。反排名从i=k向下，取满足$`\binom xi\le r`$的最大x，记录x并减去该项，再继续处理更小的位置。每次选择锁定了一个完整分块。

给定n和k，合法排名恰为$`0,\ldots,\binom nk-1`$。这让生成任务能按编号直接切块，也能把一个子集压缩成一个整数标识。Python大整数能避免普通整数溢出，但大整数运算本身并不具有与位长无关的成本。

## 4. 固定重量格雷码：每次拿走一个，再放进一个

普通二进制格雷码每次只翻一位，会改变1的个数，不能直接保持集合大小。固定重量的相邻对象应当交换一对0和1，因此对称差大小为2。

可以从反射递归直接构造。设$`G(n,k)`$表示长度n、重量k的有序列表：

```math
G(n,k)=0G(n-1,k)\;\Vert\;1\mathop{\mathrm{rev}}\nolimits G(n-1,k-1).
```

边界为$`G(n,0)=\{0^n\}`$、$`G(n,n)=\{1^n\}`$。第一半不含最高位，第二半含最高位，因此两半不相交；数量满足帕斯卡递推，合起来恰好覆盖所有组合。反射方向保证两半连接时只移出、移入一个元素。

这和“生成全部$`2^n`$个格雷码再筛掉重量不对的项”在结果上相关，但运行方式不同。直接递归只进入可能形成目标重量的分支，避免先扫描一个远大于输出的空间。

这里的转门是一种集合成员交换，不保证被交换的两个位在位串中相邻。也不要把本文便于证明的递归版本标成原书精细优化后的无循环算法：它有递归栈、整数构造和生成器传递开销。

## 5. 重复组合可以变成普通组合

若允许重复选择，使用非递减序列$`0\le b_0\le\cdots\le b_{k-1}<n`$。令

$$
a_i=b_i+i,
$$

就得到`0`至`n+k−2`中的严格递增k元组。这建立了可逆映射，因此多重组合数为$`\binom{n+k-1}{k}`$。反向只需减去位置下标。

与之密切相关的是隔板法：把k个相同物件放入n个有标号的盒子，使用k个星号和n−1个隔板记录各盒数量。边界仍要单独处理，尤其n=0、k=0，不能机械地把负数带进组合数公式。

## 6. 原节为何还讨论影子集合

对一族k元集合F，删去每个集合中的一个元素，可得到一族k−1元集合，称为下影子。不同集合的删减结果可能重叠，因此影子大小通常小于$`k|F|`$。

取F=`{012,013,023,123}`，四个三元集合的下影子恰好是`{01,02,03,12,13,23}`，共六个。这个例子说明集合族的组织方式，会影响它暴露了多少较小子集。

书中进一步联系余字典序初段与极小影子，给出Kruskal–Katona型结论。这里的组合数展开不只是编号技巧，也能描述极值集合族。阅读时要区分单个组合的排名公式与整个集合族的极值定理：验证几张小表并不能证明后者。

## 7. 可运行代码

代码核验n≤10的所有k。字典序逐项对照`itertools.combinations`，余字典序单独排序后核对排名，格雷顺序则检查对象集合与相邻对称差，避免误把三种顺序当成同一种。

```python
from itertools import combinations
from math import comb


def lex_combinations(n, k):
    if n < 0 or not 0 <= k <= n:
        raise ValueError('require 0 <= k <= n')
    a = list(range(k))
    while True:
        yield tuple(a)
        j = k - 1
        while j >= 0 and a[j] == n - k + j:
            j -= 1
        if j < 0:
            return
        a[j] += 1
        for i in range(j + 1, k):
            a[i] = a[i - 1] + 1


def colex_rank(a):
    if any(x < 0 for x in a) or any(x >= y for x, y in zip(a, a[1:])):
        raise ValueError('expected strictly increasing nonnegative entries')
    return sum(comb(x, i) for i, x in enumerate(a, 1))


def colex_unrank(n, k, r):
    if n < 0 or not 0 <= k <= n or not 0 <= r < comb(n, k):
        raise ValueError('invalid n, k or rank')
    a, x = [0] * k, n - 1
    for i in range(k, 0, -1):
        while comb(x, i) > r:
            x -= 1
        a[i - 1] = x
        r -= comb(x, i)
        x -= 1
    return tuple(a)


def fixed_weight_gray(n, k):
    if n < 0 or not 0 <= k <= n:
        raise ValueError('require 0 <= k <= n')

    def walk(width, weight, reverse=False):
        if weight == 0:
            yield 0
        elif weight == width:
            yield (1 << width) - 1
        elif not reverse:
            yield from walk(width - 1, weight)
            for x in walk(width - 1, weight - 1, True):
                yield (1 << (width - 1)) | x
        else:
            for x in walk(width - 1, weight - 1):
                yield (1 << (width - 1)) | x
            yield from walk(width - 1, weight, True)
    yield from walk(n, k)


def verify():
    count = 0
    for n in range(11):
        for k in range(n + 1):
            want = list(combinations(range(n), k))
            assert list(lex_combinations(n, k)) == want
            ordered = sorted(want, key=lambda a: tuple(reversed(a)))
            for r, a in enumerate(ordered):
                assert colex_rank(a) == r
                assert colex_unrank(n, k, r) == a
            gray = list(fixed_weight_gray(n, k))
            assert len(gray) == len(set(gray)) == comb(n, k)
            assert set(gray) == {sum(1 << i for i in a) for a in want}
            assert all((a ^ b).bit_count() == 2 for a, b in zip(gray, gray[1:]))
            count += len(want)
    return {'combinations_checked': count, 'max_n': 10}


if __name__ == '__main__':
    print(verify())
```

如果消费者维护的是集合权重和，每次转门只需减去离开的权重、加上进入的权重；若需要按大小比较或分页，则字典序或组合数编号更直接。顺序没有统一的最优答案，它必须服务于后续计算。

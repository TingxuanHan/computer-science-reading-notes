# 【计算机程序设计艺术 TAOCP】卷4·7.2.1.6 生成所有树：括号编码、Catalan计数与均匀采样

> 阅读位置：第4卷第4册双语版，§7.2.1.6，中文书页121—162（PDF第127—168页；书页162下部开始历史一节，范围含习题）。本文选择括号与有序二叉树形状这一主线，并说明其他树类与生成树问题的区别，不把一种生成器泛称为“生成所有类型的树”。

## 1. 说“树”之前，先说哪些差别算差别

根的位置是否固定？孩子有没有左右顺序？节点有没有标签？允许一个孩子还是要求恰有两个孩子？这些条件决定了对象集合。

一棵只有根和一个孩子的有序二叉树，可以把孩子放左边，也可以放右边，得到两种形状。若把孩子看成没有次序的集合，则这两种画法可能表示同一个对象。

本文主要生成有n个非空节点、每个节点都有明确左右位置的二叉树形状。空子树用`None`表示；节点不带独立标签。这样的对象数为Catalan数$`C_n`$。

如果把所有空子树都画成外部叶子，会得到有n个内部节点和n+1个外部叶子的满二叉树。另一条对应关系连接到有n个节点的有序森林；若再添加一个公共根，就成为有n+1个节点的平面有根树。因此，同样一个下标n，不能不加转换地套到所有“节点数为n的树”。

## 2. 一条括号串怎样编码左右子树

给空树编码为空串，给非空节点T编码为

```math
E(T)=\texttt{(}\;E(T_L)\;\texttt{)}\;E(T_R).
```

一个节点是`()`；根只有左孩子时是`(())`；根只有右孩子时是`()()`。括号的第一对包住左子树，配对右括号之后的部分编码右子树。

这一定义同时说明反向解码：找到首个左括号对应的右括号，内部递归解码为左子树，后面递归解码为右子树。匹配位置唯一，所以映射可逆。

这里`()`后面还有一棵树，不表示语法错误。若按“每一对括号对应森林中的一个节点”的另一种解释，它恰好表示右侧的下一棵树。这就是原节反复使用的森林与二叉树之间的自然对应。读图时要先确认正在使用哪一种解释。

## 3. 合法括号串不是任意含n个左括号的串

令前缀高度h等于已出现的左括号数减右括号数。合法串必须满足每个前缀都有$`h\ge0`$，最终h=0。

因此生成时只需维护opened和closed：左括号总数还没到n时可以放左括号；只有`closed < opened`时才可以放右括号。这样不会生成一个非法串后才回头发现错误。

覆盖性来自反向观察：任一合法串的每个前缀都遵守这两个规则，所以其每一步都存在于搜索树中。唯一性来自每一条路径对应唯一的括号选择序列。递归总深度为2n，终止性也直接成立。

本文按“先尝试左括号，再尝试右括号”的顺序输出，使用Python的字符比较时恰为字典序。代码交付完整字符串需要O(n)时间，不能仅凭每层只添一个字符就宣布每棵树的生成成本为O(1)。

## 4. Catalan递推从左右子树的大小得到

非空树的根占一个节点。左子树有i个节点时，右子树有n−1−i个节点，选择彼此独立，因此

$$
C_0=1,\qquad C_n=\sum_{i=0}^{n-1}C_iC_{n-1-i}.
$$

另一条证明直接数括号串：所有含n个左括号、n个右括号的串共有$`\binom{2n}{n}`$个。把第一次跌到高度−1之前的前缀交换左右括号，可将非法路径与一类不平衡路径建立双射，非法串数为$`\binom{2n}{n+1}`$。相减后得到

$$
C_n=\binom{2n}{n}-\binom{2n}{n+1}=\frac1{n+1}\binom{2n}{n}.
$$

前几项为`1,1,2,5,14,42,132,429,1430`。这是一条针对明确对象类的计数结论；它并不表示任意n个节点的无根、无序或带标签树都有同样数量。

## 5. 从剩余括号的计数，走向反排名

令F(o,h)表示还剩o个左括号、当前高度h时的合法续写数。剩余右括号数自动等于o+h。若o=0，只能把剩余右括号依次写完，因此$`F(0,h)=1`$。其他情况为

$$
F(o,h)=F(o-1,h+1)+[h>0]F(o,h-1).
$$

第一项对应放左括号，第二项对应合法地放右括号。这些状态形成有向无环图，因为每一步都让剩余字符数2o+h减少1。

要找从0开始的第r个对象，先计算放左括号后的整个分块有多大。r落在其中就选左括号；否则减去其大小，再选右括号。如此反复，能直接找到目标树形而无须枚举此前所有对象。

虽然代码使用缓存，仍须考虑递归深度和大整数位长。它是教学实现，不适合在没有资源评估的情况下把n直接设成数万。

## 6. 均匀采样为什么不能均匀选择左右子树大小

若希望所有n节点树形等概率，根的左子树大小为i的概率应为

$$
\Pr(|T_L|=i)=\frac{C_iC_{n-1-i}}{C_n}.
$$

例如n=3，左子树大小0、1、2分别对应2、1、2种树形。如果把三个大小等概率选取，中间那一种具体树会得到1/3概率，其他四种各得1/6，不是均匀分布。

另一种精确方法是在$`[0,C_n)`$中均匀抽一个整数，然后反排名。它把“随机源是否均匀”和“结构转换是否一一对应”分开处理。原节讨论随机树时，这种对象分布的区分尤为重要；随机插入二叉查找树也不会自动给出均匀树形。

## 7. 原节的其他路线应怎样接着读

括号串、深度序列、父指针和左右链接都可以表示树，但它们让不同操作变得方便。局部旋转可能只改少量链接，却改变很长的括号子串；某种编码的字典序后继，也未必对应图上最小的结构改动。

原节还涉及无序有根树和给定图的生成树。无序树要消除兄弟子树交换造成的重复，通常要对子树建立规范表示；不能生成有序树后只删掉左右标记就指望自然去重。给定图的生成树则必须同时满足“边来自原图、连通、无环”，它与枚举任意抽象树形又是另一个问题。

因此本文的可执行范围保持清楚：输出的是上述有序二叉树形状；其他树类需要各自的规范形式、计数参照和后继证明。

## 8. 代码与独立检查

程序核验n≤8，逐项编码、解码、反排名，并检查Catalan数量；n≤6时额外穷举所有长度2n的括号串，筛出合法者，与生成结果比较。这样既检查数量，也检查具体对象集合。

```python
from functools import lru_cache
from itertools import product
from math import comb


def dyck_words(n):
    if n < 0:
        raise ValueError('n must be nonnegative')
    path = []

    def visit(opened, closed):
        if closed == n:
            yield ''.join(path)
            return
        if opened < n:
            path.append('(')
            yield from visit(opened + 1, closed)
            path.pop()
        if closed < opened:
            path.append(')')
            yield from visit(opened, closed + 1)
            path.pop()
    yield from visit(0, 0)


def decode_binary(word):
    def parse(pos):
        if pos == len(word) or word[pos] == ')':
            return None, pos
        left, pos = parse(pos + 1)
        if pos >= len(word) or word[pos] != ')':
            raise ValueError('unbalanced word')
        right, pos = parse(pos + 1)
        return (left, right), pos
    if any(x not in '()' for x in word):
        raise ValueError('invalid symbol')
    tree, end = parse(0)
    if end != len(word):
        raise ValueError('unbalanced word')
    return tree


def encode_binary(tree):
    if tree is None:
        return ''
    left, right = tree
    return '(' + encode_binary(left) + ')' + encode_binary(right)


@lru_cache(None)
def suffix_count(opens_left, balance):
    if opens_left == 0:
        return 1
    return suffix_count(opens_left - 1, balance + 1) + (suffix_count(opens_left, balance - 1) if balance else 0)


def dyck_unrank(n, rank):
    if n < 0 or not 0 <= rank < suffix_count(n, 0):
        raise ValueError('invalid n or rank')
    a, left, balance = [], n, 0
    while left or balance:
        first = suffix_count(left - 1, balance + 1) if left else 0
        if rank < first:
            a.append('(')
            left -= 1
            balance += 1
        else:
            rank -= first
            if balance == 0:
                raise AssertionError('invalid completion count')
            a.append(')')
            balance -= 1
    return ''.join(a)


def valid_word(word):
    balance = 0
    for x in word:
        balance += 1 if x == '(' else -1
        if balance < 0:
            return False
    return balance == 0


def verify():
    total = 0
    for n in range(9):
        rows = list(dyck_words(n))
        catalan = comb(2 * n, n) // (n + 1)
        assert len(rows) == len(set(rows)) == catalan == suffix_count(n, 0)
        assert rows == sorted(rows)
        assert len({decode_binary(w) for w in rows}) == catalan
        for rank, w in enumerate(rows):
            assert valid_word(w)
            assert encode_binary(decode_binary(w)) == w
            assert dyck_unrank(n, rank) == w
        if n <= 6:
            brute = {''.join(w) for w in product('()', repeat=2 * n) if valid_word(w)}
            assert set(rows) == brute
        total += len(rows)
    return {'tree_shapes_checked': total, 'max_n': 8}


if __name__ == '__main__':
    print(verify())
```

参考：Donald E. Knuth，《计算机程序设计艺术》第4卷第4册（双语版），§7.2.1.6。本文以`E(T)=(E(left))E(right)`固定编码约定，避免混淆森林节点、二叉树节点与外部叶子。

## 运行

需要Python 3.10或更新版本，仅使用标准库。在仓库根目录执行：

```sh
python 计算机程序设计艺术/verification/verify_all.py
```

脚本按自身位置寻找笔记，也可从其他工作目录启动。它先检查目录、正文SHA-256、Markdown链接和独立示例与正文的一致性，再执行51篇笔记中的61个Python代码块，最后运行独立对照程序。结果写入本目录的`summary.json`及各项报告。

每篇正文中的代码块按出现顺序共享一个名字空间，以便前一块定义的函数被后文使用；不同笔记在独立子进程中运行。每篇或每组扩展检查的默认时限为180秒。

2.6《历史和文献》是纯文字笔记，检查目录、格式与正文哈希。7.1.3的前两个代码块是说明性片段，验证程序为它们提供文中约定的变量，在全部16位输入上核对取位表达式和SWAR第一步；随后再执行完整程序。

| 范围 | 主要检查 |

`taocp_*_examples.py`是部分细讲中完整代码块的独立副本；总检查会确认它们与正文一致。`verify_taocp_*.py`保留相应篇目的额外检查。`summary.json`记录北京时间和实际Python版本。

有限枚举与随机用例不能替代一般性证明，也不能保证教学实现适合大规模生产任务。此处验证程序只读取笔记并生成本地报告。

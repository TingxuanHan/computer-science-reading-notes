# 【具体数学 Concrete Mathematics】5.1.7 部分超几何和式

> 对应《具体数学：计算机科学基础（第 2 版）》第 5 章 §5.7，书内第 186—191 页。本文沿用专栏三级编号。

知道一整行二项式系数的和是 $2^n$，并不意味着任意截断到一半或三分之一的位置也有同样简单的公式。这一节关心的是部分和，以及怎样有系统地寻找一个能让和式叠缩的离散原函数。

## 1. 先把问题写成差分

若找到 $G(k)$，满足

$$
t(k)=G(k+1)-G(k),
$$

那么对整数 $a\le b$，

$$
\boxed{\sum_{k=a}^{b-1}t(k)=G(b)-G(a).}
$$

如果求和上限包含 $b$，右端应改为 $G(b+1)-G(a)$。这个端点差异非常小，却是程序和手算都常见的错误来源。

例如当 $k\ge1$ 时，

$$
\frac1{k(k+1)}=\frac1k-\frac1{k+1},
$$

因此可取 $G(k)=-1/k$，得到

$$
\sum_{k=1}^{N}\frac1{k(k+1)}=1-\frac1{N+1}.
$$

另一个例子是 $k\cdot k!=(k+1)!-k!$，所以 $\sum_{k=1}^{N}k\cdot k!=(N+1)!-1$。

## 2. Gosper 算法搜索的是哪一类答案？

如果 $t(k+1)/t(k)$ 是 $k$ 的有理函数，就把 $t(k)$ 称为超几何项。这里说的是项，不是已经求和后的超几何函数；碰到零项时，需把比值理解为一般位置的代数表达式，再检查具体边界。

Gosper 算法的问题是：**给定超几何项 $t(k)$，是否存在同样属于超几何项的 $G(k)$，使 $\Delta G(k)=t(k)$？**

为什么可以从有理函数入手？若这样的 $G$ 存在，则

$$
\frac{t(k)}{G(k)}=\frac{G(k+1)}{G(k)}-1
$$

是有理函数。因此可设 $G(k)=R(k)t(k)$，其中 $R(k)$ 为有理函数。代入差分式得到

$$
\boxed{\frac{t(k+1)}{t(k)}R(k+1)-R(k)=1.}
$$

这不是任意猜一个复杂函数，而是在一个明确的代数类中寻找解。算法判定失败时，结论是“这个类中没有所需的离散原函数”，不能扩大成“这个和没有任何表示或算法”。

## 3. 规范化项比：把有理函数问题变成多项式问题

Gosper 的关键步骤，是将项比写成

$$
\frac{t(k+1)}{t(k)}
=\frac{p(k+1)q(k)}{p(k)r(k+1)},
$$

其中 $p,q,r$ 为多项式，并要求对每个正整数 $j$，$`q(k)`$ 与 $r(k+j)$ 没有非常数公因子。

这条条件的作用是排除跨整数移位的因子重叠。若存在这样的重叠，就把相应的有限因子链移到 $p$ 中。只有完成这个规范化，后续的多项式搜索才有完整性保证。

接着设

$$
G(k)=\frac{r(k)s(k)}{p(k)}t(k).
$$

代入并消去公共因子，得到

$$
\boxed{p(k)=q(k)s(k+1)-r(k)s(k).}
$$

在上述规范化条件下，若存在有理函数解 $s$，就存在多项式解。原书通过分析分母根的整数移位链证明这一点。

于是可以设 $s(k)=c_0+c_1k+\cdots+c_dk^d$，代入后比较各次幂系数，转而解一组线性方程。

## 4. 次数也能分析，不必无止境地试

令 $Q=q-r$、$`R=q+r`$，基本方程等价于

```math
2p(k)=Q(k)\{s(k+1)+s(k)\}+R(k)\{s(k+1)-s(k)\}.
```

若 $s$ 的次数为 $d$，第一对花括号通常仍为 $d$ 次，第二对为 $d-1$ 次。由最高次项比较可得：

- 若 $\deg Q\ge\deg R$，候选次数是 $d=\deg p-\deg Q$。
- 若 $\deg Q<\deg R=e$，通常候选为 $d=\deg p-e+1$。
- 后一种情形还可能发生最高次抵消。设 $R(k)=\lambda k^e+\cdots$，$`Q(k)=\lambda'k^{e-1}+\cdots`$，则需额外检查 $d=-2\lambda'/\lambda$ 是否为更大的非负整数。

零多项式和特殊参数应单独处理；不能把“先试常数、再试一次多项式，没找到就放弃”称为完整的 Gosper 算法。规范化、次数分析与求解线性方程缺一不可。

## 5. 完整例子：交错二项式的部分和

固定正整数 $n$，取

$$
t(k)=(-1)^k\binom nk.
$$

一般位置上的项比为

$$
\frac{t(k+1)}{t(k)}=\frac{k-n}{k+1}.
$$

可取 $p(k)=1,q(k)=k-n,r(k)=k$。它们满足所需的移位互素条件。基本方程为

$$
1=(k-n)s(k+1)-ks(k).
$$

尝试常数 $s(k)=c$，就得到 $1=-nc$，从而 $c=-1/n$。因此

$$
G(k)=-\frac kn(-1)^k\binom nk.
$$

对内部指标用吸收恒等式整理，可写成

$$
G(k)=(-1)^{k-1}\binom{n-1}{k-1},\qquad k\ge1,
\quad G(0)=0.
$$

这个最终表达式在边界处也容易直接检查，避免使用已经失去意义的 $0/0$ 项比。于是对 $0\le m\le n$，

$$
\boxed{\sum_{k=0}^{m}(-1)^k\binom nk
=(-1)^m\binom{n-1}m.}
$$

例如 $n=6,m=3$ 时，原和为 $1-6+15-20=-10$，右边为 $-\binom53=-10$。$`m=n`$ 时总和为零；$`n=0`$ 不在这段推导的范围内，此时只需直接计算唯一的一项 $1$。

## 6. 参数改变后，需要重新分析

把上指标换成 $-2$，则

$$
\binom{-2}k=(-1)^k(k+1).
$$

此时一个离散原函数是

$$
G(k)=(-1)^k\left(-\frac k2-\frac14\right).
$$

直接相减可验证 $G(k+1)-G(k)=(-1)^k(k+1)$，因此

$$
\sum_{k=0}^{m-1}(-1)^k(k+1)
=\frac{1-(-1)^m(2m+1)}4,\qquad m\ge0.
$$

这个例子提醒我们：参数取特殊整数值后，规范化因子、候选次数甚至是否可求和，都可能改变。不能先在一般参数下得到结论，再忽略特殊值造成的变化。

对于不带交错符号的 $\binom nk$，以 $n$ 为一般参数时，Gosper 不会给出同类的统一超几何离散原函数；但完整的有限和仍有二项式定理。这正是下一节要从“不定求和”转向“关于参数的递归”的原因。

## 7. Python：检查差分证书与所有截断位置

```python
from fractions import Fraction
from math import comb, factorial

def choose(n, k):
    return comb(n, k) if 0 <= k <= n else 0

def certificate(n, k):
    if k == 0:
        return 0
    return (-1)**(k-1) * choose(n-1, k-1)

for n in range(1, 41):
    total = 0
    for k in range(n+1):
        term = (-1)**k * comb(n, k)
        assert certificate(n, k+1) - certificate(n, k) == term
        total += term
        assert total == (-1)**k * choose(n-1, k)

for n in range(1, 61):
    assert sum(Fraction(1, k*(k+1)) for k in range(1, n+1)) == Fraction(n, n+1)
    assert sum(k*factorial(k) for k in range(1, n+1)) == factorial(n+1)-1

def negative_certificate(k):
    return (-1)**k * (-Fraction(k, 2)-Fraction(1, 4))

for m in range(61):
    assert negative_certificate(m+1)-negative_certificate(m) == (-1)**m*(m+1)
    assert sum((-1)**k*(k+1) for k in range(m)) == Fraction(1-(-1)**m*(2*m+1), 4)
print("差分证书、零端点与全部截断位置核验通过")
```

这段代码验证正文给出的证书，并没有实现完整的 Gosper 搜索算法。证书恒等式的代数证明与有限枚举承担不同的任务。

## 8. 自测

**若 $t(k)=\Delta G(k)$，从 $a$ 加到 $b$ 应得到什么？** $G(b+1)-G(a)$。

**Gosper 返回失败意味着什么？** 在它搜索的超几何项类别中，不存在所需的离散原函数；不能据此否定其他表达方式。

**求出证书后，还要检查什么？** 原参数条件、分母、求和端点，以及零项处是否能使用最终化简后的表达式。

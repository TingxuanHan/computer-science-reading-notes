# 【具体数学 Concrete Mathematics】5.1.8 机械求和法

> 对应《具体数学：计算机科学基础（第 2 版）》第 5 章 §5.8，书内第 191—201 页。本文沿用专栏三级编号。

上一节寻找 $\Delta_kG=t$，有时找不到超几何形式的 $G$。Zeilberger 的想法是把参数 $n$ 也利用起来：原来的项求不出离散原函数，就尝试若干相邻参数项的线性组合。

## 1. 从求原函数，转向求递归式

设

$$
S_n=\sum_k t(n,k).
$$

我们寻找只依赖 $n$ 的系数 $\beta_0(n),\ldots,\beta_r(n)$，使

$$
\boxed{\sum_{j=0}^{r}\beta_j(n)t(n+j,k)
=G(n,k+1)-G(n,k).}
$$

如果右边关于 $k$ 求和后的边界项为零，就得到

$$
\sum_{j=0}^{r}\beta_j(n)S_{n+j}=0.
$$

这类方法通常称为创造性叠缩。$G$ 是一份求和证书：找到它可能需要计算，但检查“它的差分是否等于左边”通常只是代数运算。

得到递归后还需要初始值，而且递推时所除的系数不能为零。递归不自动等于简单的封闭形式，却已经可能提供高效的计算方法和严格的恒等式证明。

## 2. 从头证明二项式定理

取非负整数 $n$，令

$$
t(n,k)=\binom nkz^k,\qquad
S_n=\sum_{k=0}^{n}\binom nkz^k.
$$

在非负整数 $k$ 上，把超出范围的二项式系数视为零。设

$$
G(n,k)=z^k\binom n{k-1},\qquad G(n,0)=0.
$$

利用帕斯卡公式，直接计算：

$$
\begin{aligned}
(1+z)t(n,k)-t(n+1,k)
&=z^{k+1}\binom nk-z^k\binom n{k-1}\\
&=G(n,k+1)-G(n,k).
\end{aligned}
$$

对 $k=0,\ldots,n+1$ 求和。两端满足 $G(n,0)=G(n,n+2)=0$，所以

$$
S_{n+1}=(1+z)S_n.
$$

结合 $S_0=1$，得到

$$
\boxed{S_n=(1+z)^n.}
$$

这个推导作为多项式恒等式成立，$z=0$ 也没有问题：常数项按 $z^0=1$ 处理，所有边界仍直接可验。

## 3. 截断求和时，边界往往不会消失

现在只求到某个固定的非负整数 $m$：

$$
S_n^{(m)}=\sum_{k=0}^{m}\binom nkz^k.
$$

使用同一个证书，却得到

$$
\boxed{(1+z)S_n^{(m)}-S_{n+1}^{(m)}
=z^{m+1}\binom nm.}
$$

右边就是 $G(n,m+1)-G(n,0)$。它一般不为零，因此部分和满足的是带有额外项的递归。

例如 $m=0$ 时，两个部分和都为 $1$，左边为 $z$，右边也是 $z$。如果把右边误删，就会立刻得到错误结论。

如果上下限本身也依赖 $n$，还必须将相邻 $S_n$ 的求和范围对齐；允许使用零延拓的地方可以补零，否则就要显式补上缺失项。

## 4. 归一化以后，递归可以变成“总和不变”

以 $z=1$ 为例，定义

$$
F(n,k)=\frac{\binom nk}{2^n},\qquad
H(n,k)=-\frac{\binom n{k-1}}{2^{n+1}}.
$$

则

$$
F(n+1,k)-F(n,k)=H(n,k+1)-H(n,k).
$$

对包含全部非零项的范围求和，右边为零，所以 $\sum_kF(n,k)$ 与 $n$ 无关。再检查 $n=0$ 时为 $1$，就证明了所有 $n$ 时都为 $1$。

这展示了 WZ 型证书的思路：若已经猜到答案 $C_n$，可以尝试研究归一化后的项 $t(n,k)/C_n$，将“总和等于 $C_n$”转成“归一化后的总和恒等于 $1$”。归一化要求相关分母非零。

## 5. 算法怎样寻找这样的组合？

一个典型流程是：

1. 计算 $t(n,k+1)/t(n,k)$ 与 $t(n+1,k)/t(n,k)$，检查它们的代数结构。
2. 先尝试阶数 $r=0$；失败后再尝试 $r=1,2,\ldots$。
3. 对 $\sum_j\beta_j(n)t(n+j,k)$ 应用带未知系数的 Gosper 方法，归结为多项式恒等式。
4. 比较 $k$ 的各次幂系数，求出不全为零的 $\beta_j$ 及证书。
5. 检查证书、边界与初始值，再得到原和式的结论。

原书对“正常超几何项”（proper hypergeometric term）这一大类给出存在性保证。它大致由多项式、常数的幂，以及参数为 $n,k$ 的整数线性式的阶乘乘积和商构成，并需满足定义条件。

仅仅观察到两个项比都是有理函数，并不能无条件声称所有形式都满足该保证。算法的适用类、参数退化和求和边界，都是结论的一部分。

## 6. 进阶例子：Apéry 数及完整证书

原书讨论的一个著名序列是

$$
A_n=\sum_{k=0}^{n}\binom nk^2\binom{n+k}k^2,
$$

前几项为 $1,5,73,1445,33001$。它满足

$$
\boxed{(n+1)^3A_{n+1}
=(2n+1)(17n^2+17n+5)A_n-n^3A_{n-1},\quad n\ge1.}
$$

不能把“检查前几项成立”当作这个递归的证明。下面给出可直接核对的证书。令

$$
t(n,k)=\binom nk^2\binom{n+k}k^2
$$

在 $0\le k\le n$ 之外取零，并设

$$
s(n,k)=(2n+3)\bigl(8k^2-12k-16(n+1)(n+2)\bigr).
$$

对 $1\le k\le n+2$，定义

$$
G(n,k)=s(n,k)\frac{(n+k)!^2}{(k-1)!^4(n+2-k)!^2},
$$

并在其余非负整数 $k$ 处取零。则有

$$
\begin{aligned}
&(n+1)^3t(n,k)
-(2n+3)(17n^2+51n+39)t(n+1,k)\\
&\qquad +(n+2)^3t(n+2,k)
=G(n,k+1)-G(n,k).
\end{aligned}
$$

如何检查这一大串式子？对 $0\le k\le n+2$ 提出共同的非零因子

$$
u(n,k)=\frac{(n+k)!^2}{k!^4(n+2-k)!^2}.
$$

三个求和项分别变成

$$
\begin{aligned}
t(n,k)/u&=(n+1-k)^2(n+2-k)^2,\\
t(n+1,k)/u&=(n+1+k)^2(n+2-k)^2,\\
t(n+2,k)/u&=(n+1+k)^2(n+2+k)^2.
\end{aligned}
$$

证书差分则变成

$$
\frac{\Delta_kG}{u}
=(n+k+1)^2(n+2-k)^2s(n,k+1)-k^4s(n,k).
$$

将这些多项式展开即可核对相等；端点 $k=0,n+2$ 也由零因子覆盖。最后对 $k=0,\ldots,n+2$ 求和，因 $G(n,0)=G(n,n+3)=0$，得到递归式。将参数整体减一，就是方框中的常见写法。

## 7. Python：证书、边界、递归交叉核验

```python
from fractions import Fraction
from math import comb, factorial

def choose(n, k):
    return comb(n, k) if 0 <= k <= n else 0

for n in range(21):
    for z in [Fraction(0), Fraction(-1), Fraction(2, 3), Fraction(2)]:
        def t(k, row=n):
            return choose(row, k) * z**k
        def g(k):
            return choose(n, k-1) * z**k
        for k in range(n+2):
            assert (1+z)*t(k)-t(k, n+1) == g(k+1)-g(k)
        for m in range(n+2):
            left = (1+z)*sum(t(k) for k in range(m+1))
            left -= sum(t(k, n+1) for k in range(m+1))
            assert left == z**(m+1)*choose(n, m)

def apery_term(n, k):
    return choose(n, k)**2 * choose(n+k, k)**2

def apery_certificate(n, k):
    if not 1 <= k <= n+2:
        return Fraction(0)
    s = (2*n+3)*(8*k*k-12*k-16*(n+1)*(n+2))
    return Fraction(s*factorial(n+k)**2,
                    factorial(k-1)**4 * factorial(n+2-k)**2)

for n in range(16):
    for k in range(n+3):
        lhs = (n+1)**3*apery_term(n, k)
        lhs -= (2*n+3)*(17*n*n+51*n+39)*apery_term(n+1, k)
        lhs += (n+2)**3*apery_term(n+2, k)
        assert lhs == apery_certificate(n, k+1)-apery_certificate(n, k)

direct = [sum(apery_term(n, k) for k in range(n+1)) for n in range(31)]
recursive = [1, 5]
for n in range(1, 30):
    numerator = (2*n+1)*(17*n*n+17*n+5)*recursive[n] - n**3*recursive[n-1]
    assert numerator % (n+1)**3 == 0
    recursive.append(numerator // (n+1)**3)
assert recursive == direct
print(direct[:5])  # [1, 5, 73, 1445, 33001]
```

这段程序验证了具体证书和递归，并没有实现整个自动搜索器。对一般 $n$ 的证明来自证书的多项式恒等式、边界消去和初始值；有限枚举用于补充检查实现。

## 8. 自测

**Gosper 对原项求不出离散原函数，为什么仍可能得到定和？** 若干相邻参数项的线性组合可能可求和，进而产生关于参数的递归。

**证书右边是差分，求和后就一定为零吗？** 不一定，必须计算边界。部分和往往留下非零项。

**得到递归以后还缺什么？** 足够的初始值，以及递推系数不为零等适用条件。

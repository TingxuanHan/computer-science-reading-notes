# 【具体数学 Concrete Mathematics】2.1.1 记号

> 对应《具体数学：计算机科学基础（第 2 版）》第 2 章 §2.1，书内第 18—21 页。本文沿用专栏三级编号。本节先讨论有限和，或只有有限多个非零项的和。

看到一个求和号，先别急着套公式。更基础的三个问题是：**加哪些项、指标取哪些值、哪些字母在求和过程中保持不变？** 这三个问题说清楚以后，换元和化简才有依据。

## 1. 省略号能展示规律，也可能隐藏歧义

表达式

$$
1+3+5+\cdots+(2n-1)
$$

通常能够让人看出“前 $n$ 个正奇数”。但如果只给出几个离散的数，再跟一个省略号，后续规律并不一定唯一。

求和符号把这种自然语言里的约定写得更明确：

$$
\sum_{k=1}^{n}(2k-1).
$$

这里 $k$ 是求和指标，$`2k-1`$ 是被加的通项，$`1\le k\le n`$ 是指标范围。上下限都包含在内，因此共有 $n$ 项。

“上限是 $n$”不等于“有 $n$ 项”。例如

$$
\sum_{k=0}^{n}a_k
$$

包含 $a_0,a_1,\ldots,a_n$，共有 $n+1$ 项。许多差一错误，都是从忽略这一点开始的。

## 2. 指标是局部名字，参数不是

下面三个式子表示同一个量：

$$
\sum_{k=1}^{n}a_k
=\sum_{j=1}^{n}a_j
=\sum_{r=1}^{n}a_r.
$$

改名字不改变被加的项。可以把求和指标理解成循环里的局部变量。

但改名不能覆盖本来有意义的参数。例如

$$
\sum_{k=1}^{n}a_{k+j}
$$

中的 $j$ 是固定参数。可以把 $k$ 改成 $r$，得到 $\sum_{r=1}^{n}a_{r+j}$；不能草率地把两个位置都写成 $j$，变成 $\sum_{j=1}^{n}a_{2j}$。后一式的取项规则已经改变。

同样，$`\sum_{k=1}^{n}c=nc`$ 要求 $c$ 与 $k$ 无关。若所谓的“常数”其实是 $k^2$，就不能移到求和号外。

## 3. 把范围写成条件，换元更容易检查

书中常把带上下限的写法换成条件形式：

$$
\sum_{k=1}^{n}a_k
=\sum_{1\le k\le n}a_k.
$$

条件形式尤其适合不连续的指标集合。比如“不超过 12 的正奇数的平方和”可以写成

```math
\sum_{\substack{1\le k\le12\\k\text{ 为奇数}}}k^2
=1^2+3^2+5^2+7^2+9^2+11^2
=286.
```

也能改写为 $\sum_{j=0}^{5}(2j+1)^2$。两种记法的共同要求是：**每个目标项恰好出现一次。**

再看一个平移指标的例子：

$$
\sum_{k=2}^{n+1}k^2.
$$

令 $j=k-2$，则 $k=j+2$。把旧条件一起代入：

$$
2\le j+2\le n+1
\quad\Longleftrightarrow\quad
0\le j\le n-1.
$$

因此

$$
\boxed{\sum_{k=2}^{n+1}k^2
=\sum_{j=0}^{n-1}(j+2)^2.}
$$

换元要同时改通项和条件，不能只改其中一个。还可以核对首尾：左右两边都是从 $2^2$ 加到 $(n+1)^2$。

## 4. 空和为什么等于 0？

如果指标集合为空，定义

$$
\sum_{k\in\varnothing}a_k=0.
$$

这使“没有加入任何项”与加法的单位元一致。例如按整数条件理解，$`\sum_{1\le k\le0}a_k`$ 就是空和。

为了避免上下限反转产生歧义，遇到边界情形时，直接写出条件集合最稳妥。后面的有限微积分会引入一种带方向的求和记号；它在反向区间上可以为负，不能与这里的空集求和混为一谈。

零项也不必急着删去。若 $f(0)=0$，则

$$
\sum_{k=1}^{n}f(k)=\sum_{k=0}^{n}f(k).
$$

后一个写法未必更节省计算，却可能让范围、递推和边界更统一。

## 5. 艾弗森括号：把条件写进式子里

对一个命题 $P$，定义

$$
[P]=\begin{cases}
1,&P\text{ 为真},\\
0,&P\text{ 为假}.
\end{cases}
$$

于是有限集合上的条件求和可以写为

```math
\sum_{\substack{k\in K\\P(k)}}a_k
=\sum_{k\in K}a_k[P(k)].
```

例如，统计一个列表中正数的个数，就是 $\sum_k[a_k>0]$；统计正数的总和，则是 $\sum_k a_k[a_k>0]$。前者加的是若干个 $0$ 或 $1$，后者加的是被筛选的数值。

两个常用关系是

$$
[P\text{ 且 }Q]=[P][Q],
$$

$$
[P\text{ 或 }Q]=[P]+[Q]-[P][Q].
$$

第二个式子减去重复计数的交集。不能把“或”直接当成两个指示值相加，因为两个命题同时成立时，后者会得到 $2$。

原书还有一个需要留心的约定：条件不成立时，整个被屏蔽的项按零处理，即使其中另一个因子在该处没有定义。这是一种**记号约定**，不能机械翻译成程序里的乘法。例如数学中可以约定 $[k\ne0]/k$ 在 $k=0$ 时为零，但 Python 的 `False / 0` 仍会报错。

## 6. 用代码检查“加了哪些项”

```python
from fractions import Fraction

odd_squares = sum(k * k for k in range(1, 13) if k % 2 == 1)
assert odd_squares == 286

for n in range(11):
    original = sum(k * k for k in range(2, n + 2))
    shifted = sum((j + 2) ** 2 for j in range(n))
    assert original == shifted

values = [-5, 0, 3, 8, -2]
assert sum(x > 0 for x in values) == 2
assert sum(x for x in values if x > 0) == 11

# 先筛选，再计算倒数；不让无定义的项进入求值。
reciprocal_sum = sum(
    (Fraction(1, k) for k in range(-4, 5) if k > 0),
    Fraction(0),
)
assert reciprocal_sum == Fraction(25, 12)
assert sum([]) == 0
print(odd_squares, reciprocal_sum)
```

这里 `range(a, b)` 不包含右端点 $b$，而数学记号 $a\le k\le b$ 包含右端点。将公式译成程序时，需要再次检查这一处边界。

## 7. 自测

**$\sum_{k=3}^{7}1$ 是多少？** 是 $5$，因为指标为 $3,4,5,6,7$。

**$\sum_{k=1}^{n}a_k$ 中的 $k$ 能换成 $n$ 吗？** 不能直接这样改，$`n`$ 已经是上界参数，会发生名字冲突。

**$[P]+[Q]$ 什么时候等于 $[P\text{ 或 }Q]$？** 当 $P,Q$ 不可能同时为真时。

本节最有用的习惯是：每次变换求和号，先写出指标集合，再检查项是否遗漏或重复。记号写准确，往往比提前背下更多求和公式更省事。

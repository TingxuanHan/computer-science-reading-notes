# 【具体数学 Concrete Mathematics】2.1.4 多重和式

> 对应《具体数学：计算机科学基础（第 2 版）》第 2 章 §2.4，书内第 28—35 页。本文沿用专栏三级编号，以下指标集合均有限。

二重求和可以看成对一个表格中的格子求和。真正需要记住的是**选中了哪些格子**。先按行、先按列，或者按对角线遍历，只要不漏项、不重复，就在计算同一件事。

## 1. 先认清指标区域

矩形区域中的两个指标相互独立：

$$
\sum_{j=1}^{m}\sum_{k=1}^{n}a_{j,k}
=\sum_{k=1}^{n}\sum_{j=1}^{m}a_{j,k}.
$$

若通项又能分离为 $a_jb_k$，则

$$
\sum_{j=1}^{m}\sum_{k=1}^{n}a_jb_k
=\left(\sum_{j=1}^{m}a_j\right)
 \left(\sum_{k=1}^{n}b_k\right).
$$

这里能拆成乘积，有两个理由：通项能分离，范围也相互独立。只有通项分离而范围相互依赖，还不够。

例如

$$
\sum_{j=1}^{n}\sum_{k=1}^{j}a_jb_k
$$

覆盖的是三角形区域 $1\le k\le j\le n$，不能直接写成两个完整单和的乘积。

## 2. 换序时要重新解边界

把三角区域完整写出：

$$
1\le k\le j\le n.
$$

若先选 $j$，则 $1\le j\le n$，随后 $1\le k\le j$。若先选 $k$，则 $1\le k\le n$，随后 $k\le j\le n$。因此

$$
\boxed{\sum_{j=1}^{n}\sum_{k=1}^{j}f(j,k)
=\sum_{k=1}^{n}\sum_{j=k}^{n}f(j,k).}
$$

以 $n=3$ 为例，原区域的六个点是

```text
(1,1)
(2,1) (2,2)
(3,1) (3,2) (3,3)
```

换序只是按第二个坐标把它们重新分组。不能把两个求和号交换后仍保留原来的上下限，否则有些边界会引用尚未选定的变量。

例如取 $f(j,k)=2j+k$，逐行求和为

$$
3+(5+6)+(7+8+9)=38.
$$

逐列求和为 $(3+5+7)+(6+8)+9$，结果仍是 $38$。

## 3. 利用对称性，但别忘了对角线

考虑

$$
U=\sum_{1\le j\le k\le n}a_ja_k.
$$

完整的 $n\times n$ 表格关于对角线对称。上三角加下三角覆盖所有格子，但主对角线被算了两次，所以

$$
2U=\sum_{j=1}^{n}\sum_{k=1}^{n}a_ja_k
+\sum_{k=1}^{n}a_k^2.
$$

得到

$$
\boxed{U=\frac12\left[
\left(\sum_{k=1}^{n}a_k\right)^2+\sum_{k=1}^{n}a_k^2
\right].}
$$

若只要严格上三角 $j<k$，则应减去对角线：

$$
\sum_{1\le j<k\le n}a_ja_k
=\frac12\left[
\left(\sum_{k=1}^{n}a_k\right)^2-\sum_{k=1}^{n}a_k^2
\right].
$$

“大约是一半”必须落实为“全体的一半，再加减对角线修正”。

## 4. 从二重和得到一个不等式

展开并整理下面这个对称和，可得

$$
\boxed{\sum_{1\le j<k\le n}(a_k-a_j)(b_k-b_j)
=n\sum_{k=1}^{n}a_kb_k
-\left(\sum_{k=1}^{n}a_k\right)
 \left(\sum_{k=1}^{n}b_k\right).}
$$

一种验证方式是先对所有 $(j,k)$ 求和。交换 $j,k$ 后通项不变，对角线又等于零，因此全体和是严格上三角和的两倍；展开四项后，两个交叉项能分别拆成乘积。

当两个实数序列都单调非减时，每一项 $(a_k-a_j)(b_k-b_j)$ 非负，因而

$$
\left(\sum a_k\right)\left(\sum b_k\right)
\le n\sum a_kb_k.
$$

若一个非减、另一个非增，则不等号反向。这就是切比雪夫单调不等式。这里只需要同向或反向的单调性，并不要求所有元素都是正数。

## 5. 换元不是一一对应时，需要计数重数

设 $f:J\to K$，但 $f$ 不一定是双射。正确的一般公式是

```math
\sum_{j\in J}a_{f(j)}
=\sum_{k\in K}a_k\,\#\{j\in J:f(j)=k\}.
```

右边的系数记录每个值被命中了几次。

例如 $`J=\{-2,-1,0,1,2\}`$、$`f(j)=|j|`$，那么

$$
\sum_{j=-2}^{2}a_{|j|}=a_0+2a_1+2a_2.
$$

若把它直接改成 $\sum_{k=0}^{2}a_k$，就漏掉了两项。所谓指标替换是否合法，最终仍要回到“每个目标项出现几次”。

## 6. 按距离求和，比按行或列更容易

考虑书中这个和式：

$$
S_n=\sum_{1\le j<k\le n}\frac1{k-j}.
$$

通项只与距离 $d=k-j$ 有关。固定 $d$ 后，合法的指标对是

$$
(1,1+d),(2,2+d),\ldots,(n-d,n),
$$

共有 $n-d$ 对。因此

$$
\begin{aligned}
S_n&=\sum_{d=1}^{n-1}\frac{n-d}{d}\\
&=nH_{n-1}-(n-1)\\
&=\boxed{nH_n-n}\qquad(n\ge1).
\end{aligned}
$$

若先固定 $k$，内和则等于 $H_{k-1}$，所以顺便得到

$$
\boxed{\sum_{k=0}^{n-1}H_k=nH_n-n,}
$$

其中 $H_0=0$。原来显得复杂的“调和数之和”，通过更换遍历方向变成了一个简单计数。

## 7. 用枚举核对区域与恒等式

```python
from fractions import Fraction

def harmonic(n):
    return sum((Fraction(1, k) for k in range(1, n + 1)), Fraction(0))

for n in range(1, 31):
    rows = sum(2 * j + k for j in range(1, n + 1)
               for k in range(1, j + 1))
    cols = sum(2 * j + k for k in range(1, n + 1)
               for j in range(k, n + 1))
    assert rows == cols == n * (n + 1) * (5 * n + 4) // 6

    direct = sum((Fraction(1, k - j)
                  for j in range(1, n + 1)
                  for k in range(j + 1, n + 1)), Fraction(0))
    assert direct == n * harmonic(n) - n

a = [-3, 1, 4]
b = [-2, 2, 9]
pair_sum = sum((a[k] - a[j]) * (b[k] - b[j])
               for j in range(3) for k in range(j + 1, 3))
assert pair_sum == 3 * sum(x * y for x, y in zip(a, b)) - sum(a) * sum(b)
assert pair_sum >= 0
print(rows, direct)
```

**自测：$`\sum_{j=1}^{n}\sum_{k=1}^{j}1`$ 有多少项？** 是 $n(n+1)/2$，不是 $n^2$。

**自测：为什么 $a_ja_k$ 的上三角和不能直接取完整和的一半？** 因为主对角线只在原表格中出现一次，却同时属于上、下两个三角区域。

**自测：看到 $f(k-j)$ 时可以先试什么？** 令 $d=k-j$，按相同距离重新分组，并计算每个距离对应多少个指标对。

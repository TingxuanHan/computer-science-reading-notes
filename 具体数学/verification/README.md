# 程序验证

这里保存九章 57 篇章节笔记的验证程序，按当前章节目录读取文件。[结语](../10-结语.md)中的排列枚举示例可复制为 Python 文件单独运行；它不计入九章验证报告的篇数。

## 运行

使用 Python 3.10 或更新版本，无须安装第三方包。在仓库根目录执行：

```sh
python 具体数学/verification/verify_all.py
```

也可以只运行一章，例如：

```sh
python 具体数学/verification/verify_chapter8.py
```

程序根据脚本所在位置寻找笔记，不依赖当前工作目录。运行时会执行笔记中的 Python 代码，并将结果写入本目录的 `chapterN-report.json`；完整运行还会生成 `summary.json`，记录北京时间、各章执行状态和笔记篇数。

## 检查范围

| 章节 | 检查内容 |
| --- | --- |
| 第 1 章 | 汉诺塔合法移动与最短路、直线区域数、约瑟夫问题及成套方法 |
| 第 2 章 | 求和、递归、多重和式、有限微积分与无限和式中的有限检查 |
| 第 3 章 | 底与顶、递归式、模运算与取整和式 |
| 第 4 章 | 整除、素数、阶乘因子、互素、同余和数论函数 |
| 第 5 章 | 二项式恒等式、生成函数、超几何变换与机械求和证书 |
| 第 6 章 | 斯特林数、欧拉数、调和数、伯努利数、斐波那契数与连项式 |
| 第 7 章 | 生成函数系数、卷积、指数生成函数和狄利克雷卷积 |
| 第 8 章 | 离散概率、均值方差、概率生成函数、模式等待与散列 |
| 第 9 章 | 渐近式示例、欧拉求和、调和数与阶乘余项等有限高精度检查 |

这些检查用于复现示例和发现边界错误。有限测试不能替代一般性证明，也不能证明无限级数收敛或渐近极限。

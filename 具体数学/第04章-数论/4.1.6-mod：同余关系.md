# 【具体数学 Concrete Mathematics】4.1.6 mod：同余关系

> 对应《具体数学：计算机科学基础（第 2 版）》第 4 章 §4.6，书内第 103—105 页。本文沿用专栏三级编号。

同余让我们只保留与某个模数有关的信息。加法、减法、乘法都可以在这个世界里继续使用，最容易出错的步骤却是看似普通的“约掉同一个因子”。

## 1. 余数是一种值，同余是一种关系

本文限定整数 $a,b$ 和正整数模数 $m$。定义

$$
\boxed{a\equiv b\pmod m\quad\Longleftrightarrow\quad m\mid(a-b).}
$$

等价地，$a\bmod m=b\bmod m$。例如

$$
17\bmod5=2,\qquad17\equiv-3\pmod5.
$$

前一式在计算一个余数，后一式表示两个整数相差 $5$ 的整数倍。这里允许用负数作为同余代表；如果需要标准余数，再把它化到 $0,\ldots,m-1$。

原书还讨论了更一般的 mod 约定。本文选择正整数模，是为了让整除、逆元和代码中的 `%` 始终处在同一个范围内。

## 2. 哪些代数运算可以保留？

同余满足自反、对称与传递性质。如果
$a\equiv b\pmod m$、$c\equiv d\pmod m$，则

$$
a+c\equiv b+d,\qquad a-c\equiv b-d,\qquad ac\equiv bd\pmod m.
$$

乘法的证明可以写成

$$
ac-bd=(a-b)c+b(c-d).
$$

右边两项都能被 $m$ 整除。因此整系数多项式代入同余的整数，结果仍同余；尤其对非负整数 $k$，有 $a^k\equiv b^k\pmod m$。

例如 $2\equiv-1\pmod3$，于是 $2^k\equiv(-1)^k\pmod3$，立刻知道 $3\mid(2^k-1)$ 当且仅当 $k$ 为偶数。

## 3. 为什么同余式不能随意约分？

看这个反例：

$$
2\times1\equiv2\times4\pmod6,
$$

因为两边之差为 $-6$；但 $1\not\equiv4\pmod6$。如果把公共因子 $2$ 约掉却不改变模，就得到了错误结论。

正确的一般规则是：对整数 $c$，令 $g=\gcd(c,m)$，则

$$
\boxed{ca\equiv cb\pmod m
\quad\Longleftrightarrow\quad
a\equiv b\pmod{m/g}.}
$$

证明：写出 $c=gc'$、$m=gm'$，其中 $\gcd(c',m')=1$。原式等价于 $m'\mid c'(a-b)$，利用互素条件可以消去 $c'$，得到 $m'\mid a-b$。

在刚才的例子中，约去 $2$ 后得到的是 $1\equiv4\pmod3$。

## 4. 模逆元就是合法除法的依据

若 $\gcd(c,m)=1$，贝祖等式给出 $cu+mv=1$，所以

$$
cu\equiv1\pmod m.
$$

$u$ 称为 $c$ 的模逆元。给同余式两边乘以 $u$，就能在不改变模的情况下消去 $c$。

反过来，若逆元存在，则 $cu-mk=1$，$c,m$ 的任何公因子都必须整除 $1$。因此

$$
\boxed{c\text{ 在模 }m\text{ 下可逆}
\quad\Longleftrightarrow\quad\gcd(c,m)=1.}
$$

例如 $3^{-1}\equiv5\pmod7$，因为 $3\times5=15\equiv1\pmod7$。它表示模意义下的乘法逆元，不是把实数 $1/3$ 取余。

## 5. 一次同余方程有几个解？

考虑 $ax\equiv b\pmod m$，令 $g=\gcd(a,m)$。

如果 $g\nmid b$，没有解，因为 $ax-mk$ 总是 $g$ 的倍数。若 $g\mid b$，同时除以 $g$：

$$
\frac agx\equiv\frac bg\pmod{m/g}.
$$

约化后的系数与模互素，所以模 $m/g$ 下有唯一解 $x_0$。回到模 $m$，则有 $g$ 个不同余的解：

$$
x=x_0+t\frac mg,\qquad t=0,1,\ldots,g-1.
$$

例如 $6x\equiv9\pmod{15}$，约化为 $2x\equiv3\pmod5$，故 $x\equiv4\pmod5$。模 $15$ 下三个解为 $4,9,14$。

## 6. 合并模数用 lcm，不能总用乘积

对正整数 $m,n$，

$$
\boxed{
a\equiv b\pmod m\text{ 且 }a\equiv b\pmod n
\quad\Longleftrightarrow\quad
a\equiv b\pmod{\operatorname{lcm}(m,n)}.
}
$$

因为 $a-b$ 同时是 $m,n$ 的倍数，等价于它是最小公倍数的倍数。

若 $m,n$ 互素，lcm 才等于 $mn$。例如模 $4$ 与模 $25$ 的信息可以合并成模 $100$；模 $12$ 与模 $18$ 则合并成模 $36$，不能直接写成模 $216$。

## 7. Python：把公式得到的解与穷举比较

```python
from math import gcd

def linear_congruence(a, b, m):
    if m <= 0:
        raise ValueError("模数必须为正整数")
    g = gcd(a, m)
    if b % g:
        return []
    reduced_mod = m // g
    if reduced_mod == 1:
        x0 = 0
    else:
        inverse = pow(a // g, -1, reduced_mod)
        x0 = ((b // g) * inverse) % reduced_mod
    return [x0 + t * reduced_mod for t in range(g)]

for m in range(1, 31):
    for a in range(-8, 9):
        for b in range(-8, 9):
            expected = [x for x in range(m) if (a * x - b) % m == 0]
            assert linear_congruence(a, b, m) == expected

assert linear_congruence(6, 9, 15) == [4, 9, 14]
assert linear_congruence(6, 8, 15) == []
print(linear_congruence(6, 9, 15))
```

代码在约化模为 $1$ 时单独处理，也覆盖了 $a=0$ 的退化情况。`pow(a, -1, m)` 的用法要求支持模逆元的 Python 版本；这里使用 Python 3.8 及以上。

## 8. 自测

**什么时候能约分而不改模？** 被约掉的因子必须与模互素。

**$ax\equiv b\pmod m$ 有解就一定只有一个解吗？** 模 $m$ 下的解数是 $\gcd(a,m)$；仅在互素时唯一。

**模 $m$ 下唯一的解，是唯一一个整数吗？** 不是，它表示唯一的剩余类，仍包含相差 $m$ 的所有整数。

# 【具体数学 Concrete Mathematics】4.1.4 阶乘的因子

> 对应《具体数学：计算机科学基础（第 2 版）》第 4 章 §4.4，书内第 93—96 页。本文沿用专栏三级编号。

想知道 $100!$ 的末尾有多少个零，不必真的把 $100!$ 算出来。只需要知道它包含多少个因子 $2$ 和 $5$。本节把巨大乘积里的素因子计数，变成一个很短的取整和式。

## 1. 阶乘很大，但我们未必需要它的全部数字

对非负整数 $n$，

$$
n!=\prod_{k=1}^n k,\qquad0!=1.
$$

对 $n\ge1$，正着和倒着各写一遍，得到

$$
(n!)^2=\prod_{k=1}^n k(n+1-k).
$$

由 $n\le k(n+1-k)\le(n+1)^2/4$，可得

$$
n^{n/2}\le n!\le\left(\frac{n+1}{2}\right)^n.
$$

这已经说明阶乘增长非常快。原书还介绍了斯特林近似，但本节的整除问题需要精确指数，而不是阶乘大小的近似值。

## 2. 不要只数一遍 $p$ 的倍数

记 $v_p(n!)$ 为素数 $p$ 在 $n!$ 中的指数。以 $p=2,n=10$ 为例：

| 被计数的额外因子 | 对应的数 | 贡献 |
|---|---|---:|
| 第一层 $2$ | $2,4,6,8,10$ | $5$ |
| 第二层 $2$ | $4,8$ | $2$ |
| 第三层 $2$ | $8$ | $1$ |

所以 $v_2(10!)=5+2+1=8$。只数偶数会漏掉 $4$ 的第二个 $2$，以及 $8$ 的第二、第三个 $2$。

一般地，每个能被 $p^j$ 整除的数，都在第 $j$ 层贡献一个 $p$。交换“先遍历整数”与“先遍历层数”的求和次序：

$$
\begin{aligned}
v_p(n!)
&=\sum_{k=1}^n v_p(k)\\
&=\sum_{k=1}^n\sum_{j\ge1}[p^j\mid k]\\
&=\boxed{\sum_{j\ge1}\left\lfloor\frac{n}{p^j}\right\rfloor}.
\end{aligned}
$$

这是勒让德公式。当 $p^j>n$ 时，后面的项都是零，因此这个看似无限的和实际是有限和。$n=0$ 时也给出 $0$，与 $0!=1$ 一致。

## 3. 二进制里藏着另一种表达

写出 $n$ 的二进制展开：

$$
n=\sum_{i\ge0}b_i2^i,\qquad b_i\in\{0,1\}.
$$

处于第 $i$ 位的一个 $1$，对 $n$ 贡献 $2^i$，对取整和则贡献

$$
2^{i-1}+2^{i-2}+\cdots+1=2^i-1.
$$

所以若 $s_2(n)$ 为二进制中 $1$ 的个数，就有

$$
\boxed{v_2(n!)=n-s_2(n).}
$$

例如 $100=(1100100)_2$ 有三个 $1$，因此 $v_2(100!)=97$。

同样的推导可以推广到素数 $p$ 进制。设 $s_p(n)$ 为各位数字之和，则

$$
\boxed{v_p(n!)=\frac{n-s_p(n)}{p-1}.}
$$

这是对原书二进制公式的自然延伸：第 $i$ 位数字 $a_i$ 的贡献是 $a_i(p^i-1)/(p-1)$。这里仍要求 $p$ 为素数，才能将结果解释成素因子指数。

## 4. 末尾零：由最缺少的因子决定

十进制的一个末尾零对应一个因子 $10=2\times5$。因此

$$
Z_{10}(n!)=\min\{v_2(n!),v_5(n!)\}=v_5(n!).
$$

最后一个等号成立，是因为取整和中每一项 $\lfloor n/2^j\rfloor$ 都不小于 $\lfloor n/5^j\rfloor$。

例如

$$
Z_{10}(100!)=\left\lfloor\frac{100}{5}\right\rfloor
+\left\lfloor\frac{100}{25}\right\rfloor=20+4=24.
$$

若进制为 $B=\prod_i p_i^{a_i}$，一个末尾零要消耗完整的一份 $B$，所以

$$
\boxed{Z_B(n!)=\min_i\left\lfloor\frac{v_{p_i}(n!)}{a_i}\right\rfloor.}
$$

例如 $12=2^2\times3$，$10!$ 在十二进制下有
$\min(\lfloor8/2\rfloor,4)=4$ 个末尾零。不能把 $B=12$ 直接代入勒让德公式当作素数。

## 5. 阶乘商与二项式系数

素因子指数把乘法变成加法，也把整除情况下的除法变成减法。对 $0\le k\le n$，

$$
v_p\binom nk=v_p(n!)-v_p(k!)-v_p((n-k)!).
$$

例如 $\binom{10}{3}=120$，其 $2$ 的指数为 $8-1-4=3$。这个公式不要求先构造大阶乘，后续研究二项式系数时很实用。

## 6. Python：取整和与直接分解除法核对

```python
from math import factorial, comb

def valuation_factorial(n, p):
    # 调用者须保证 p 为素数。
    if n < 0 or p < 2:
        raise ValueError("要求 n >= 0 且 p 为素数")
    result = 0
    while n:
        n //= p
        result += n
    return result

def valuation(x, p):
    count = 0
    while x % p == 0:
        count += 1
        x //= p
    return count

def digit_sum(n, base):
    result = 0
    while n:
        n, digit = divmod(n, base)
        result += digit
    return result

for n in range(101):
    for p in [2, 3, 5, 7, 11]:
        value = valuation_factorial(n, p)
        assert value == valuation(factorial(n), p)
        assert (p - 1) * value == n - digit_sum(n, p)
    assert valuation_factorial(n, 2) == n - n.bit_count()

assert valuation_factorial(100, 5) == 24
assert valuation(comb(10, 3), 2) == 3
print(valuation_factorial(100, 2))  # 97
```

程序用反复整除替代不断构造 $p^j$，既保留公式含义，也使实现更简洁。

## 7. 自测

**为什么 $25$ 会在求 $5$ 的指数时被算两次？** 因为 $25$ 确实含两个因子 $5$，两层计数分别对应它们。

**求末尾零能否只看最小的素因子？** 不能，要比较每种素因子能配成多少份完整的进制基数。

**$v_p(n!)<n/(p-1)$ 对 $n=0$ 也严格成立吗？** 不成立，此时两边都是 $0$；严格不等式需要 $n>0$。

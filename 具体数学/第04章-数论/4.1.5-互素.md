# 【具体数学 Concrete Mathematics】4.1.5 互素

> 对应《具体数学：计算机科学基础（第 2 版）》第 4 章 §4.5，书内第 96—102 页。本文沿用专栏三级编号。

一个分数什么时候已经约到最简？怎样把所有正的最简分数排列成一棵树，而且保证不重不漏？本节用“互素”把这两个问题连接起来。

## 1. 互素与素数是不同概念

若 $\gcd(a,b)=1$，则称 $a,b$ 互素。原书记为 $a\perp b$。

$8$ 与 $15$ 都不是素数，但它们互素；$6$ 与 $35$ 也一样。互素描述两个整数之间的关系，不是单个整数的属性。

对不同时为零的整数 $a,b$，令 $g=\gcd(a,b)$，则

$$
\gcd(a/g,b/g)=1.
$$

另一个常用规则是

$$
\boxed{\gcd(k,ab)=1
\quad\Longleftrightarrow\quad
\gcd(k,a)=\gcd(k,b)=1.}
$$

用素因子解释很直接：$k$ 不与 $ab$ 共享任何素因子，等价于它既不与 $a$ 共享，也不与 $b$ 共享。

多个整数的“两两互素”比“整体 gcd 为 $1$”更强。例如 $6,10,15$ 的整体 gcd 是 $1$，但三对数分别有公因子 $2,3,5$。

## 2. 中位分数不是算术平均

给定 $a/b<c/d$，其中分母为正，定义中位分数为

$$
\frac{a+c}{b+d}.
$$

它满足

$$
\frac ab<\frac{a+c}{b+d}<\frac cd.
$$

交叉相乘即可验证；它也可视作以分母为权重的加权平均。但它通常不等于两端的算术平均。例如 $1/3$ 和 $1/2$ 的中位分数是 $2/5$，算术平均则是 $5/12$。

任意两个最简分数的中位分数未必最简。例如 $1/3$ 与 $3/5$ 产生 $4/8$。接下来需要一个更强的相邻条件。

## 3. 行列式为 1，保证新分数最简

设相邻边界满足

$$
bc-ad=1.
$$

如果 $g$ 同时整除 $a+c$ 与 $b+d$，那么它也整除

$$
b(a+c)-a(b+d)=bc-ad=1,
$$

于是 $g=1$。因此中位分数必为最简分数。

插入之后，两组新邻居仍满足同样的条件：

$$
b(a+c)-a(b+d)=1,
$$

$$
(b+d)c-(a+c)d=1.
$$

这个不变量同时解释了“为什么不必再约分”和“为什么可以反复插入”。

## 4. Stern–Brocot 树怎样生成？

从边界 $0/1$ 与 $1/0$ 开始，在每对相邻分数之间插入中位分数。这里 $1/0$ 只充当右侧无穷远的哨兵，不是一个可以按通常除法求值的有理数。

初次插入得到根 $1/1$；再下一轮得到 $1/2$ 与 $2/1$。从根向左或向右分别记作 `L`、`R`，例如

$$
1/1\xrightarrow{L}1/2\xrightarrow{R}2/3
\xrightarrow{R}3/4\xrightarrow{L}5/7.
$$

所以 $5/7$ 的路径为 `LRRL`，根 $1/1$ 对应空路径。

**为什么不会重复？** 每次新分数严格位于当前相邻分数之间，不同区间互不交叠。新插入的值也不可能等于已有边界。

**为什么不会漏掉正有理数？** 设目标为最简分数 $p/q>0$，始终保留包围它的边界 $a/b,c/d$。若还没有命中目标，则

$$
u=bp-aq\ge1,\qquad v=cq-dp\ge1.
$$

利用 $bc-ad=1$，可验证

$$
p=av+cu,\qquad q=bv+du.
$$

从而 $p+q\ge a+b+c+d$。搜索每前进一步都会用中位分数替换一个边界，使右边严格增加；它却不能一直超过固定的 $p+q$。因此搜索必在有限步命中目标。

## 5. 路径与欧几里得算法

求 $p/q$ 的路径不必真的构造整棵树。对正的互素整数 $p,q$：

- 如果 $p<q$，输出 `L`，并令 $q\leftarrow q-p$；
- 如果 $p>q$，输出 `R`，并令 $p\leftarrow p-q$；
- 当 $p=q$ 时停止，此时它们都为 $1$。

每一步都减小 $p+q$，并保持 gcd。这就是减法形式的欧几里得算法在树上的体现。

以 $5/7$ 为例：

$$
(5,7)\to(5,2)\to(3,2)\to(1,2)\to(1,1),
$$

对应 `LRRL`。如果连续很多步方向相同，可以用整除批量计算长度；下面为便于理解，保留逐步减法。

原书还用矩阵表示边界。令

$$
M=\begin{pmatrix}b&d\\a&c\end{pmatrix},\quad
L=\begin{pmatrix}1&1\\0&1\end{pmatrix},\quad
R=\begin{pmatrix}1&0\\1&1\end{pmatrix}.
$$

从单位矩阵出发，向左一步对应右乘 $L$，向右一步对应右乘 $R$；当前分数为下行和除以上行和。两个操作矩阵的行列式都为 $1$，所以相邻不变量一直保留。

## 6. 法里序列：给分母加一个上限

阶为 $N$ 的法里序列 $F_N$，由 $[0,1]$ 中分母不超过 $N$ 的所有最简分数递增排列而成，包括 $0/1$ 和 $1/1$。例如

$$
F_4=\left(0,\frac14,\frac13,\frac12,\frac23,\frac34,1\right).
$$

从 $F_1$ 开始，只要中位分数的分母不超过 $N$ 就继续插入，可得到 $F_N$。因为新分母是两端分母之和，一旦超过上限，继续深入那个分支也无法得到更小的分母。

法里序列的相邻项仍满足 $bc-ad=1$。要反过来判定两个既约分数是否在给定的 $F_N$ 中相邻，还须检查 $b,d\le N$ 且 $b+d>N$；只检查行列式为 $1$ 不够。

## 7. Python：编码以后再解码

```python
from math import gcd

def encode(p, q):
    if p <= 0 or q <= 0 or gcd(p, q) != 1:
        raise ValueError("要求正的最简分数")
    path = []
    while p != q:
        if p < q:
            path.append("L")
            q -= p
        else:
            path.append("R")
            p -= q
    return "".join(path)

def decode(path):
    a, b, c, d = 0, 1, 1, 0
    for step in path:
        if step == "L":
            c, d = a + c, b + d
        elif step == "R":
            a, b = a + c, b + d
        else:
            raise ValueError("路径只允许 L 和 R")
        assert b * c - a * d == 1
    return a + c, b + d

for p in range(1, 51):
    for q in range(1, 51):
        if gcd(p, q) == 1:
            assert decode(encode(p, q)) == (p, q)

assert encode(1, 1) == ""
assert encode(5, 7) == "LRRL"
print(decode("LRRL"))  # (5, 7)
```

编码使用减法，解码使用边界插入；往返检查把两种描述联系起来，也避免仅验证同一段实现。

## 8. 自测

**两个最简分数的中位分数必然最简吗？** 不必，树中的结论依赖相邻行列式为 $1$。

**为什么使用交叉相乘比较分数？** 它保持整数精确性，避免浮点近似把两个不同的有理数误判为相同。

**树中出现无理数吗？** 每个有限节点都是有理数；原书进一步用无限的左右路径研究无理数近似，不能把有限节点与无限极限混为一谈。

# 【具体数学 Concrete Mathematics】4.1.1 整除性

> 对应《具体数学：计算机科学基础（第 2 版）》第 4 章 §4.1，书内第 85—87 页。本文沿用专栏三级编号。

数论里经常遇到两种问题：一个数能不能被另一个数整除，以及怎样把“所有可能的因子”组织起来。这一节从整除出发，走到欧几里得算法、可以检查的计算证书，以及因子和的换序。

## 1. 先约定符号与边界

本文用常见记号 $d\mid n$ 表示整除：

$$
d\mid n\quad\Longleftrightarrow\quad n=dk\text{，其中 }k\in\mathbb Z.
$$

沿用原书的约定，这里的除数 $d$ 为正整数；原书用向左倾斜的整除符号表达同一关系。因此，$`3\mid12`$、$`3\mid(-12)`$、$`3\mid0`$ 都成立。被除数为零没有问题，因为 $0=3\times0$。

如果 $d\mid a$ 且 $d\mid b$，那么对任意整数 $u,v$，都有

$$
d\mid(ua+vb).
$$

证明只需写出 $a=dr$、$`b=ds`$，得到 $ua+vb=d(ur+vs)$。这个简单事实会贯穿整章。

对不同时为零的整数 $a,b$，最大公因子 $\gcd(a,b)$ 取正值。例如 $\gcd(0,18)=18$。原书不定义 $\gcd(0,0)$；Python 的 `math.gcd(0, 0)` 则约定返回 `0`。下面的代码明确拒绝这个输入，避免把库的约定当成书中的定义。

## 2. 欧几里得算法为什么保留答案？

设 $a\ge0$、$`b>0`$，做带余除法：

```math
a=qb+r,\qquad0\le r\lt b.
```

$a,b$ 的公因子一定整除 $r=a-qb$；反过来，$`b,r`$ 的公因子也整除 $a=qb+r$。两组数的公因子集合完全相同，所以

$$
\boxed{\gcd(a,b)=\gcd(b,a\bmod b).}
$$

例如：

$$
252=2\times105+42,\qquad
105=2\times42+21,\qquad
42=2\times21.
$$

所以 $\gcd(252,105)=21$。每一步的非零余数严格变小，算法必然终止；最后一个非零余数就是答案。

## 3. 把计算过程倒过来，得到贝祖等式

沿着上例回代：

$$
\begin{aligned}
21&=105-2\times42\\
&=105-2(252-2\times105)\\
&=-2\times252+5\times105.
\end{aligned}
$$

一般地，扩展欧几里得算法给出整数 $x,y$，使

$$
\boxed{ax+by=\gcd(a,b).}
$$

$x,y$ 可以为负数，也不一定唯一。它们的价值在于帮助核查答案：如果某程序声称最大公因子是 $g$，并提供 $ax+by=g$，只要同时检查

$$
g>0,\qquad g\mid a,\qquad g\mid b,
$$

就能确认结果。任何公因子 $d$ 都必须整除 $ax+by=g$，因此不可能比 $g$ 更大。这是一份比重新做完整计算更容易检查的证书。

由此还得到一个比“所有公因子都不超过最大公因子”更强的结论：

$$
\boxed{d\mid a\text{ 且 }d\mid b
\quad\Longleftrightarrow\quad d\mid\gcd(a,b).}
$$

## 4. 对因子求和：配对与换元

当 $n>0$ 时，$`d\mapsto n/d`$ 是正因子集合到自身的双射，因此

$$
\sum_{d\mid n}f(d)=\sum_{d\mid n}f(n/d).
$$

例如 $18$ 的正因子为 $1,2,3,6,9,18$，它们成对出现：$`(1,18)`$、$`(2,9)`$、$`(3,6)`$。完全平方数则有一个自配对的因子，例如 $36$ 中的 $6$；枚举时不能把它重复加入。

更进一步，考虑

$$
\sum_{d\mid n}\sum_{k\mid d}F(k,d).
$$

原来的范围是 $k\mid d\mid n$。令 $d=k\ell$，就得到

$$
\boxed{
\sum_{d\mid n}\sum_{k\mid d}F(k,d)
=\sum_{k\mid n}\sum_{\ell\mid n/k}F(k,k\ell).
}
$$

这和第二章的二重和换序完全一样：先确定被计数的对象，再改写同一个指标集合。它会在后面的莫比乌斯反演中再次出现。

## 5. Python：返回答案，也返回证书

```python
from math import gcd, isqrt

def extended_gcd(a, b):
    if a == 0 and b == 0:
        raise ValueError("本例不定义 gcd(0, 0)")
    old_r, r = abs(a), abs(b)
    old_x, x = 1, 0
    old_y, y = 0, 1
    while r:
        q = old_r // r
        old_r, r = r, old_r - q * r
        old_x, x = x, old_x - q * x
        old_y, y = y, old_y - q * y
    return old_r, old_x * (-1 if a < 0 else 1), old_y * (-1 if b < 0 else 1)

def divisors(n):
    if n <= 0:
        raise ValueError("n 必须为正整数")
    result = []
    for d in range(1, isqrt(n) + 1):
        if n % d == 0:
            result.append(d)
            if d * d != n:
                result.append(n // d)
    return sorted(result)

for a in range(-30, 31):
    for b in range(-30, 31):
        if a == b == 0:
            continue
        g, x, y = extended_gcd(a, b)
        assert g == gcd(a, b) and a * x + b * y == g
        assert a % g == b % g == 0

assert divisors(36) == [1, 2, 3, 4, 6, 9, 12, 18, 36]
print(extended_gcd(252, 105))  # (21, -2, 5)
```

输入范围的枚举用于发现程序错误，一般性结论仍由上面的公因子集合和回代论证保证。

## 6. 自测

**只给出 $ax+by=g$，就能证明 $g$ 是最大公因子吗？** 还不够，还要确认 $g>0$ 且 $g$ 同时整除 $a,b$。

**为什么因子和中的 $n$ 要取正数？** 本节需要一个有限的正因子集合；$`0`$ 的正因子有无穷多个。

**回代得到负系数是错误吗？** 不是，整数线性组合本来就允许负系数。

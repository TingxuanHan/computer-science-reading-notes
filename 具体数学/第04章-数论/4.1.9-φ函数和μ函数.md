# 【具体数学 Concrete Mathematics】4.1.9 φ函数和μ函数

> 对应《具体数学：计算机科学基础（第 2 版）》第 4 章 §4.9，书内第 110—119 页正文部分。本文沿用专栏三级编号。

本章最后一节把此前的工具汇合起来：互素给出欧拉函数，因子和引出莫比乌斯反演，gcd 又决定圆形项链在旋转下的重复方式。两个看起来抽象的函数，最终都服务于具体的计数问题。

## 1. φ 函数数的是什么？

对正整数 $n$，欧拉函数定义为

$$
\varphi(n)=\#\{0\le a<n:\gcd(a,n)=1\}.
$$

例如模 $12$ 的互素余数为 $1,5,7,11$，所以 $\varphi(12)=4$。边界 $n=1$ 时，集合包含 $a=0$，因为 $\gcd(0,1)=1$，故 $\varphi(1)=1$。

对素数幂 $p^k$，不互素的数恰好是 $p$ 的倍数，共有 $p^{k-1}$ 个，因此

$$
\varphi(p^k)=p^k-p^{k-1}\qquad(k\ge1).
$$

## 2. 积性来自互素模数的独立组合

若 $\gcd(m,n)=1$，中国剩余定理把模 $mn$ 的余数与模 $m,n$ 的余数对一一对应。一个数与 $mn$ 互素，当且仅当它在两个分量中都互素，所以

$$
\varphi(mn)=\varphi(m)\varphi(n).
$$

满足 $f(1)=1$，且仅在 $\gcd(m,n)=1$ 时要求上述乘法规则的函数，称为积性函数。不能漏掉互素条件，例如

$$
\varphi(4)=2\ne\varphi(2)\varphi(2)=1.
$$

把整数分成互素的素数幂，得到

$$
\boxed{\varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right).}
$$

乘积只遍历不同的素因子。以 $n=360=2^3 3^2 5$ 为例，

$$
\varphi(360)=360\left(1-\frac12\right)
\left(1-\frac13\right)\left(1-\frac15\right)=96.
$$

更一般地，若 $g(n)=\sum_{d\mid n}f(d)$，则 $f$ 积性当且仅当 $g$ 积性。正向来自互素乘积的每个因子都唯一拆成两个因子的乘积；反向可用 $f(n)=g(n)-\sum_{d\mid n,d<n}f(d)$ 归纳。这解释了为什么因子求和能保留整章反复出现的乘法结构。

## 3. 欧拉定理：费马小定理的推广

若 $n\ge2$ 且 $\gcd(a,n)=1$，乘以 $a$ 会把所有与 $n$ 互素的余数重新排列。把这 $\varphi(n)$ 个数相乘后，再约掉它们的乘积，得到

$$
\boxed{a^{\varphi(n)}\equiv1\pmod n.}
$$

约分合法，因为这组数以及它们的乘积都与 $n$ 互素。

例如 $\varphi(12)=4$，所有与 $12$ 互素的整数都满足 $a^4\equiv1\pmod{12}$。这个指数保证结果为 $1$，却未必是最小的可用指数；不要把它与乘法阶混同。

## 4. 为什么所有因子的 φ 值相加等于 n？

将 $1,2,\ldots,n$ 按 $g=\gcd(k,n)$ 分组。固定 $g\mid n$，令 $d=n/g$，则 $k=gj$，其中

$$
1\le j\le d,\qquad\gcd(j,d)=1.
$$

这样的 $j$ 有 $\varphi(d)$ 个；$d=1$ 时计入 $j=1$，与 $\varphi(1)=1$ 一致。因此

$$
\boxed{\sum_{d\mid n}\varphi(d)=n.}
$$

例如 $n=12$ 时，$1+1+2+2+2+4=12$。这个和式看起来把 $\varphi$ 的取值混在一起，下一步则要问：能否从混合结果中恢复单个函数值？

## 5. μ 函数负责让多余的因子项抵消

莫比乌斯函数定义为

$$
\mu(n)=
\begin{cases}
1,&n=1,\\
(-1)^r,&n\text{ 是 }r\text{ 个不同素数的乘积},\\
0,&n\text{ 含有某个素数的平方因子}.
\end{cases}
$$

例如 $\mu(6)=1$、$\mu(30)=-1$、$\mu(12)=0$。它也是积性函数，但不是对任意两个整数都满足乘法规则：$\mu(2)^2=1$，而 $\mu(4)=0$。

它最重要的性质为

$$
\boxed{\sum_{d\mid n}\mu(d)=[n=1].}
$$

若 $n>1$ 有 $r$ 个不同素因子，只有由这些素数选子集得到的无平方因子项非零。带符号的总和就是 $(1-1)^r=0$；$n=1$ 时只有 $\mu(1)=1$。

## 6. 莫比乌斯反演为什么有效？

如果

$$
g(n)=\sum_{d\mid n}f(d),
$$

那么

$$
\boxed{f(n)=\sum_{d\mid n}\mu(d)g(n/d).}
$$

把 $g$ 展开，交换同一个有限指标集合的求和次序：

$$
\begin{aligned}
\sum_{d\mid n}\mu(d)g(n/d)
&=\sum_{d\mid n}\mu(d)\sum_{k\mid n/d}f(k)\\
&=\sum_{k\mid n}f(k)\sum_{d\mid n/k}\mu(d)\\
&=\sum_{k\mid n}f(k)[n/k=1]\\
&=f(n).
\end{aligned}
$$

反演不要求 $f,g$ 为积性函数；有限因子和的抵消性质已经足够。反过来，由右式也可恢复 $g(n)=\sum_{d\mid n}f(d)$。

对上一节的 $\sum_{d\mid n}\varphi(d)=n$ 应用反演，就得到

$$
\varphi(n)=\sum_{d\mid n}\mu(d)\frac nd,
$$

它与素因子乘积公式一致。

## 7. 法里序列长度与带取整的反演

定义

$$
\Phi(N)=\sum_{k=1}^{N}\varphi(k),\qquad\Phi(0)=0.
$$

对 $N\ge1$，法里序列 $F_N$ 的长度为 $1+\Phi(N)$：每个分母贡献互素分子的数量，再补齐一个端点。

把 $1\le a\le b\le N$ 按 $\gcd(a,b)$ 分类，可以得到

$$
\sum_{d=1}^{N}\Phi\left(\left\lfloor\frac Nd\right\rfloor\right)
=\frac{N(N+1)}2.
$$

这里每一对 $(a,b)$ 都唯一约化为一对互素整数，再由 gcd 确定放大倍数。

对形如 $G(N)=\sum_{d=1}^N F(\lfloor N/d\rfloor)$ 的有限和，同样可用 $\mu$ 抵消；利用 $\lfloor\lfloor N/d\rfloor/k\rfloor=\lfloor N/(dk)\rfloor$，有

$$
F(N)=\sum_{d=1}^{N}\mu(d)G\left(\left\lfloor\frac Nd\right\rfloor\right).
$$

因此

$$
\boxed{
\Phi(N)=\frac12\sum_{d=1}^{N}\mu(d)
\left\lfloor\frac Nd\right\rfloor
\left(\left\lfloor\frac Nd\right\rfloor+1\right).
}
$$

例如 $\Phi(12)=46$，所以 $F_{12}$ 有 $47$ 个元素。这个式子是精确计数，不是渐近近似。

## 8. 圆形项链：为什么不能直接除以长度？

用 $q\ge1$ 种颜色制作长度 $m\ge1$ 的项链。颜色可以重复使用；旋转后的图案视为相同，镜像不额外合并。

有位置标号时共有 $q^m$ 种串，但不能直接除以 $m$。例如长度 $4$ 的 `AAAA` 旋转后始终不变，`ABAB` 只有两种不同的旋转结果，`AAAB` 则有四种。不同图案的重复次数不同。

考虑所有“被某次旋转保持不变的有标号串”。旋转 $k$ 格会把位置拆成 $\gcd(m,k)$ 个循环，每个循环必须使用同一种颜色，所以固定串数为

$$
q^{\gcd(m,k)}.
$$

为什么将这些固定串数相加再除以 $m$ 就是项链数？一条项链若有 $t$ 个不同的有标号旋转结果，则每个结果恰好被 $m/t$ 次旋转保持不变；它对总和的贡献为 $t(m/t)=m$，恰好相同。

于是项链数为

$$
N(m,q)=\frac1m\sum_{k=0}^{m-1}q^{\gcd(m,k)}.
$$

若按 $d=\gcd(m,k)$ 分组，满足条件的 $k$ 有 $\varphi(m/d)$ 个。换元之后得到

$$
\boxed{N(m,q)=\frac1m\sum_{d\mid m}\varphi(d)q^{m/d}.}
$$

例如

$$
N(4,2)=\frac{2^4+2^2+2\times2}{4}=6.
$$

镜像也视为相同的“手镯”是另一个计数问题，不能直接使用这里的公式。

原书最后还从同余角度解释分子为什么能被 $m$ 整除：先对素数幂证明 $a^{p^j}\equiv a^{p^{j-1}}\pmod{p^j}$，再借助互素分解合并。这里的计数证明已经保证整数性；两种视角分别突出代数结构与重复计数。

## 9. Python：用直接计数检查 φ、μ 与项链公式

```python
from itertools import product
from math import gcd

def factorize(n):
    if n < 1:
        raise ValueError("n 必须为正整数")
    result = {}
    p = 2
    while p * p <= n:
        while n % p == 0:
            result[p] = result.get(p, 0) + 1
            n //= p
        p += 1
    if n > 1:
        result[n] = result.get(n, 0) + 1
    return result

def phi(n):
    answer = n
    for p in factorize(n):
        answer = answer // p * (p - 1)
    return answer

def mu(n):
    factors = factorize(n)
    return 0 if any(e >= 2 for e in factors.values()) else (-1) ** len(factors)

def divisors(n):
    return [d for d in range(1, n + 1) if n % d == 0]

def necklace_formula(m, q):
    numerator = sum(phi(d) * q ** (m // d) for d in divisors(m))
    assert numerator % m == 0
    return numerator // m

def necklace_brute(m, q):
    # 取所有旋转中字典序最小的一个；不加入反射。
    representatives = set()
    for word in product(range(q), repeat=m):
        representatives.add(min(word[k:] + word[:k] for k in range(m)))
    return len(representatives)

for n in range(1, 101):
    ds = divisors(n)
    assert phi(n) == sum(gcd(a, n) == 1 for a in range(n))
    assert sum(phi(d) for d in ds) == n
    assert sum(mu(d) for d in ds) == int(n == 1)
    assert sum(mu(d) * (n // d) for d in ds) == phi(n)
    summatory = sum(phi(k) for k in range(1, n + 1))
    inverted = sum(mu(d) * (n // d) * (n // d + 1) for d in range(1, n + 1))
    assert 2 * summatory == inverted

for m in range(1, 8):
    for q in range(1, 4):
        assert necklace_formula(m, q) == necklace_brute(m, q)

assert phi(360) == 96
assert sum(phi(k) for k in range(1, 13)) == 46
print(necklace_formula(4, 2))  # 6
```

项链部分直接枚举小规模染色并按旋转去重，再与公式比较；并没有用待验证的公式构造预期答案。程序检查有限范围，一般性证明由前面的分类、换序和旋转计数完成。

## 10. 自测

**积性是否意味着 $f(ab)=f(a)f(b)$ 对所有 $a,b$ 都成立？** 不是，它要求 $a,b$ 互素；去掉条件的是更强的完全积性。

**莫比乌斯反演要求原函数积性吗？** 不要求，它适用于一般的因子和关系。

**项链计数中的颜色各只能使用一次吗？** 不是，这里有 $q$ 种可重复使用的颜色，每个位置独立选择一种。

**本章的工具怎样接起来？** 欧几里得算法产生互素证书，互素让同余可约分，让余数可以独立组合；φ 统计可逆余数，μ 则从因子和中恢复原来的计数。

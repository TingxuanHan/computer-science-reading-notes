# 【具体数学 Concrete Mathematics】4.1.7 独立剩余

> 对应《具体数学：计算机科学基础（第 2 版）》第 4 章 §4.7，书内第 105—107 页。本文沿用专栏三级编号。

一个大整数可以拆成关于几个小模数的余数，分别计算，再拼回结果。问题是：这些余数是否会相互矛盾，拼回的数是否唯一，以及“唯一”究竟是在什么范围内？

## 1. 先用模 3 与模 5 看清结构

用

```math
\mathop{\mathrm{Res}}\nolimits(x)=(x\bmod3,\ x\bmod5)
```

表示一个整数。例如 $13\mapsto(1,3)$，$`7\mapsto(1,2)`$。

由于 $3,5$ 互素，两个整数有相同的余数对，当且仅当它们模 $15$ 同余。第一分量有 $3$ 种选择，第二分量有 $5$ 种选择，$`15`$ 个余数对与 $0,\ldots,14$ 恰好一一对应。

这里的“独立”指可以任意选择两个分量，而且加、减、乘可以逐分量计算；它并不是概率论里的独立事件。

例如

$$
13\times7\mapsto(1\times1\bmod3,\ 3\times2\bmod5)=(1,1),
$$

对应模 $15$ 的结果 $1$。这与 $91\bmod15=1$ 一致。

## 2. 如何构造还原公式？

找到两个整数，分别对应余数对 $(1,0)$ 与 $(0,1)$：

$$
10\mapsto(1,0),\qquad6\mapsto(0,1).
$$

于是余数对 $(r,s)$ 可以还原为

$$
\boxed{x\equiv10r+6s\pmod{15}.}
$$

例如 $(1,3)$ 给出 $10+18=28\equiv13\pmod{15}$。

一般地，对两两互素的正整数 $m_1,\ldots,m_r$，令

$$
M=\prod_i m_i,\qquad M_i=M/m_i.
$$

因为 $\gcd(M_i,m_i)=1$，可取逆元 $u_i$，使 $M_i u_i\equiv1\pmod{m_i}$。定义 $E_i=M_i u_i$，则它在第 $i$ 个模下为 $1$，在其他模下为 $0$。

因此，对于给定余数 $r_i$，

$$
\boxed{x\equiv\sum_{i=1}^r r_iM_i u_i\pmod M.}
$$

这就是中国剩余定理的一个构造形式。公式证明了解的存在；若两个解有相同的全部余数，它们之差能被每个 $m_i$ 整除，也就能被 $M$ 整除，证明了模 $M$ 的唯一性。

## 3. 只有余数，还不能恢复任意大的整数

余数只能确定一个剩余类。例如 $13,28,-2$ 在模 $3,5$ 下的表示完全一样。

若事先知道 $0\le x<M$，才能从剩余类中选出唯一整数。更一般地，若已知 $|x|\le B$ 且 $M>2B$，则至多有一个符合范围的整数与这些余数一致。

例如模 $3,5,7$ 时，$`M=105`$。余数 $(1,0,3)$ 的标准代表为 $10$；若另知 $|x|\le50$，就可以确认 $x=10$。如果没有范围约束，$`115`$ 也满足同一组余数。

在程序里，固定宽度整数的乘法可能在取模之前溢出；分别计算余数并不会自动解决这个问题。下面使用 Python 任意精度整数，避免把机器整数溢出混入数学演示。

## 4. 不互素时，分量不能任意选择

例如

$$
x\equiv0\pmod4,\qquad x\equiv1\pmod6
$$

没有解，因为前者要求 $x$ 为偶数，后者要求 $x$ 为奇数。

对两个任意正模数 $m,n$，方程组
$x\equiv a\pmod m$、$`x\equiv b\pmod n`$ 有解，当且仅当

$$
a\equiv b\pmod{\gcd(m,n)}.
$$

存在解时，唯一性是模 $`\mathop{\mathrm{lcm}}\nolimits(m,n)`$。这是一般情形的兼容条件；不能把上一节的互素构造直接套进去。

## 5. 应用：$`x^2\equiv1\pmod M`$ 有几个解？

先把模数拆成不同的素数幂。对奇素数 $p$，

$$
(x-1)(x+1)\equiv0\pmod{p^k}.
$$

两因子相差 $2$，奇素数 $p$ 不会同时整除它们，所以全部 $p^k$ 必须落在其中一项中。故恰有两个根：$`x\equiv\pm1\pmod{p^k}`$。

$2$ 的幂需要单独讨论：

| 模数 | 不同余的根 | 根数 |
|---|---|---:|
| $2$ | $1$ | $1$ |
| $4$ | $1,3$ | $2$ |
| $2^k,\ k\ge3$ | $1,-1,1+2^{k-1},-1+2^{k-1}$ | $4$ |

最后一行来自：$`x`$ 必须为奇数，$`x-1,x+1`$ 中恰有一个只含一个因子 $2$，另一个则必须含至少 $k-1$ 个因子 $2$。

不同素数幂的根可以通过中国剩余定理独立组合，因此总根数是各部分根数的乘积。

例如模 $60=4\times3\times5$ 有 $2\times2\times2=8$ 个根：

$$
1,11,19,29,31,41,49,59.
$$

“平方等于 $1$ 只有正负 $1$”适用于奇素数幂，却不能原样推广到任意合数模。

## 6. Python：构造解并检查唯一性

```python
from itertools import combinations
from math import gcd, prod

def crt(residues, moduli):
    if len(residues) != len(moduli) or not moduli:
        raise ValueError("需要长度相同的非空列表")
    if any(m <= 1 for m in moduli):
        raise ValueError("本例要求每个模数大于 1")
    if any(gcd(a, b) != 1 for a, b in combinations(moduli, 2)):
        raise ValueError("模数必须两两互素")
    total_mod = prod(moduli)
    total = 0
    for residue, modulus in zip(residues, moduli):
        part = total_mod // modulus
        total += residue * part * pow(part, -1, modulus)
    return total % total_mod, total_mod

for moduli in ([3, 5], [4, 9, 5], [5, 7, 11]):
    total_mod = prod(moduli)
    seen = set()
    for x in range(total_mod):
        residues = tuple(x % m for m in moduli)
        seen.add(residues)
        assert crt(residues, moduli) == (x, total_mod)
    assert len(seen) == total_mod

assert crt([1, 0, 3], [3, 5, 7]) == (10, 105)
roots = [x for x in range(60) if (x * x - 1) % 60 == 0]
assert roots == [1, 11, 19, 29, 31, 41, 49, 59]
print(roots)
```

这里主动拒绝不互素的模数，防止代码暗中使用不存在的逆元。`pow` 的模逆元形式使用 Python 3.8 及以上。

## 7. 自测

**余数对 $(1,3)$ 唯一表示 $13$ 吗？** 只在指定模 $15$ 的标准范围后成立；所有 $13+15k$ 都有这个表示。

**各分量相乘之后，可以直接在分量里判断大小吗？** 不行，剩余表示方便加减乘，却不直接保留通常整数的大小顺序。

**恢复过程是否没有成本？** 不是。原书强调，应当在分量中完成足够多的运算，再考虑还原的代价是否值得。

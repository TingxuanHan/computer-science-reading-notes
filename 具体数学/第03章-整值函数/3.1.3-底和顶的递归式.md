# 【具体数学 Concrete Mathematics】3.1.3 底和顶的递归式

> 对应《具体数学：计算机科学基础（第 2 版）》第 3 章 §3.3，书内第 66—68 页。本文沿用专栏三级编号。

规模必须取整数时，递归式里自然会出现底和顶。例如把 $n$ 个对象尽量平均分成两组，规模就是 $\lfloor n/2\rfloor$ 与 $\lceil n/2\rceil$。

这一节记录三个问题：归纳假设不够用时怎么办，平衡拆分怎样影响精确代价，以及约瑟夫问题如何化成一个上取整递归。

## 1. 一个看起来差一点就能证出的不等式

原书给出 Knuth 数递归：

$$
K_0=1,\qquad
K_{n+1}=1+\min\left(2K_{\lfloor n/2\rfloor},
3K_{\lfloor n/3\rfloor}\right),\quad n\ge0.
$$

前几项为

$$
1,3,3,4,7,7,7,9,9,10,13,\ldots
$$

想证明 $K_n\ge n$，自然会尝试强归纳。可若只代入 $K_j\ge j$，就得到

$$
K_{n+1}\ge1+\min\left(2\lfloor n/2\rfloor,
3\lfloor n/3\rfloor\right).
$$

由于 $2\lfloor n/2\rfloor$ 可能比 $n$ 小 1，$`3\lfloor n/3\rfloor`$ 可能比 $n$ 小 2，这个估计无法推出需要的 $n+1$。证明卡住，并不等于命题错误；也可能是归纳假设丢掉了太多余量。

## 2. 把命题加强，反而更容易闭合

这里可以证明更强的结论：

$$
\boxed{K_n\ge n+1\quad(n\ge0).}
$$

初始值 $K_0=1$ 成立。假设对所有 $j\le n$ 都有 $K_j\ge j+1$，那么对 $d=2,3$，

$$
dK_{\lfloor n/d\rfloor}
\ge d\lfloor n/d\rfloor+d
=n-(n\bmod d)+d
\ge n+1.
$$

最后一步只用了 $0\le n\bmod d\le d-1$。两个候选项都至少为 $n+1$，所以

$$
K_{n+1}\ge1+(n+1)=n+2.
$$

归纳完成，当然也推出 $K_n\ge n$。

这里的余量并非装饰：假设中的那个 $+1$，乘上 2 或 3 后，恰好补回取底造成的损失。遇到“只差一个常数”的归纳证明，可以试着寻找在递归中能够传递的更强不变量。

## 3. 平衡拆分与合并排序的精确递归

把 $n$ 个元素分成尽量相等的两半，有

```math
\lfloor n/2\rfloor+\lceil n/2\rceil=n,
\qquad
\lceil n/2\rceil-\lfloor n/2\rfloor\in\{0,1\}.
```

若合并两段有序序列的最坏比较次数为 $n-1$，则平衡合并排序的最坏比较次数满足

$$
C(1)=0,\qquad
C(n)=C(\lfloor n/2\rfloor)+C(\lceil n/2\rceil)+n-1,
\quad n>1.
$$

原书在这里引入递归模型。下面补充它的闭式，帮助观察取整怎样影响精确答案。设

$$
h=\lceil\lg n\rceil,
$$

则

$$
\boxed{C(n)=nh-2^h+1.}
$$

可以从递归树解释。对 $n>1$，每层反复平衡拆分，子问题大小是 $n/2^d$ 的底或顶；因此所有单元素叶子只会在深度 $h-1$ 或 $h$ 出现。

设两个深度的叶子数分别为 $a,b$。显然 $a+b=n$。把深度 $h-1$ 的叶子各展开成两个深度 $h$ 的位置，就有 $2a+b=2^h$，所以

$$
a=2^h-n,\qquad b=2n-2^h.
$$

每个内部节点的代价是“子问题大小减 1”。把所有子问题大小相加，等于每个叶子被祖先计数的次数之和，也就是叶子深度之和；二叉树有 $n-1$ 个内部节点。因此

$$
\begin{aligned}
C(n)&=a(h-1)+bh-(n-1)\\
&=nh-a-n+1\\
&=nh-2^h+1.
\end{aligned}
$$

$n=1$ 时公式直接给出 0。例如 $n=10$，$`h=4`$，得到 $C(10)=25$。只把 $n$ 当成 $2^h$ 来估算，就会漏掉非整幂规模的这部分差异。

## 4. 约瑟夫问题：换一个量来递推

约定：$`n\ge1`$ 个人编号为 $1,\ldots,n$，从 1 开始报数，每数到第 $q$ 个人就移除他，然后从下一人重新计数。这里 $q\ge2$。

第一章已经讨论过 $q=2$。对一般 $q$，原书通过循环重新编号，得到一个适合反向追踪的量 $D$：

$$
\boxed{D_0=1,\qquad
D_{t+1}=\left\lceil\frac q{q-1}D_t\right\rceil.}
$$

在第一次满足 $D_t>(q-1)n$ 时停下，幸存者编号为

$$
\boxed{J_q(n)=qn+1-D_t.}
$$

这里的 $D_t$ 是重新编号后的反向距离，不是剩余人数，也不是正向被删除的人的编号。

## 5. 上取整从哪里来

理解这个递归，可以看一次重新编号的逆变换。给初始位置标上 $1,\ldots,n$；每次报数时，未被删除的人获得下一个新标签，被删除的人跳过。每 $q$ 次报数只有 $q-1$ 次重新编号。

若一个新标签写成

$$
N=n+(q-1)k+r,\qquad 1\le r\le q-1,
$$

它来自旧标签 $qk+r$。故追溯一次的变换为

$$
N\longmapsto N-n+
\left\lfloor\frac{N-n-1}{q-1}\right\rfloor.
$$

最后仅剩一个人时，可以继续给他报数、重新编号，直到第 $q$ 次报数将其移除。这个补充步骤只为确定标签终点：第 $n$ 次删除发生在报数 $qn$，此前共有 $(q-1)n$ 次重新编号，所以最后的幸存者对应标签 $qn$。

从 $N=qn$ 出发逆推，直到回到初始标签范围 $N\le n$。令

$$
D=qn+1-N,
$$

初始值就是 1。代入上面的逆变换并利用整数平移，可得

$$
D\longmapsto D-\left\lfloor\frac{-D}{q-1}\right\rfloor
=D+\left\lceil\frac D{q-1}\right\rceil
=\left\lceil\frac{qD}{q-1}\right\rceil.
$$

$N\le n$ 等价于整数 $D>(q-1)n$，这同时解释了递推式和停止条件。

例如 $n=10,q=3$：

$$
1\to2\to3\to5\to8\to12\to18\to27.
$$

第一次超过 20 的值是 27，所以 $J_3(10)=31-27=4$。当 $q=2$ 时，递归退化成不断乘 2，也就回到了第一章的二进制结构。

## 6. 三个递归的程序检查

```python
from functools import lru_cache

K = [1]
for n in range(1000):
    K.append(1 + min(2 * K[n // 2], 3 * K[n // 3]))
assert K[:11] == [1, 3, 3, 4, 7, 7, 7, 9, 9, 10, 13]
assert all(value >= i + 1 for i, value in enumerate(K))

@lru_cache(None)
def merge_cost(n):
    if n == 1:
        return 0
    return merge_cost(n // 2) + merge_cost((n + 1) // 2) + n - 1

for n in range(1, 501):
    h = (n - 1).bit_length()  # 精确计算 ceil(log2(n))
    assert merge_cost(n) == n * h - 2 ** h + 1

def josephus_by_ceiling(n, q):
    if n < 1 or q < 2:
        raise ValueError("require n >= 1 and q >= 2")
    D = 1
    while D <= (q - 1) * n:
        D = (q * D + q - 2) // (q - 1)
    return q * n + 1 - D

def josephus_by_size(n, q):
    # 常规的零起点递归，返回时转换为从 1 开始的编号。
    j = 0
    for size in range(1, n + 1):
        j = (j + q) % size
    return j + 1

for n in range(1, 101):
    for q in range(2, 13):
        assert josephus_by_ceiling(n, q) == josephus_by_size(n, q)
assert josephus_by_ceiling(10, 3) == 4
print("加强归纳、合并递归与约瑟夫递归检查通过")
```

对于固定 $q$，$`D`$ 至少按比例 $q/(q-1)>1$ 增长，迭代次数为 $O(\log n)$。如果 $q$ 也作为输入增长，就不能把这个比例当作统一常数；这里也没有把任意大整数运算的位复杂度计入。

本节最有用的两个动作是：当归纳估计不足时保留更多余量；当递推中的平移项繁杂时，换成距离或差值。取整没有消失，但它们所在的结构会更清楚。

# 【具体数学 Concrete Mathematics】3.1.5 底和顶的和式

> 对应《具体数学：计算机科学基础（第 2 版）》第 3 章 §3.5，书内第 72—79 页。本文沿用专栏三级编号。

含取整符号的和式不一定要逐项计算。底函数本身就是一种计数：数一数某个数以下有多少个正整数。把这层计数展开，再交换求和顺序，常常能把台阶状表达式变成熟悉的多项式和式。

本节先算平方根取底的和，再说明分数部分分布问题中的转换，最后推导带最大公约数的等差取底和式。

## 1. 把一个底函数展开成一列指示函数

对 $x\ge0$，

$$
\boxed{\lfloor x\rfloor=\sum_{j\ge1}[j\le x].}
$$

右边只有有限个非零项。例如 $x=3.6$，对应 $j=1,2,3$ 的三个 1。

这里必须保留 $x\ge0$。如果直接把负数代入右边，结果是 0，无法表示负的底值。

这个表示有两种计数方向：按输入值，数它达到几层；按层数，数有多少输入值达到了这一层。第二章的交换求和顺序，在这里就变成了切换计数方向。

## 2. 平方根取底的和：按台阶分块

设 $n\ge0$ 为整数，考虑

$$
S(n)=\sum_{k=0}^{n-1}\lfloor\sqrt k\rfloor.
$$

令 $a=\lfloor\sqrt n\rfloor$。值 $\lfloor\sqrt k\rfloor=j$ 的完整区间是

$$
j^2\le k<(j+1)^2,
$$

其中有 $2j+1$ 个整数。因此前面的完整区块与最后一段分别给出

$$
S(n)=\sum_{j=0}^{a-1}j(2j+1)+a(n-a^2).
$$

用整数和、平方和公式整理，得到

$$
\boxed{S(n)=an-\frac{a(a+1)(2a+1)}6,
\qquad a=\lfloor\sqrt n\rfloor.}
$$

注意求和上界是 $n-1$，而 $a$ 定义为 $\lfloor\sqrt n\rfloor$。若 $n=a^2$，最后一段长度为 0，公式仍成立；$`n=0`$ 时是空和，也得到 0。

## 3. 换个计数方向，公式几乎直接出现

由指示函数展开，

$$
\begin{aligned}
S(n)
&=\sum_{k=0}^{n-1}\sum_{j\ge1}[j^2\le k]\\
&=\sum_{j=1}^{a}\sum_{k=0}^{n-1}[j^2\le k]\\
&=\sum_{j=1}^{a}(n-j^2)\\
&=an-\frac{a(a+1)(2a+1)}6.
\end{aligned}
$$

每一层 $j$ 对应区间 $j^2\le k<n$，其中有 $n-j^2$ 个整数。当 $n=a^2$ 时，最高层贡献 0，可以保留在求和里。

例如 $n=10$，$`a=3`$，原和式为

$$
0+1+1+1+2+2+2+2+2+3=16,
$$

闭式也给出 $30-14=16$。这一例子说明：底函数的台阶不一定是障碍，有时它正好暴露了可以重新计数的对象。

## 4. 分数部分的分布：先精确写出误差

原书接着研究无理数 $\alpha$ 的分数部分序列 $`\{k\alpha\}`$。它们在 $[0,1)$ 上均匀分布，指的是固定区间所占的长期比例与区间长度一致；并不是有限的前 $n$ 项恰好等距。

对 $0\le v\le1$，定义

```math
E(\alpha,n,v)=\sum_{k=0}^{n-1}
\bigl([\{k\alpha\}\lt v]-v\bigr).
```

其中第一部分是真实落点数，$`nv`$ 是区间 $[0,v)$ 对应的理想计数。再取

$$
D(\alpha,n)=\sup_{0\le v\le1}|E(\alpha,n,v)|.
$$

要证明均匀分布，可以控制 $D(\alpha,n)/n\to0$。

连接到本章的关键是以下恒等式：

```math
[\{x\}\lt v]=\lfloor x\rfloor-\lfloor x-v\rfloor,
\qquad0\le v\le1.
```

写 $x=m+r$，其中 $0\le r<1$。若 $r<v$，则 $-1\le r-v<0$，右边为 1；若 $r\ge v$，则 $0\le r-v<1$，右边为 0。严格小于号的边界也因此被准确保留下来。

于是误差可以改写成两个取底和式的差：

$$
E(\alpha,n,v)=\sum_{k=0}^{n-1}
\bigl(\lfloor k\alpha\rfloor-\lfloor k\alpha-v\rfloor\bigr)-nv.
$$

原书随后引入另一个整数指标、交换计数方向，将问题变成参数约为 $`\{1/\alpha\}`$、长度约为 $n\alpha$ 的较短和式，再控制边界项。本篇先记录这个转换入口，不展开均匀分布定理的全部估计证明，也不以有限数值实验代替该定理。

## 5. 等差取底和式：答案里为什么出现 gcd

考虑

$$
F(m,n,x)=\sum_{k=0}^{m-1}\left\lfloor\frac{nk+x}{m}\right\rfloor,
$$

其中 $m$ 是正整数，$`n`$ 是整数，$`x`$ 是实数。令

$$
d=\gcd(m,n)>0,
$$

并采用 $\gcd(m,0)=m$。结论是

$$
\boxed{F(m,n,x)=d\left\lfloor\frac xd\right\rfloor
+\frac{(m-1)(n-1)+d-1}{2}.}
$$

与其猜测这个式子，不如观察 $nk$ 除以 $m$ 的余数。记

$$
r_k=nk\bmod m.
$$

由于 $nk-r_k$ 是 $m$ 的整数倍，整数平移给出

$$
\left\lfloor\frac{nk+x}{m}\right\rfloor
=\frac{nk-r_k}{m}+\left\lfloor\frac{x+r_k}{m}\right\rfloor.
$$

这样就把每一项拆成整数商与一个只依赖余数的取底项。

## 6. 余数的种类和重数完成了求和

写 $m=dM,n=dN$，则 $\gcd(M,N)=1$。在 $k=0,\ldots,M-1$ 内，$`Nk\bmod M`$ 两两不同：若两个余数相等，就有 $M\mid N(k_1-k_2)$，由互素性得到 $M\mid k_1-k_2$，只能是同一个下标。

因此原来的 $m=dM$ 个余数中，

$$
0,d,2d,\ldots,m-d
$$

各出现 $d$ 次。这个重数就是最大公约数进入公式的原因。

先算取底部分。利用上一节的 Hermite 恒等式，

$$
\begin{aligned}
\sum_{k=0}^{m-1}\left\lfloor\frac{x+r_k}{m}\right\rfloor
&=d\sum_{j=0}^{M-1}\left\lfloor\frac{x/d+j}{M}\right\rfloor\\
&=d\left\lfloor\frac xd\right\rfloor.
\end{aligned}
$$

再算被拆出的线性部分：

$$
\frac1m\sum_{k=0}^{m-1}nk=\frac{n(m-1)}2,
$$

$$
\frac1m\sum_{k=0}^{m-1}r_k
=\frac dm\sum_{j=0}^{M-1}dj
=\frac{m-d}{2}.
$$

合并以后，

$$
F(m,n,x)=d\left\lfloor\frac xd\right\rfloor
+\frac{n(m-1)-(m-d)}2,
$$

整理便得到上一节的方框公式。

例如 $m=12,n=8,x=7/2$，$`d=4`$，故

$$
F(12,8,7/2)=4\lfloor7/8\rfloor+
\frac{11\cdot7+3}{2}=40.
$$

当 $m,n$ 都为正整数时，闭式关于 $m,n$ 对称，因而

$$
F(m,n,x)=F(n,m,x).
$$

左边与右边的项数不同，逐项很难看出联系；闭式却直接揭示了这个对称性。特别地，若 $x=0$ 且 $\gcd(m,n)=1$，就有

$$
\sum_{k=0}^{m-1}\left\lfloor\frac{nk}{m}\right\rfloor
=\frac{(m-1)(n-1)}2.
$$

若不互素，必须保留 $(d-1)/2$ 的修正，不能直接套用最后这个简式。

## 7. 精确计算与边界验证

```python
from fractions import Fraction
from math import floor, gcd, isqrt

def sqrt_floor_sum(n):
    if n < 0:
        raise ValueError("n must be nonnegative")
    a = isqrt(n)
    return a * n - a * (a + 1) * (2 * a + 1) // 6

running = 0
for n in range(2001):
    assert sqrt_floor_sum(n) == running
    running += isqrt(n)
assert sqrt_floor_sum(10) == 16

def floor_sum_closed(m, n, x):
    if m < 1:
        raise ValueError("m must be positive")
    x = Fraction(x)
    d = gcd(m, n)
    numerator = (m - 1) * (n - 1) + d - 1
    assert numerator % 2 == 0
    return d * floor(x / d) + numerator // 2

def floor_sum_direct(m, n, x):
    x = Fraction(x)
    return sum(floor((n * k + x) / m) for k in range(m))

samples = [Fraction(-7, 3), Fraction(0), Fraction(7, 2), Fraction(9)]
for m in range(1, 26):
    for n in range(-25, 26):
        for x in samples:
            assert floor_sum_closed(m, n, x) == floor_sum_direct(m, n, x)
            if n > 0:
                assert floor_sum_closed(m, n, x) == floor_sum_closed(n, m, x)
assert floor_sum_closed(12, 8, Fraction(7, 2)) == 40

for x in [Fraction(p, 7) for p in range(-20, 21)]:
    for v in [Fraction(j, 5) for j in range(6)]:
        assert (x - floor(x) < v) == floor(x) - floor(x - v)
print("平方根和式、gcd 闭式与指示函数转换检查通过")
```

测试覆盖了空和、平方数边界、负的 $n$、$`n=0`$、互素与不互素，以及分数平移量。它检查实现是否与推导一致；闭式对全部合法输入成立，仍由前面的计数证明保证。

## 8. 第三章回看

这一章的思路可以连成一条线：先用区间定义底和顶，再用它们准确处理整数边界；递归中保留取整损失与补偿；mod 把商和余数分开；最后把取整和式转成层数、余数和重数的计数。

下次遇到 $\sum\lfloor f(k)\rfloor$，可以先问两个具体问题：固定一个整数层高时，哪些 $k$ 会被计入？各项的余数是否形成一个可描述的周期？这两种改写，往往比直接展开原和式更容易继续。

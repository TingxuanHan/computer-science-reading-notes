# 【具体数学 Concrete Mathematics】3.1.2 底和顶的应用

> 对应《具体数学：计算机科学基础（第 2 版）》第 3 章 §3.2，书内第 58—66 页。本文沿用专栏三级编号。

底和顶的用途，往往是把连续的不等式转成离散的计数。本节沿着四类问题展开：一个整数占几位、嵌套取整能否合并、区间里有几个整数，以及两条取整序列怎样恰好覆盖正整数。

## 1. 二进制位数：检查整幂边界

设 $n\ge1$ 是整数。它的二进制表示有 $b$ 位，当且仅当

$$
2^{b-1}\le n<2^b.
$$

因此

$$
\boxed{b=\lfloor\lg n\rfloor+1=\lceil\lg(n+1)\rceil,}
$$

其中 $\lg$ 表示以 2 为底的对数。第二个等式利用了 $n$ 为整数：$n<2^b$ 等价于 $n+1\le2^b$。

容易误写的公式是 $\lceil\lg n\rceil$。它在 $n=8$ 时给出 3，但二进制 `1000` 有 4 位。凡是对数与取整一起出现，都值得检查整幂及其相邻位置。

实际写 Python 时，正整数位数可以直接用 `n.bit_length()`，避免大整数转成浮点数后的边界误差。$n=0$ 不在上述公式的定义域内；字符串 `"0"` 的长度与 `0.bit_length()` 也不是同一套约定。

## 2. 哪些嵌套取整可以去掉

对 $x\ge0$，有

$$
\left\lfloor\sqrt{\lfloor x\rfloor}\right\rfloor
=\lfloor\sqrt x\rfloor.
$$

设右边为整数 $m$，则 $m^2\le x<(m+1)^2$。两端都是整数，所以同样有

$$
m^2\le\lfloor x\rfloor<(m+1)^2.
$$

开平方后再取底，得到的仍是 $m$。

对应的上取整版本也成立：

$$
\left\lceil\sqrt{\lceil x\rceil}\right\rceil
=\lceil\sqrt x\rceil.
$$

若右边为 $m\ge1$，使用 $(m-1)^2<x\le m^2$ 即可证明；$x=0$ 单独检查。

但混合版本不一定成立。例如 $x=17/4$ 时，

$$
\left\lceil\sqrt{\lfloor17/4\rfloor}\right\rceil=2,
\qquad \left\lceil\sqrt{17/4}\right\rceil=3.
$$

更准确地说，这个混合等式恰好在 $m^2<x<m^2+1$（$m=0,1,2,\ldots$）时失效：内层取底先把数拉回平方数，外层取顶就少了一次进位。

另一个常用规则是：对整数 $a$、正整数 $b$，

$$
\left\lfloor\frac{x+a}{b}\right\rfloor
=\left\lfloor\frac{\lfloor x\rfloor+a}{b}\right\rfloor,
\qquad
\left\lceil\frac{x+a}{b}\right\rceil
=\left\lceil\frac{\lceil x\rceil+a}{b}\right\rceil.
$$

以底为例，令结果为 $m$，就把条件转成
$bm-a\le x<b(m+1)-a$。端点为整数，替换成 $\lfloor x\rfloor$ 不改变结论。

于是对正整数 $a,b$，

$$
\left\lfloor\frac{\lfloor x/a\rfloor}{b}\right\rfloor
=\left\lfloor\frac{x}{ab}\right\rfloor.
$$

关键条件是除数为正整数；不能看到两层括号就直接合并。

## 3. 区间里有多少个整数

设 $a\le b$，以下公式统一使用 $\max(0,\cdot)$，以包含空区间的情形。

| 区间 | 其中的整数个数 |
|---|---|
| $[a,b]$ | $\max(0,\lfloor b\rfloor-\lceil a\rceil+1)$ |
| $[a,b)$ | $\max(0,\lceil b\rceil-\lceil a\rceil)$ |
| $(a,b]$ | $\max(0,\lfloor b\rfloor-\lfloor a\rfloor)$ |
| $(a,b)$ | $\max(0,\lceil b\rceil-\lfloor a\rfloor-1)$ |

例如 $(-2,3]$ 中有 $-1,0,1,2,3$ 共 5 个整数；直接用区间长度得到的巧合，不能代替端点分析。再看 $(2,2)$，若漏掉非负截断，最后一行就会错误地算出 $-1$。

推导时只需找出最小和最大允许整数，再用“末项减首项加一”。半开区间特别适合程序下标，也适合下一段的分块。

## 4. 一个立方根整除计数

在 $1\le n\le N$ 中，有多少个整数满足 $\lfloor\sqrt[3]n\rfloor\mid n$？记答案为 $W(N)$，并假设 $N\ge1$。

固定 $k=\lfloor\sqrt[3]n\rfloor$，等价于

$$
k^3\le n<(k+1)^3.
$$

若再要求 $n=km$，则

$$
k^2\le m<k^2+3k+3+\frac1k.
$$

这一完整区块中的整数 $m$ 有

$$
\left\lceil k^2+3k+3+\frac1k\right\rceil-k^2=3k+4
$$

个。这里 $k\ge1$，所以 $\lceil1/k\rceil=1$，包括 $k=1$。

令 $K=\lfloor\sqrt[3]N\rfloor$。前 $K-1$ 个块完整，最后一个块只有 $K^3\le n\le N$，其中的倍数有 $\lfloor N/K\rfloor-K^2+1$ 个。因此

$$
\begin{aligned}
W(N)
&=\sum_{k=1}^{K-1}(3k+4)+\left\lfloor\frac NK\right\rfloor-K^2+1\\
&=\boxed{\left\lfloor\frac NK\right\rfloor+
\frac{K^2+5K-6}{2}}.
\end{aligned}
$$

例如 $N=1000$ 时 $K=10$，得到 $W(1000)=172$。这个推导真正需要留心的是最后一个不完整区块，而不是等差数列的求和。

## 5. 两条序列怎样无重无漏地覆盖整数

考虑 $\alpha>1$ 时的序列

$$
\lfloor\alpha\rfloor,\lfloor2\alpha\rfloor,
\lfloor3\alpha\rfloor,\ldots
$$

原书将这样的序列称为谱。要证明两条谱互补，可以先数每条谱在 $1,\ldots,n$ 中出现多少项，而不必逐个寻找某个整数属于哪条谱。

因为

$$
\lfloor k\alpha\rfloor\le n
\iff k\alpha<n+1,
$$

所以项数为

$$
C_\alpha(n)=\left\lceil\frac{n+1}{\alpha}\right\rceil-1.
$$

设 $\alpha,\beta>1$ 都是无理数，并满足

$$
\frac1\alpha+\frac1\beta=1.
$$

那么 $(n+1)/\alpha$ 与 $(n+1)/\beta$ 都不是整数，其和为整数 $n+1$。它们的顶之和因此是 $n+2$，从而

$$
C_\alpha(n)+C_\beta(n)=n.
$$

对 $n$ 和 $n-1$ 的计数相减，说明整数 $n$ 在两条谱中合计恰好出现一次。这就同时证明了没有遗漏和没有重复。

具体取 $\alpha=\sqrt2$，$\beta=2+\sqrt2$，它们满足上述倒数关系。这是 Beatty 序列互补现象的一个例子。

## 6. 用整数算法验证，而不是浮点开根后强转

```python
from math import isqrt

def icbrt(n):
    """非负整数的立方根下取整，全部使用整数运算。"""
    if n < 0:
        raise ValueError("n must be nonnegative")
    lo, hi = 0, 1
    while hi ** 3 <= n:
        hi *= 2
    while hi - lo > 1:
        mid = (lo + hi) // 2
        if mid ** 3 <= n:
            lo = mid
        else:
            hi = mid
    return lo

def count_divisible(N):
    if N < 1:
        raise ValueError("N must be positive")
    K = icbrt(N)
    return N // K + (K * K + 5 * K - 6) // 2

running = 0
for N in range(1, 1001):
    running += (N % icbrt(N) == 0)
    assert count_divisible(N) == running
assert count_divisible(1000) == 172

# floor(k*sqrt(2)) = isqrt(2*k*k)，避免浮点误差。
limit = 500
A = [isqrt(2 * k * k) for k in range(1, limit + 1)]
B = [2 * k + isqrt(2 * k * k) for k in range(1, limit + 1)]
covered = sorted(v for v in A + B if v <= limit)
assert covered == list(range(1, limit + 1))

for n in range(1, 1000):
    b = n.bit_length()
    assert 2 ** (b - 1) <= n < 2 ** b

print("位数、立方根分块与谱的有限范围检查通过")
```

代码验证了有限范围内的实现。谱覆盖所有正整数的理由，是前面的累计计数证明。

## 7. 这一节的解题入口

遇到取整应用，可以先尝试三件事：把结果等于某个整数的条件写成区间；按取整值不变的范围分块；用累计个数的差，替代逐项判断。

例如位数看整幂区间，立方根整除看立方区块，谱的互补看每个前缀的项数。表面上是不同问题，真正反复使用的都是整数端点与计数范围。

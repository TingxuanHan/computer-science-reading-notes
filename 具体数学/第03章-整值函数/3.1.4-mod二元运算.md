# 【具体数学 Concrete Mathematics】3.1.4 mod：二元运算

> 对应《具体数学：计算机科学基础（第 2 版）》第 3 章 §3.4，书内第 68—72 页。本文沿用专栏三级编号。

熟悉整数除法以后，很容易把 mod 理解为“除完剩下的数”。但遇到负数、实数或不同程序语言时，这句话还不够精确。本节从底函数出发定义 mod，再用它处理平均分组，最后得到一个取整求和恒等式。

## 1. 用底函数给出定义

对实数 $x,y$ 且 $y\ne0$，定义

$$
\boxed{x\bmod y=x-y\left\lfloor\frac xy\right\rfloor.}
$$

若 $y>0$，由 $0\le x/y-\lfloor x/y\rfloor<1$ 得到

```math
0\le x\bmod y\lt y.
```

若 $y<0$，乘法使不等号反向，因此

```math
y\lt x\bmod y\le0.
```

这意味着：非零结果与第二个操作数同号。

| $x$ | $y$ | $\lfloor x/y\rfloor$ | $x\bmod y$ |
|---:|---:|---:|---:|
| $5$ | $3$ | $1$ | $2$ |
| $5$ | $-3$ | $-2$ | $-1$ |
| $-5$ | $3$ | $-2$ | $1$ |
| $-5$ | $-3$ | $1$ | $-2$ |

原书另外约定 $x\bmod0=x$，使部分代数式能够统一处理。**这是书中的数学扩展约定。Python 的 `% 0` 会报错，并不会返回 $x$。** 使用程序时要明确自己采用哪套定义。

## 2. 实数也可以做 mod

例如

$$
\frac{17}{4}\bmod\frac32
=\frac{17}{4}-\frac32\left\lfloor\frac{17}{6}\right\rfloor
=\frac54.
$$

尤其是

```math
x\bmod1=x-\lfloor x\rfloor=\{x\}.
```

上一节的分数部分，原来就是模 1 的结果。

对于 $c\ne0,y\ne0$，由于 $(cx)/(cy)=x/y$，有

$$
\boxed{c(x\bmod y)=(cx)\bmod(cy).}
$$

这个缩放公式对负 $c$ 也成立。如果采用原书的零模数扩展，它还可以延伸到 $c=0$ 或 $y=0$。

不过，mod 不是普通乘法，不能随意交换或结合。例如

$$
7\bmod5=2\ne5=5\bmod7,
$$

$$
(7\bmod5)\bmod3=2,
\qquad7\bmod(5\bmod3)=1.
$$

表达式里有连续多个 mod 时，应把括号写清楚。

## 3. 商和余数给出最均衡的分组

把 $n\ge0$ 个对象依次分成 $m\ge1$ 组，要求各组大小相差至多 1。写成

```math
n=mq+r,\qquad q=\lfloor n/m\rfloor,\qquad r=n\bmod m,
\quad0\le r\lt m.
```

那么应有 $r$ 组各含 $q+1$ 个对象，其余 $m-r$ 组各含 $q$ 个。总数恰好是

$$
r(q+1)+(m-r)q=mq+r=n.
$$

例如 $n=29,m=6$，得到 $q=4,r=5$。若把较大的组放在前面，组大小就是

$$
5,5,5,5,5,4.
$$

这里没有要求 $n\ge m$；对象少于组数时，允许后面的组为空。

## 4. 顺序分配为什么不会越分越歪

一种自然的操作是：每次把剩余对象数除以剩余组数，取顶作为下一组大小。

当 $r>0$ 时，第一组取 $q+1$，剩余

$$
n-(q+1)=q(m-1)+(r-1).
$$

基准大小仍是 $q$，需要多放一个对象的组数由 $r$ 减到 $r-1$。等 $r$ 变成 0，余下各组大小便都是 $q$。这就证明了逐次取顶与前一节的商余数方案一致。

对第 $k$ 组（$`1\le k\le m`$），还可以直接写成

$$
\boxed{s_k=q+[k\le r]=\left\lceil\frac{n-k+1}{m}\right\rceil.}
$$

右端的分母始终是原来的 $m$，它是直接公式，不是逐次分配中“剩余组数”的记号。

第 $k$ 组之前共有

$$
p_k=(k-1)q+\min(k-1,r)
$$

个对象，所以零起点数组的这一组是半开区间 $[p_k,p_k+s_k)$。这套写法能直接用于连续分片，并自动处理空组。

## 5. 从分组得到一个取整恒等式

各组大小相加就是 $n$，于是

$$
\sum_{k=0}^{m-1}\left\lceil\frac{n-k}{m}\right\rceil=n.
$$

虽然分组故事使用 $n\ge0$，代数式对所有整数 $n$ 也成立：仍写 $n=mq+r$，则 $\lceil(r-k)/m\rceil$ 在前 $r$ 项为 1，其余为 0。

对应的底函数形式是

$$
\boxed{\sum_{k=0}^{m-1}\left\lfloor\frac{n+k}{m}\right\rfloor=n,}
\qquad n\in\mathbb Z,\quad m\in\mathbb Z_{>0}.
$$

因为每项为 $q+\lfloor(r+k)/m\rfloor$，后 $r$ 项多出 1，总计仍为 $mq+r$。

再令 $n=\lfloor mx\rfloor$，使用上一节的嵌套取底规则，可得更一般的形式：

$$
\begin{aligned}
\sum_{k=0}^{m-1}\left\lfloor x+\frac{k}{m}\right\rfloor
&=\sum_{k=0}^{m-1}\left\lfloor\frac{\lfloor mx\rfloor+k}{m}\right\rfloor\\
&=\boxed{\lfloor mx\rfloor}.
\end{aligned}
$$

它对任意实数 $x$ 和正整数 $m$ 成立，常称为 Hermite 恒等式。等距平移后的多个台阶，正好合成一个高度放大的台阶。

## 6. 程序实现与精确检查

```python
from fractions import Fraction
from math import floor, ceil

def book_mod(x, y):
    # 明确实现原书的扩展约定，不调用 Python 的 % 0。
    x, y = Fraction(x), Fraction(y)
    if y == 0:
        return x
    return x - y * floor(x / y)

assert book_mod(-5, 3) == 1
assert book_mod(5, -3) == -1
assert book_mod(Fraction(17, 4), Fraction(3, 2)) == Fraction(5, 4)
assert book_mod(7, 0) == 7
for x in range(-12, 13):
    for y in range(-5, 6):
        if y:
            assert book_mod(x, y) == x % y
        for c in (Fraction(-3, 2), Fraction(0), Fraction(5, 3)):
            assert c * book_mod(x, y) == book_mod(c * x, c * y)

def balanced_ranges(n, m):
    if n < 0 or m < 1:
        raise ValueError("require n >= 0 and m >= 1")
    q, r = divmod(n, m)
    start = 0
    result = []
    for k in range(m):
        size = q + (k < r)
        result.append(range(start, start + size))
        start += size
    return result

assert [len(g) for g in balanced_ranges(29, 6)] == [5, 5, 5, 5, 5, 4]
for n in range(61):
    for m in range(1, 11):
        groups = balanced_ranges(n, m)
        assert [v for g in groups for v in g] == list(range(n))
        sizes = [len(g) for g in groups]
        assert max(sizes) - min(sizes) <= 1
        assert sizes == [ceil(Fraction(n - k, m)) for k in range(m)]

for p in range(-30, 31):
    for q in range(1, 8):
        x = Fraction(p, q)
        for m in range(1, 11):
            assert sum(floor(x + Fraction(k, m)) for k in range(m)) == floor(m * x)
print("mod、连续分组与 Hermite 恒等式检查通过")
```

使用负数测试很有必要：只测试正整数，许多不同的余数约定恰好会给出相同结果，无法暴露实现与数学定义的差异。

# 【具体数学 Concrete Mathematics】3.1.1 底和顶

> 对应《具体数学：计算机科学基础（第 2 版）》第 3 章 §3.1，书内第 56—58 页。本文沿用专栏三级编号。

处理计数、数组下标和递归规模时，计算结果经常是实数，答案却必须是整数。向哪个方向取整，决定了边界上的对象究竟算不算进去。

这一节先把两个基本工具说清楚：底函数 $\lfloor x\rfloor$ 和顶函数 $\lceil x\rceil$，通常也叫向下取整与向上取整。

## 1. 定义中的方向，比“去掉小数”更重要

定义为

```math
\lfloor x\rfloor=\max\{n\in\mathbb Z:n\le x\},\qquad
\lceil x\rceil=\min\{n\in\mathbb Z:n\ge x\}.
```

| $x$ | $\lfloor x\rfloor$ | $\lceil x\rceil$ | $x-\lfloor x\rfloor$ |
|---|---:|---:|---:|
| $2.7$ | $2$ | $3$ | $0.7$ |
| $2$ | $2$ | $2$ | $0$ |
| $-2.7$ | $-3$ | $-2$ | $0.3$ |
| $-2$ | $-2$ | $-2$ | $0$ |

尤其要记住 $\lfloor-2.7\rfloor=-3$。沿数轴向左走到整数，与直接去掉小数部分不是一回事。

两种取整都不会把一个本来就是整数的数再推远一步。它们满足

```math
x-1\lt \lfloor x\rfloor\le x\le\lceil x\rceil\lt x+1.
```

用上一章的艾弗森括号，可以把两者的间距写成

$$
\lceil x\rceil-\lfloor x\rfloor=[x\notin\mathbb Z].
$$

因此“顶总比底大 1”要补上条件：$`x`$ 不是整数。

## 2. 把取整翻译成普通不等式

设 $n\in\mathbb Z$，有

```math
\lfloor x\rfloor=n\iff n\le x\lt n+1,
```

```math
\lceil x\rceil=n\iff n-1\lt x\le n.
```

这是证明取整恒等式最稳妥的起点。例如，想证明某个量的底等于 $n$，只需把它夹在 $[n,n+1)$ 中。

比较一个实数与整数时，还可以使用下表。

| 普通不等式 | 等价的取整形式，$`n`$ 为整数 |
|---|---|
| $x<n$ | $\lfloor x\rfloor<n$ |
| $n<x$ | $n<\lceil x\rceil$ |
| $x\le n$ | $\lceil x\rceil\le n$ |
| $n\le x$ | $n\le\lfloor x\rfloor$ |

例如整数 $k$ 满足 $k<x$，最大的可选值是 $\lceil x\rceil-1$，不能一律写成 $\lfloor x\rfloor$：当 $x=5$ 时，前者是 4，后者是 5。

开区间与闭区间的差别，就藏在这个整数端点上。

## 3. 整数平移与符号翻转

对任意整数 $n$，

$$
\lfloor x+n\rfloor=\lfloor x\rfloor+n,\qquad
\lceil x+n\rceil=\lceil x\rceil+n.
$$

证明只需平移区间：若 $m\le x<m+1$，则 $m+n\le x+n<m+n+1$。

但是这里的平移量必须是整数。例如

$$
\lfloor0.6+0.6\rfloor=1\ne0=\lfloor0.6\rfloor+\lfloor0.6\rfloor.
$$

乘法也不能随意移到取整符号外：

$$
\left\lfloor2\cdot\frac12\right\rfloor=1
\ne2\left\lfloor\frac12\right\rfloor=0.
$$

取负数则会交换底和顶：

$$
\boxed{\lfloor-x\rfloor=-\lceil x\rceil,\qquad
\lceil-x\rceil=-\lfloor x\rfloor.}
$$

因为数轴反向以后，“不大于”变成了“不小于”。后面遇到上取整递归时，这组公式可以把它改写成底函数。

## 4. 分数部分，以及加法时的一次进位

定义分数部分

```math
\{x\}=x-\lfloor x\rfloor.
```

于是每个实数都可以分解为

```math
x=\lfloor x\rfloor+\{x\},\qquad 0\le\{x\}<1.
```

负数的分数部分依然非负，例如 $`\{-2.7\}=0.3`$。

把 $x,y$ 都这样拆开，再利用整数平移，就得到

```math
\boxed{\lfloor x+y\rfloor
=\lfloor x\rfloor+\lfloor y\rfloor
+\lfloor\{x\}+\{y\}\rfloor.}
```

最后一项只有两种可能：分数部分之和小于 1 时为 0，否则为 1。它正好是加法中的进位。因此

$$
\lfloor x\rfloor+\lfloor y\rfloor
\le\lfloor x+y\rfloor
\le\lfloor x\rfloor+\lfloor y\rfloor+1.
$$

这比简单记住“底函数不能拆加法”更有用：虽然不能直接拆，却能准确描述拆开以后差多少。

## 5. 用精确有理数检查边界

下面的代码使用 `Fraction`，让测试中的十进制例子保持精确。Python 的 `int` 向零截断，`floor` 和 `ceil` 则分别遵循本节定义。

```python
from fractions import Fraction
from math import floor, ceil

x = Fraction(-27, 10)
assert int(x) == -2
assert floor(x) == -3
assert ceil(x) == -2
assert x - floor(x) == Fraction(3, 10)

values = [Fraction(p, q) for q in range(1, 8)
          for p in range(-20, 21)]
for x in values:
    assert x - 1 < floor(x) <= x <= ceil(x) < x + 1
    assert ceil(x) - floor(x) == (x.denominator != 1)
    assert floor(-x) == -ceil(x)
    for n in range(-4, 5):
        assert floor(x + n) == floor(x) + n
        assert (x < n) == (floor(x) < n)
        assert (n < x) == (n < ceil(x))
        assert (x <= n) == (ceil(x) <= n)
        assert (n <= x) == (n <= floor(x))

for x in values:
    for y in (Fraction(3, 5), Fraction(-8, 3), Fraction(2)):
        carry = floor((x - floor(x)) + (y - floor(y)))
        assert carry in (0, 1)
        assert floor(x + y) == floor(x) + floor(y) + carry

print("底、顶与边界检查通过")
```

这些检查用于发现符号、端点和程序实现中的错误。一般性结论的依据仍然是前面的定义与推导。

## 6. 留给自己的三个小问题

1. $`\{-7/3\}`$ 是多少？答：$`2/3`$，因为 $\lfloor-7/3\rfloor=-3$。
2. $\lceil x\rceil=-\lfloor-x\rfloor$ 对整数 $x$ 也成立吗？答：成立，不需要排除整数。
3. 什么时候 $\lfloor x+y\rfloor=\lfloor x\rfloor+\lfloor y\rfloor$？答：恰好在 $`\{x\}+\{y\}<1`$ 时。

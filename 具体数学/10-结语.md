# 结语：把九章的方法带回算法分析

九章读完，再看一个程序时，可以把问题问得更具体：正在计算哪个操作的次数，输入有什么约束，答案需要精确到什么程度？这些问题决定了该写递归式、做组合计数，还是建立概率模型。

下面用一个短小的例子，把调和数、期望和渐近式接在一起。它也是[第六章调和数笔记](第06章-特殊的数/6.1.3-调和数.md)中概率解释的展开。

## 1. 扫描一次，最大值会刷新多少次

将 $n$ 个互不相同的数均匀随机排列，从左到右扫描，维护当前见过的最大值。每当读到的数比之前所有数都大，就记一次刷新。这里把第一个元素设为当前最大值也计作一次，空序列的刷新次数为零。

记刷新总次数为 $R_n$。对 $n\ge1$，递增排列刷新 $n$ 次，递减排列只刷新一次。平均次数不能只用这两个极端来判断。

对第 $k$ 个位置定义指示变量：

$$
I_k=[\text{第 }k\text{ 个元素是前 }k\text{ 个元素中的最大值}].
$$

于是

$$
R_n=\sum_{k=1}^{n}I_k.
$$

在均匀随机排列中，前 $k$ 个位置具有对称性，其中最大元素落在任一位置的概率都是 $1/k$，因此

$$
\mathbb E[I_k]=\frac1k.
$$

利用期望的线性性，得到精确答案：

$$
\boxed{\mathbb E[R_n]=\sum_{k=1}^{n}\frac1k=H_n.}
$$

这一步只用到了期望可加，不需要先证明这些指示变量独立。若要进一步计算方差，则需要检查它们的联合关系，可以回看[第八章的均值和方差](第08章-离散概率/8.1.2-均值和方差.md)。

### 从精确答案到规模判断

第九章给出了调和数的渐近展开：

$$
H_n=\ln n+\gamma+\frac1{2n}-\frac1{12n^2}+O(n^{-4}),
\qquad n\to\infty.
$$

这里 $\gamma$ 是欧拉常数。推导及更精确的余项界见[最后的求和法](第09章-渐近式/9.1.6-最后的求和法.md)。因此刷新次数的期望按对数增长。

这个结论只描述刷新操作。采用首元素初始化最大值的常规实现，后续仍需进行 $n-1$ 次大小比较，整个扫描的时间复杂度仍是 $\Theta(n)$。同一段程序，统计的操作不同，得到的数量级就可能不同。

计数约定也会改变答案。如果只统计初始化之后的刷新，期望应为 $H_n-1$。如果输入排列不再等可能，前面使用的 $1/k$ 就需要重新推导。

### 用有限枚举核对

下面的程序枚举小规模下的所有排列，用有理数计算平均值：

```python
from fractions import Fraction
from itertools import permutations
from math import factorial


def record_updates(values):
    maximum = None
    updates = 0
    for value in values:
        if maximum is None or value > maximum:
            maximum = value
            updates += 1
    return updates


assert record_updates(()) == 0
assert record_updates((1, 2, 3, 4)) == 4
assert record_updates((4, 3, 2, 1)) == 1

for n in range(1, 8):
    total = sum(record_updates(p) for p in permutations(range(n)))
    average = Fraction(total, factorial(n))
    harmonic = sum((Fraction(1, k) for k in range(1, n + 1)), Fraction(0))
    assert average == harmonic
    print(n, average)
```

输出中的前四个平均值分别为 $1,3/2,11/6,25/12$。枚举核对了实现与计数约定，一般的 $\mathbb E[R_n]=H_n$ 则由上面的对称性和期望线性性证明。

## 2. 遇到新问题时，怎样找到合适的章节

这个例子没有用上全书所有技巧。实际分析时，可以根据表达式中的困难返回对应章节。

| 遇到的困难 | 可以尝试的方法 | 对应章节 |
| --- | --- | --- |
| 一步操作会产生更小的同类问题 | 定义状态，写递归式和边界条件 | 第一章 |
| 结果表现为一串累计量或多重和式 | 换元、叠缩、交换求和次序、有限微积分 | 第二章 |
| 分组数量、商或下标必须取整数 | 明确底与顶、余数和端点 | 第三章 |
| 约束来自整除或周期 | 互素、同余及数论函数 | 第四章 |
| 和式中出现选择数或阶乘比 | 组合解释、二项式恒等式及超几何方法 | 第五章 |
| 多次遇到相似的数列 | 识别特殊数，使用其递推和恒等式 | 第六章 |
| 递归与卷积难以逐项处理 | 构造生成函数，再提取系数 | 第七章 |
| 答案取决于随机输入或随机过程 | 定义随机变量，分析分布、均值和方差 | 第八章 |
| 精确表达式难以判断规模 | 指定精度，展开主项并控制余项 | 第九章 |

有些问题需要连续使用多种方法。例如，先通过生成函数求出系数，再做渐近估计；先建立随机变量，再把期望化为可求的和式。判断下一步的方法时，当前表达式的结构通常比章节名称更有帮助。

## 3. 再读一遍时，可以检查什么

可以从自己写过的循环或递归中选一个，完整记录下面几个问题的答案：

- 统计的是哪种操作？是否把初始化也算进去？
- 结论适用于哪些输入？随机模型中的概率从哪里来？
- 能否给出精确关系，并说明每次变形的依据？
- 如果使用近似，误差是什么，在哪个范围内成立？

随后用一个小规模实现去核对，主动测试空输入、最小规模和临界值。若结果不一致，就回到模型、边界和求和范围逐项检查。

还可以重做一题熟悉的例子，只改变一个条件。汉诺塔改变初始状态后，原来的递归是否仍然适用？扫描中的元素允许重复后，刷新规则和概率怎样变化？这些改动能检验自己是否理解了公式背后的条件。

对上面的扫描问题，一份完整的分析记录应同时保留：均匀随机排列的假设、首元素计一次的约定、期望 $H_n$ 的证明，以及扫描仍需线性时间的说明。把这些信息放在同一页，下一次使用结论时就有据可查。

# 【具体数学 Concrete Mathematics】1.1.1 汉诺塔问题

> 对应《具体数学：计算机科学基础（第 2 版）》第 1 章 §1.1“河内塔”，书内第 1—4 页。本文沿用专栏的三级编号；“河内塔”和通常所说的“汉诺塔”指同一个问题。

汉诺塔的答案很容易记：$n$ 个圆盘至少需要移动 $2^n-1$ 次。读这一节时，更值得弄清楚的是：递归式从哪里来，以及为什么我们得到的是“最少次数”。

## 1. 先把问题说清楚

有三根柱子 $A,B,C$，$n$ 个大小不同的圆盘起初都放在 $A$ 上，**从上到下越来越大**。目标是将整座塔搬到 $C$，可以借助 $B$，但要遵守两个限制：

- 每次只能移动一根柱子最上面的一个圆盘。
- 大圆盘不能放在小圆盘上。

定义 $T_n$ 为完成任务的最少移动次数。这里的“最少”很重要：某一种算法用了多少步，与所有合法方案至少要用多少步，是两个需要分别回答的问题。

先看小规模：

| 圆盘数 $n$ | $0$ | $1$ | $2$ | $3$ | $4$ |
|---|---:|---:|---:|---:|---:|
| 最少移动次数 $T_n$ | $0$ | $1$ | $3$ | $7$ | $15$ |

把 $n=0$ 纳入定义并不多余。没有圆盘就不需要移动，$T_0=0$ 正好给递归提供统一的终点。

## 2. 盯住最大的圆盘，得到一个可行方案

要把最大的圆盘从 $A$ 搬到 $C$，先得把上面的 $n-1$ 个小圆盘挪开。因此可以分三步：

1. 将 $n-1$ 个小圆盘从 $A$ 搬到 $B$，借助 $C$，需要 $T_{n-1}$ 次。
2. 将最大的圆盘从 $A$ 搬到 $C$，需要 $1$ 次。
3. 将 $n-1$ 个小圆盘从 $B$ 搬到 $C$，借助 $A$，需要 $T_{n-1}$ 次。

在第三步中，$C$ 上的大圆盘不会妨碍小圆盘的移动，它可以看作一个更高的底座。于是我们确实构造出了一个使用 $2T_{n-1}+1$ 次移动的方案。

但此时严格来说，只能写：

$$
T_n\le 2T_{n-1}+1.
$$

这是上界，因为还没有排除更快的方案。

## 3. 为什么任何方案都不可能更快？

考虑任意一个能够完成任务的合法方案，最大的圆盘至少要移动一次。

在它**第一次移动之前**，其余 $n-1$ 个圆盘必须全部堆在第三根柱子上。否则，要么压住最大的圆盘，要么挡住它要去的柱子。仅完成这次小塔转移，就至少需要 $T_{n-1}$ 次移动。

再看最大的圆盘**最后一次移动**。这次它一定移到目标柱 $C$；当时所有小圆盘仍须在另一根柱子上。随后把小塔完整搬到 $C$，还至少需要 $T_{n-1}$ 次。

这两段移动不重叠，中间至少有一次最大圆盘的移动，所以：

$$
T_n\ge T_{n-1}+1+T_{n-1}.
$$

把上下界合起来，才能得到完整的递归式：

$$
\boxed{T_0=0,\qquad T_n=2T_{n-1}+1\quad(n\ge1).}
$$

这里不需要假设最大的圆盘只移动一次。即使某个方案把它来回搬了很多次，下界依然成立。

## 4. 解递归式：为什么两边加 1？

由前几个值可以猜到 $T_n=2^n-1$，但也可以直接通过代数变形得到它：

$$
T_n+1=2T_{n-1}+2=2(T_{n-1}+1).
$$

令 $U_n=T_n+1$，就有：

$$
U_0=1,\qquad U_n=2U_{n-1}.
$$

这是等比数列，因此 $U_n=2^n$，从而：

$$
\boxed{T_n=2^n-1.}
$$

“加 1”可以主动算出来。假设我们希望找到一个常数 $c$，让 $T_n+c=2(T_{n-1}+c)$，比较常数项便得到 $1+c=2c$，所以 $c=1$。

最后用归纳法核对：$n=0$ 时公式给出 $0$；若 $T_{n-1}=2^{n-1}-1$，则

$$
T_n=2(2^{n-1}-1)+1=2^n-1.
$$

因此公式对所有非负整数 $n$ 成立。

## 5. 用 Python 看见递归过程

下面的生成器依次给出移动步骤。返回的三元组是“圆盘编号、起点、终点”，编号越大，圆盘越大。

```python
def hanoi(n: int, source="A", target="C", spare="B"):
    if n < 0:
        raise ValueError("n 必须是非负整数")
    if n == 0:
        return

    yield from hanoi(n - 1, source, spare, target)
    yield n, source, target
    yield from hanoi(n - 1, spare, target, source)


for disk, source, target in hanoi(3):
    print(f"圆盘 {disk}: {source} -> {target}")
```

输出为：

```text
圆盘 1: A -> C
圆盘 2: A -> B
圆盘 1: C -> B
圆盘 3: A -> C
圆盘 1: B -> A
圆盘 2: B -> C
圆盘 1: A -> C
```

三盘恰好需要 $7$ 步，八盘需要 $255$ 步。每增加一个圆盘，总步数几乎翻倍。

这里也要区分两个计算任务：**求步数**可以直接计算 $2^n-1$；**列出全部移动**则必须输出 $2^n-1$ 条记录。在通常把单步操作视为常数时间的分析中，列举的时间复杂度是 $\Theta(2^n)$，递归栈深度是 $O(n)$。若将所有步骤存入列表，列表本身还需要指数规模的空间。大整数的实际运算成本则另算。

## 6. 自测：不看公式再想一遍

**问题一：** 为什么只有“三步递归算法”的说明还不够？

因为它只证明了某个步数足够，还没有证明更少的步数不可能。

**问题二：** 若 $T_n=2T_{n-1}+1$，但没有给出初始值，能唯一确定数列吗？

不能。例如把初始值改成 $T_0=a$，同样变形可得 $T_n=2^n(a+1)-1$。边界条件是递归定义的一部分。

**问题三：** 从 $5$ 个圆盘增加到 $6$ 个，最少步数增加了多少？

从 $31$ 增至 $63$，增加 $32$。一般有 $T_{n+1}-T_n=2^n$。

这一节最值得留下的做法是：先明确所求的量，再分别证明可行方案和不可突破的下界，最后求解递归式。这样得到的公式，才同时回答了“怎么算”和“为什么”。

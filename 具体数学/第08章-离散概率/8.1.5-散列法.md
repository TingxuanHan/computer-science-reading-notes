# 【具体数学 Concrete Mathematics】8.1.5 散列法

> 对应《具体数学：计算机科学基础（第 2 版）》第 8 章 §8.5，书内第 344—357 页。本文沿用专栏三级编号，分析原书使用的链式散列模型。

把 $n$ 个键分散到 $m$ 条链中，平均链长是 $n/m$。这个观察可以解释散列法为什么快，却还回答不了三个问题：成功与失败搜索是否一样快？偏好某些键会怎样？一张表内部的搜索波动，与不同散列表之间的波动是否相同？

## 1. 先固定数据结构和随机模型

本文采用以下约定：

1. 有 $m\ge1$ 个桶，每个桶维护一条链。
2. $n$ 个互异键按编号 $1,\ldots,n$ 插入；冲突时追加到链尾，因此链内保持插入顺序。
3. 各键的散列值 $H_1,\ldots,H_n$ 相互独立，且在 $m$ 个桶上均匀。
4. 成本 $P$ 只统计访问并比较了多少个已有键；计算散列值、读取桶头和判断链尾的固定开销暂不计入。

例如散列值依次为 $0,1,0,2,1$，三条链分别包含键 $[1,3]$、$`[2,5]`$、$`[4]`$。查找键 5 需要比较两个键；到桶 2 查找不存在的键，需要比较一个键。

独立均匀散列是分析假设。一个确定的散列函数是否适合某组输入，需要另外判断；有了这些平均值公式，并不代表每次操作都得到同样的保证。

## 2. 失败搜索：桶长度服从二项分布

设要查找的新键不在表内，其散列值 $H_{n+1}$ 也独立均匀。必须检查目标桶的所有已有键，因此

$$
P_{\mathrm{fail}}=\sum_{i=1}^{n}[H_i=H_{n+1}].
$$

给定目标桶后，各指示变量独立，命中概率均为 $1/m$，且这个条件分布不依赖目标桶是哪一个。因此无条件下也有

```math
P_{\mathrm{fail}}\sim\mathop{\mathrm{Bin}}\nolimits\left(n,\frac1m\right).
```

其概率生成函数、均值和方差分别为

$$
G_{\mathrm{fail}}(z)=\left(1-\frac1m+\frac zm\right)^n,
$$

```math
\boxed{
\mathbb E[P_{\mathrm{fail}}]=\frac nm,\qquad
\mathop{\mathrm{Var}}\nolimits(P_{\mathrm{fail}})
=\frac{n(m-1)}{m^2}.
}
```

失败搜索可能比较零个键：目标桶为空时就会发生。这不表示实际运行时间为零，而是我们的计数没有包括固定开销。

## 3. 成功搜索：先给定搜索的是第几个键

令 $K$ 表示查询键的插入编号。假设它独立于散列值序列，且

$$
\Pr(K=k)=s_k,\qquad
s_k\ge0,\quad \sum_{k=1}^{n}s_k=1.
$$

成功搜索要求 $n\ge1$。给定 $K=k$，第 $k$ 个键前面只有先插入且与它落在同桶的键，所以

```math
P_{\mathrm{succ}}\mid K=k
=1+\sum_{i\lt k}[H_i=H_k]
\sim1+\mathop{\mathrm{Bin}}\nolimits\left(k-1,\frac1m\right).
```

记 $a(z)=1-1/m+z/m$，并以

$$
S(z)=\sum_{k=1}^n s_kz^{k-1}
$$

作为 $K-1$ 的概率生成函数。按条件分布加权，

$$
\boxed{G_{\mathrm{succ}}(z)=zS(a(z)).}
$$

这是混合分布：先抽查询编号，再抽它的链内位置。它通常不是一个固定参数的二项分布。

由条件期望可得

$$
\boxed{
\mathbb E[P_{\mathrm{succ}}]
=1+\frac{\mathbb E[K-1]}m.
}
$$

方差则分成两部分：

```math
\boxed{
\mathop{\mathrm{Var}}\nolimits(P_{\mathrm{succ}})
=\frac{m-1}{m^2}\mathbb E[K-1]
+\frac1{m^2}\mathop{\mathrm{Var}}\nolimits(K-1).
}
```

第一部分是固定查询编号时，由冲突导致的波动；第二部分是查询编号本身不同带来的波动。

## 4. 均匀查询与偏斜查询

如果每个已有键等可能被查询，则 $K-1$ 在 $`\{0,\ldots,n-1\}`$ 上均匀。代入上一节的公式：

$$
\boxed{\mathbb E[P_{\mathrm{succ}}]=1+\frac{n-1}{2m},}
$$

```math
\boxed{
\mathop{\mathrm{Var}}\nolimits(P_{\mathrm{succ}})
=\frac{(n-1)(6m+n-5)}{12m^2}.
}
```

例如 $n=4,m=2$，成功搜索的平均比较次数是 $7/4$，方差是 $11/16$；失败搜索对应均值 2、方差 1。

若早插入的键更常被查询，例如

$$
s_k=\frac1{kH_n},\qquad
H_n=\sum_{k=1}^n\frac1k,
$$

则 $\mathbb E[K]=n/H_n$，于是

$$
\mathbb E[P_{\mathrm{succ}}]
=1+\frac1m\left(\frac n{H_n}-1\right).
$$

早插入的键位于链前面，所以这种访问分布会改变平均成本。若实现采用链头插入，给定第 $k$ 个键的前置冲突数改为来自后插入的键，公式中的 $k-1$ 应换成 $n-k$；只有均匀查询时，整体平均数才保持相同。

## 5. 单次搜索的方差，与平均搜索成本的方差

继续假设均匀查询。先固定一张散列表 $H=(H_1,\ldots,H_n)$，设它的各桶长度为 $N_1,\ldots,N_m$。

一条长度为 $N_j$ 的链，成功搜索各键分别需要 $1,\ldots,N_j$ 次比较。因此这张表的平均成功搜索成本为

$$
A(H)=\mathbb E[P_{\mathrm{succ}}\mid H]
=\frac1n\sum_{j=1}^m\frac{N_j(N_j+1)}2.
$$

利用 $\sum_jN_j=n$，写成

$$
A(H)=1+\frac{B(H)}n,\qquad
B(H)=\sum_{j=1}^m\binom{N_j}{2}.
$$

$B$ 正好是落在同桶的无序键对总数：

```math
B=\sum_{1\le i\lt j\le n}[H_i=H_j].
```

每个碰撞指示变量的均值为 $1/m$、方差为 $(m-1)/m^2$。不同键对的指示变量两两独立：不共享键时直接由独立性得到；共享一个键时，例如

$$
\Pr(H_i=H_j,\ H_i=H_k)=\frac1{m^2},
$$

恰好等于两边各自概率的乘积。

注意这只说明两两独立，并不说明所有碰撞事件相互独立；三个键两两相等的事件之间就有约束。但计算和的方差，两两不相关已经够用。因此

```math
\mathop{\mathrm{Var}}\nolimits(B)=\binom n2\frac{m-1}{m^2},
```

```math
\boxed{\mathop{\mathrm{Var}}\nolimits(A)=
\frac{(n-1)(m-1)}{2nm^2}.}
```

这里的随机性来自重新生成整张表。它和前面的 $`\mathop{\mathrm{Var}}\nolimits(P_{\mathrm{succ}})`$ 是不同的量。

用 $m=1$ 检查最直观：所有键都在唯一一条链上，表的平均成本恒为 $(n+1)/2$，所以 $`\mathop{\mathrm{Var}}\nolimits(A)=0`$；但随机查一个键时，比较次数仍在 $1,\ldots,n$ 上变化。

## 6. 全方差公式把两层随机性接起来

对有限二阶矩的随机变量 $X$，有

```math
\boxed{
\mathop{\mathrm{Var}}\nolimits(X)
=\mathop{\mathrm{Var}}\nolimits(\mathbb E[X\mid Y])
+\mathbb E[\mathop{\mathrm{Var}}\nolimits(X\mid Y)].
}
```

证明可以从

$$
X-\mathbb E[X]
=\bigl(X-\mathbb E[X\mid Y]\bigr)
+\bigl(\mathbb E[X\mid Y]-\mathbb E[X]\bigr)
$$

开始。平方后，交叉项的期望为 0，因为给定 $Y$ 时，第一项的条件期望是 0。

应用到散列表上：

```math
\mathop{\mathrm{Var}}\nolimits(P_{\mathrm{succ}})
=\mathop{\mathrm{Var}}\nolimits(A)
+\mathbb E[\mathop{\mathrm{Var}}\nolimits(P_{\mathrm{succ}}\mid H)].
```

总波动等于“不同表的平均表现差异”加“固定表内，不同查询的表现差异”。报告随机算法性能时，应说明自己测量的是哪一层。

## 7. 比较次数怎样转换成实际成本

原书进一步考虑失败搜索后的插入：空桶与非空桶可能走不同的分支。可用

$$
T=\alpha+\beta P+\delta[P=0]
$$

建模，其中 $P=P_{\mathrm{fail}}$，$`\alpha,\beta,\delta`$ 是固定成本参数。

记 $r=\Pr(P=0)=(1-1/m)^n$，则

$$
\mathbb E[T]=\alpha+\beta\frac nm+\delta r.
$$

由于 $P[P=0]=0$，

```math
\mathop{\mathrm{Cov}}\nolimits(P,[P=0])=-\frac nm r.
```

于是

```math
\boxed{
\mathop{\mathrm{Var}}\nolimits(T)
=\beta^2\frac{n(m-1)}{m^2}
+\delta^2r(1-r)-2\beta\delta\frac nm r.
}
```

这说明不同分支的固定差异也会影响方差，不能永远把“比较次数乘一个常数”当作全部运行时间。空表 $n=0$ 时 $r=1$，整个成本恒为 $\alpha+\delta$；这里将 $0^0$ 按空乘积约定为 1。

## 8. Python：穷举整张表并验证两层方差

```python
from fractions import Fraction as Q
from itertools import product
from math import comb

def average(values):
    return sum(values, Q(0)) / len(values)

def variance(values):
    mean = average(values)
    return average([x * x for x in values]) - mean * mean

for m in range(1, 5):
    for n in range(1, 6):
        all_success, all_failure = [], []
        table_means, table_variances = [], []
        for hashes in product(range(m), repeat=n):
            # 实际建立各桶的链，链内保持插入顺序。
            chains = [[] for _ in range(m)]
            for key, bucket in enumerate(hashes):
                chains[bucket].append(key)
            probes = [
                chains[hashes[key]].index(key) + 1
                for key in range(n)
            ]
            all_success.extend(probes)
            all_failure.extend(len(chain) for chain in chains)
            table_means.append(average(probes))
            table_variances.append(variance(probes))

        assert average(all_failure) == Q(n, m)
        assert variance(all_failure) == Q(n * (m - 1), m * m)
        assert average(all_success) == 1 + Q(n - 1, 2 * m)
        expected_var = Q((n - 1) * (6 * m + n - 5), 12 * m * m)
        assert variance(all_success) == expected_var
        assert variance(table_means) == Q((n - 1) * (m - 1), 2 * n * m * m)
        assert variance(all_success) == (
            variance(table_means) + average(table_variances)
        )
print("链式散列的均值、方差与全方差分解检查通过")
```

程序枚举的是独立均匀模型下的所有散列值分配，使用精确分数计算。它验证小规模实例，正文推导给出一般公式。实际工程里还需要考察散列函数、输入分布、缓存和内存访问等成本，尤其不能把这里的均值当作最坏情况上界。

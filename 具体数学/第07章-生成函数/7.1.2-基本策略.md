# 【具体数学 Concrete Mathematics】7.1.2 基本策略

> 对应《具体数学：计算机科学基础（第 2 版）》第 7 章 §7.2，书内第 277—282 页。本文沿用专栏三级编号。

有了生成函数，接下来要学会把“序列上想做的事”翻译成“级数上能做的事”。移位、乘以下标、取前缀和、筛选奇偶项，都有对应的操作；熟悉这些对应关系，求递归式时就不必每一步都从头猜。

## 1. 形式级数与数值函数分开看

记

$$
G(z)=\sum_{n\ge0}g_nz^n,\qquad g_n=0\quad(n<0).
$$

在形式幂级数中，两个级数相等是指每个次数的系数相等。乘积中 $z^n$ 的系数只涉及 $n+1$ 项，所以不需要先讨论无穷数值和是否收敛。

不过，“形式”并不等于任何操作都允许。在有理数或复数系数下：

- $G(z)$ 有乘法逆元，当且仅当 $g_0\ne0$。
- 对任意形式级数 $F$，若要普遍地定义 $F(G(z))$，通常要求 $G(0)=0$，保证固定次数的系数只收集有限项。若 $F$ 是多项式，则不需要这个限制。
- 微分和积分按系数定义；定积分 $\int_0^z$ 约定常数项为零。

例如 $\sum n!z^n$ 在任何非零数值 $z$ 处都不收敛，但作为形式级数可以合法求导。反过来，形式恒等式 $\sum z^n=1/(1-z)$ 不能用来断言 $1+2+4+\cdots=-1$。

## 2. 一张操作对照表

以下 $m$ 为非负整数，$`F(z)=\sum f_nz^n`$。

| 想得到的序列 | 对应生成函数 |
|---|---|
| $\alpha f_n+\beta g_n$ | $\alpha F(z)+\beta G(z)$ |
| $g_{n-m}$，负下标取零 | $z^mG(z)$ |
| $g_{n+m}$ | $(G(z)-\sum_{j=0}^{m-1}g_jz^j)/z^m$ |
| $c^ng_n$ | $G(cz)$ |
| $(n+1)g_{n+1}$ | $G'(z)$ |
| $ng_n$ | $zG'(z)$ |
| $g_{n-1}/n$，$`n\ge1`$，常数项为零 | $`\int_0^zG(t)\,dt`$ |
| $\sum_{k=0}^nf_kg_{n-k}$ | $F(z)G(z)$ |
| $\sum_{k=0}^ng_k$ | $G(z)/(1-z)$ |

左移时最容易漏掉初始项。比如 $G(z)=1+2z+3z^2+\cdots$，删除第一项得到 $2+3z+\cdots$，应该使用 $(G-1)/z$；直接写 $G/z$ 会多出 $z^{-1}$。

## 3. 乘下标与前缀和可以连续使用

从几何级数出发：

$$
\frac1{1-z}=\sum_{n\ge0}z^n.
$$

施加算子 $\vartheta=z\frac d{dz}$，就把第 $n$ 项乘以 $n$：

$$
\sum_{n\ge0}nz^n=\frac{z}{(1-z)^2},
$$

$$
\sum_{n\ge0}n^2z^n
=\vartheta\frac{z}{(1-z)^2}
=\frac{z(1+z)}{(1-z)^3}.
$$

再除以 $1-z$，得到平方数前缀和的生成函数

$$
\sum_{n\ge0}\left(\sum_{k=0}^nk^2\right)z^n
=\frac{z(1+z)}{(1-z)^4}.
$$

利用 $`[z^n](1-z)^{-r}=\binom{n+r-1}{r-1}`$，便有

$$
\sum_{k=0}^nk^2=\binom{n+2}{3}+\binom{n+1}{3}
=\frac{n(n+1)(2n+1)}6.
$$

逆向操作也有用：$`(1-z)G(z)`$ 的系数为 $g_n-g_{n-1}$。因此乘以 $1-z$ 对应差分，除以 $1-z$ 对应累加。

## 4. 积分产生倒数，累加产生调和数

积分几何级数得到

$$
\int_0^z\frac{dt}{1-t}
=-\log(1-z)=\sum_{n\ge1}\frac{z^n}{n}.
$$

对系数做前缀和，立刻得到

$$
\boxed{\sum_{n\ge0}H_nz^n=\frac{-\log(1-z)}{1-z}},
\qquad H_0=0.
$$

如果想把一般序列的 $g_n$ 改成 $g_n/n$，正确公式是

```math
\sum_{n\ge1}\frac{g_n}{n}z^n
=\int_0^z\frac{G(t)-g_0}{t}\,dt.
```

先减去常数项再除以 $t$，既对齐下标，也避开 $n=0$ 处无意义的除法。

## 5. 奇偶筛选与压缩下标是两步

代入 $-z$ 会让奇数次项变号，所以

$$
\frac{G(z)+G(-z)}2=\sum_{n\ge0}g_{2n}z^{2n},
\qquad
\frac{G(z)-G(-z)}2=\sum_{n\ge0}g_{2n+1}z^{2n+1}.
$$

第一式保留了原位置，生成的是 $g_0,0,g_2,0,g_4,\ldots$。若需要序列 $g_0,g_2,g_4,\ldots$，还要把 $z^{2n}$ 换成新变量的 $w^n$。

以斐波那契数为例，$`F(z)=z/(1-z-z^2)`$，从而

$$
\frac{F(z)+F(-z)}2=\frac{z^2}{1-3z^2+z^4}.
$$

再令 $w=z^2$，得到

$$
\boxed{\sum_{n\ge0}F_{2n}w^n=\frac{w}{1-3w+w^2}.}
$$

偶下标子序列于是满足 $a_n=3a_{n-1}-a_{n-2}$，初始值为 $a_0=0,a_1=1$。这比逐项写出斐波那契数再筛选更能揭示结构。

## 6. 几个值得熟悉的基本形式

| 系数 $a_n$ | 生成函数 |
|---|---|
| $c^n$ | $1/(1-cz)$ |
| $[m\mid n]$，$`m\ge1`$ | $1/(1-z^m)$ |
| $\binom{n+m}{m}$，$`m\ge0`$ | $1/(1-z)^{m+1}$ |
| $\binom{n}{m}$，$`m\ge0`$ | $z^m/(1-z)^{m+1}$ |
| $\binom{\alpha}{n}$ | $(1+z)^\alpha$ |
| $1/n!$ | $e^z$ |

方括号 $[P]$ 表示命题 $P$ 成立时取 1，否则取 0。遇到固定间隔的非零项，应想到 $z^m$；遇到二项式系数，应尝试 $(1\pm z)$ 的幂。

## 7. Python：检查系数，而非代入浮点数

```python
from fractions import Fraction
from math import comb

N = 30
reciprocal = [Fraction(0)] + [Fraction(1, n) for n in range(1, N + 1)]
harmonic = [sum(reciprocal[:n + 1]) for n in range(N + 1)]
for n in range(1, N + 1):
    assert harmonic[n] - harmonic[n - 1] == Fraction(1, n)
    coefficient = comb(n + 2, 3) + (comb(n + 1, 3) if n >= 2 else 0)
    assert coefficient == sum(k * k for k in range(n + 1))

fib = [0, 1]
for _ in range(2 * N):
    fib.append(fib[-1] + fib[-2])
even = [0, 1]
for _ in range(2, N + 1):
    even.append(3 * even[-1] - even[-2])
assert even == fib[:2 * N + 1:2]
print(even[:7])  # [0, 1, 3, 8, 21, 55, 144]
```

程序使用整数与精确分数，检查的是有限次数的系数关系。形式恒等式的一般性来自前面的代数推导。

## 8. 自测

**为什么 $G'(z)$ 不是 $ng_n$ 的生成函数？** 求导后次数下降了一位，要再乘以 $z$。

**筛出偶数项，是否已经得到偶下标子序列的生成函数？** 尚未压缩下标；筛选结果仍以 $z^{2n}$ 计次。

**什么时候需要讨论收敛？** 当把 $z$ 代成具体数值，或利用解析性质研究渐近行为时。

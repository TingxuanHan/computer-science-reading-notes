# 【具体数学 Concrete Mathematics】7.1.1 多米诺理论与换零钱

> 对应《具体数学：计算机科学基础（第 2 版）》第 7 章 §7.1，书内第 268—277 页。本文沿用专栏三级编号。

一串数常常来自一类对象：第 $n$ 项表示大小为 $n$ 的对象有多少个。生成函数把这些计数放在一起，让“如何拼成一个对象”变成一个代数方程。本节用铺多米诺和换零钱来说明这件事。

## 1. 先决定变量记录什么

设 $a_n$ 是大小为 $n$ 的对象个数，定义普通生成函数

$$
A(z)=\sum_{n\ge0}a_nz^n,\qquad [z^n]A(z)=a_n.
$$

指数记录大小，系数记录数量。比如 $3z^4$ 表示大小为 4 的对象有 3 个。

如果一个对象能唯一地拆成左右两部分，大小分别为 $i,j$，那么拼接后的大小为 $i+j$；代数中也恰好有 $z^iz^j=z^{i+j}$。这就是乘法能表达拼接的原因。

这里主要使用形式幂级数：只要每个固定大小的对象数量有限，取一个系数时就只需做有限次计数。我们暂时不把 $z$ 代成具体的实数。

## 2. 铺满 $2\times n$：空铺法也算一种

用 $2\times1$ 的多米诺牌覆盖 $2\times n$ 的矩形，牌可以旋转，不允许重叠。设铺法数为 $T_n$。

最左侧只有两种情况：竖放一张，留下宽度 $n-1$；横放上下两张，留下宽度 $n-2$。因此

$$
T_0=1,\quad T_1=1,\quad T_n=T_{n-1}+T_{n-2}\quad(n\ge2).
$$

$T_0=1$ 表示“什么都不放”这一种完成方式。它保证递归分解在恰好铺完时正确终止。

这篇文章用 $z$ 记录矩形的宽度。一个竖牌块贡献 $z$，一对横牌块贡献 $z^2$，于是

$$
T(z)=1+zT(z)+z^2T(z),
\qquad
\boxed{T(z)=\frac1{1-z-z^2}.}
$$

在 $F_0=0,F_1=1$ 的约定下，$`T_n=F_{n+1}`$，前几项为 $1,1,2,3,5,8,13$。

若还想记录横牌的数量，可用 $u$ 记录“一对横牌”，得到

$$
T(z,u)=\frac1{1-z-uz^2}.
$$

恰有 $j$ 对横牌时，剩下 $n-2j$ 张竖牌，总共有 $n-j$ 个块。选出哪些块是横牌块即可：

$$
\boxed{[z^nu^j]T(z,u)=\binom{n-j}{j}},
\qquad 0\le j\le\lfloor n/2\rfloor.
$$

所以 $F_{n+1}=\sum_j\binom{n-j}{j}$。例如宽度为 6 时，按横牌对数分类，得到 $1+5+6+1=13$。

## 3. 铺满 $3\times n$：补充一个缺角状态

设完整矩形的铺法数为 $U_n$。奇数宽度时，面积为奇数，因此 $U_n=0$；但这个观察还不足以计算偶数宽度。

引入 $V_n$：从 $3\times n$ 矩形中删去一个指定角格后的铺法数，上角与下角由反射给出相同的数量。考察边界上第一组牌，可以得到

$$
U_n=U_{n-2}+2V_{n-1},\qquad
V_n=U_{n-1}+V_{n-2}.
$$

第一式中，三张横牌留下完整矩形；另外两类留下互为镜像的缺角形状。第二式中，填补缺口要么留下一个完整矩形，要么把缺口向内推进两列。

取 $U_0=1,V_0=0$，负下标的项为零；第一式另在 $n=0$ 加上修正项 1。求和后得到

$$
U=1+z^2U+2zV,\qquad V=zU+z^2V.
$$

消去 $V$，便有

$$
\boxed{U(z)=\frac{1-z^2}{1-4z^2+z^4}.}
$$

分子和分母都只含偶次幂，自动保留了面积的奇偶限制。设 $a_m=U_{2m}$，则

$$
a_0=1,\quad a_1=3,\quad a_m=4a_{m-1}-a_{m-2}\quad(m\ge2),
$$

从而 $U_0,U_2,U_4,U_6,U_8=1,3,11,41,153$。

**变量的含义必须固定。** 原书前半节还使用按多米诺牌张数计次的表达式；一个 $3\times2m$ 矩形需要 $3m$ 张牌。按宽度计次与按牌数计次会得到不同的指数，不能直接混用。

## 4. 换零钱：为什么是乘积

假设面额为 $d$ 的硬币可以使用任意多枚，它的选择为

$$
1+z^d+z^{2d}+\cdots=\frac1{1-z^d}.
$$

这里 $z$ 记录金额。不同面额独立选择，因此面额为 $1,5,10,25,50$ 时，总生成函数为

$$
\boxed{C(z)=\frac1{(1-z)(1-z^5)(1-z^{10})(1-z^{25})(1-z^{50})}.}
$$

$[z^{50}]C(z)=50$，表示有 50 种凑出 50 的硬币组合。

不能把它改成 $1/(1-z-z^5-z^{10}-z^{25}-z^{50})$：后者记录的是一枚接一枚放入硬币的**有序序列**，会将“先放 1 再放 5”和“先放 5 再放 1”分开计数。

如果面额 $d$ 最多只能用 $b$ 枚，只需把对应因子改成

$$
1+z^d+\cdots+z^{bd}=\frac{1-z^{(b+1)d}}{1-z^d}.
$$

若用 $u$ 记录硬币总枚数，则无限供应的因子改为 $1/(1-uz^d)$。同一个框架可以同时处理金额、库存和枚数。

## 5. 从乘积直接得到动态规划

令 $W_i(n)$ 表示只用前 $i$ 种面额凑成 $n$ 的方法数。把第 $i$ 个因子的分母乘到左边，有

$$
W_i(n)=W_{i-1}(n)+W_i(n-d_i).
$$

第一项不使用新面额，第二项先取走一枚新面额。两类互不相交，并且覆盖全部组合。

因此一维数组的更新应当是：外层遍历面额，内层让金额从小到大。金额递增允许同一面额重复使用；外层固定面额的加入顺序，避免把同一组合的不同排列重复计算。

如果每个正整数都可作为面额，就得到整数划分函数

$$
\sum_{n\ge0}p(n)z^n=\prod_{d\ge1}\frac1{1-z^d}.
$$

这个无穷乘积在形式意义下仍然有效：计算 $z^N$ 的系数时，面额大于 $N$ 的因子只贡献常数项。例如 $p(5)=7$，而 $p(7)=15$。

## 6. Python：用格子搜索独立检查铺法

下面的铺法程序直接寻找第一个空格并尝试放牌，没有使用斐波那契或 $U_n$ 的递推。

```python
from functools import lru_cache

def tilings(height, width):
    full = (1 << (height * width)) - 1

    @lru_cache(None)
    def fill(mask):
        if mask == full:
            return 1
        i = next(i for i in range(height * width)
                 if not (mask >> i) & 1)
        row, col = divmod(i, width)
        total = 0
        for r, c in [(row + 1, col), (row, col + 1)]:
            if r < height and c < width:
                j = r * width + c
                if not (mask >> j) & 1:
                    total += fill(mask | (1 << i) | (1 << j))
        return total

    return fill(0)

def change(amount, coins):
    ways = [1] + [0] * amount
    for coin in coins:
        for n in range(coin, amount + 1):
            ways[n] += ways[n - coin]
    return ways[amount]

assert [tilings(2, n) for n in range(7)] == [1, 1, 2, 3, 5, 8, 13]
assert [tilings(3, n) for n in range(9)] == [1, 0, 3, 0, 11, 0, 41, 0, 153]
assert change(50, [1, 5, 10, 25, 50]) == 50
assert change(100, [1, 5, 10, 25, 50]) == 292
assert change(5, range(1, 6)) == 7
print("铺法与换零钱检查通过")
```

这些检查可以发现边界或下标错误；任意规模成立的依据仍是前面的唯一分解与系数比较。

## 7. 自测

**为什么零金额有一种凑法？** 因为所有面额都选零枚，对应乘积中的常数项 1。

**为什么铺法用序列，而换零钱按面额相乘？** 铺牌块的位置顺序会改变铺法；同面额硬币的排列顺序不改变组合。

**增加一个变量有什么用？** 它让我们在不丢失原有大小信息的同时，记录横牌对数、硬币枚数等第二个统计量。

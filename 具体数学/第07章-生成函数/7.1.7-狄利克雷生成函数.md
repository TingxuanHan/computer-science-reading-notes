# 【具体数学 Concrete Mathematics】7.1.7 狄利克雷生成函数

> 对应《具体数学：计算机科学基础（第 2 版）》第 7 章 §7.7，书内第 310—312 页。本文沿用专栏三级编号，使用 $s$ 表示狄利克雷级数的变量。

普通生成函数的乘法对应 $i+j=n$，适合把大小相加的组合问题。如果问题中的基本操作是整数相乘，或者不断对约数求和，就需要另一种核函数。狄利克雷生成函数把加法结构换成了乘法结构，也把本章重新连接到第四章的数论。

## 1. 从 $z^n$ 换成 $n^{-s}$

对从 $n=1$ 开始的数列 $a_1,a_2,\ldots$，定义

$$
\mathcal D_a(s)=\sum_{n\ge1}\frac{a_n}{n^s}.
$$

这里没有 $n=0$ 项。常数数列 $a_n=1$ 给出黎曼 ζ 函数

$$
\zeta(s)=\sum_{n\ge1}\frac1{n^s}.
$$

作为通常的数值级数，这个表达式在 $\operatorname{Re}s>1$ 时绝对收敛。ζ 函数可以作解析延拓，但延拓后的数值不能直接当作原级数在收敛区间之外的普通求和结果。

做算术函数的系数运算时，也可以把狄利克雷级数形式地理解为系数序列。固定整数 $n$ 只有有限多个约数，所以后面的卷积本身不依赖无限数值和的收敛。

## 2. 乘法对应“约数卷积”

注意核函数满足

$$
\frac1{i^s}\frac1{j^s}=\frac1{(ij)^s}.
$$

因此将两个级数相乘，把所有满足 $ij=n$ 的项收集在一起，有

$$
\mathcal D_a(s)\mathcal D_b(s)
=\sum_{n\ge1}\frac1{n^s}\sum_{d\mid n}a_db_{n/d}.
$$

定义狄利克雷卷积

$$
\boxed{(a*b)(n)=\sum_{d\mid n}a(d)b(n/d).}
$$

如果把级数视为数值函数，上述乘法与换序可在两者都绝对收敛的半平面内使用。

例如令 $\mathbf1(n)=1$，则

$$
(\mathbf1*\mathbf1)(n)=\sum_{d\mid n}1=\tau(n),
$$

其中 $\tau(n)$ 是正约数个数，所以

$$
\sum_{n\ge1}\frac{\tau(n)}{n^s}=\zeta(s)^2
\qquad(\operatorname{Re}s>1).
$$

$n=12$ 的约数是 $1,2,3,4,6,12$，故其系数为 6。

## 3. 卷积的单位元与默比乌斯反演

普通卷积的单位元位于下标 0；狄利克雷卷积的单位元位于下标 1：

$$
\varepsilon(n)=[n=1],\qquad a*\varepsilon=a.
$$

默比乌斯函数 $\mu$ 满足

$$
\sum_{d\mid n}\mu(d)=\varepsilon(n),
\qquad \mu*\mathbf1=\varepsilon.
$$

所以

$$
\boxed{\sum_{n\ge1}\frac{\mu(n)}{n^s}=\frac1{\zeta(s)}}
\qquad(\operatorname{Re}s>1).
$$

例如 $\mu(1)=1,\mu(2)=\mu(3)=-1,\mu(6)=1$，它们相加为零，符合 $n=6$ 的约数和。

如果 $g(n)=\sum_{d\mid n}f(d)$，也就是 $g=\mathbf1*f$，两边再与 $\mu$ 卷积，就有

$$
\boxed{f(n)=\sum_{d\mid n}\mu(d)g(n/d).}
$$

这就是默比乌斯反演。它并不是一条孤立技巧，而是“对约数累加”的逆运算。

更一般地，算术函数 $a$ 在数值系数域中有卷积逆元，当且仅当 $a(1)\ne0$。逆元 $b$ 可逐项求出：

$$
b(1)=\frac1{a(1)},\qquad
b(n)=-\frac1{a(1)}\sum_{\substack{d\mid n\\d>1}}a(d)b(n/d).
$$

求 $b(n)$ 时右侧只涉及更小的下标。

## 4. 积性函数为什么能分解成素数乘积

积性函数要求 $a(1)=1$，且仅在 $\gcd(m,n)=1$ 时要求 $a(mn)=a(m)a(n)$。这弱于对所有 $m,n$ 都成立的“完全积性”。

每个正整数唯一分解为素数幂的乘积，因此

$$
\boxed{\mathcal D_a(s)=\prod_p
\left(1+\frac{a(p)}{p^s}+\frac{a(p^2)}{p^{2s}}+\cdots\right).}
$$

乘积遍历全部素数。形式解释是：为每个素数选择一个指数，唯一确定一个整数；数值解释则在相应绝对收敛区域内成立。

对 $\mathbf1$，每个局部因子都是几何级数，所以

$$
\zeta(s)=\prod_p\frac1{1-p^{-s}}.
$$

对 $\mu$，有 $\mu(p)=-1$，$\mu(p^k)=0$（$k\ge2$），故

$$
\sum_{n\ge1}\frac{\mu(n)}{n^s}=\prod_p(1-p^{-s}).
$$

并非所有积性函数的局部因子都能写成 $1/(1-a(p)p^{-s})$。该简化需要 $a(p^k)=a(p)^k$，即素数幂上也满足完全积性；$\mu$ 就不满足。

## 5. 欧拉函数的级数：两种推导相互印证

欧拉函数在素数幂上的值为 $\varphi(p^k)=p^k-p^{k-1}$。于是

$$
1+\sum_{k\ge1}\frac{\varphi(p^k)}{p^{ks}}
=\frac{1-p^{-s}}{1-p^{1-s}}.
$$

逐个素数相乘得到

$$
\boxed{\sum_{n\ge1}\frac{\varphi(n)}{n^s}
=\frac{\zeta(s-1)}{\zeta(s)}}
\qquad(\operatorname{Re}s>2).
$$

这里绝对收敛的充分条件变成 $\operatorname{Re}s>2$，不能照搬 $\zeta(s)$ 的条件。

也可以从第四章的恒等式 $\sum_{d\mid n}\varphi(d)=n$ 出发。令 $\operatorname{id}(n)=n$，则

$$
\mathbf1*\varphi=\operatorname{id},\qquad
\varphi=\mu*\operatorname{id}.
$$

由于 $\operatorname{id}$ 的狄利克雷级数为 $\zeta(s-1)$，相除便得到同一个结果。前一种方法沿素数分解，后一种方法沿约数卷积。

## 6. Python：用直接计数检查约数恒等式

```python
from math import gcd

def divisors(n):
    return [d for d in range(1, n + 1) if n % d == 0]

def mobius(n):
    sign, p = 1, 2
    while p * p <= n:
        if n % p == 0:
            n //= p
            sign = -sign
            if n % p == 0:
                return 0
        p += 1
    return -sign if n > 1 else sign

def phi_direct(n):
    return sum(gcd(k, n) == 1 for k in range(1, n + 1))

for n in range(1, 201):
    ds = divisors(n)
    assert sum(mobius(d) for d in ds) == (n == 1)
    assert sum(phi_direct(d) for d in ds) == n
    assert sum(mobius(d) * (n // d) for d in ds) == phi_direct(n)

    # 任取 f(n)=n^2；先约数累加，再用 mu 还原。
    recovered = sum(mobius(d) * sum(k * k for k in divisors(n // d))
                    for d in ds)
    assert recovered == n * n

print(divisors(12), phi_direct(12), mobius(12))  # 约数列表，4，0
```

程序核对的是有限范围的精确整数恒等式，没有用截断的 ζ 数值近似去代替卷积等式。无限级数及欧拉乘积的数值使用范围仍由收敛条件决定。

## 7. 三种生成函数怎样选

| 递归或计数中的结构 | 适合的生成函数 | 乘法对应的系数 |
|---|---|---|
| 大小相加 | 普通生成函数 | $\sum_{k=0}^na_kb_{n-k}$ |
| 不同标签分给两个部件 | 指数生成函数 | $\sum_{k=0}^n\binom nka_kb_{n-k}$ |
| 整数相乘、约数分解 | 狄利克雷生成函数 | $\sum_{d\mid n}a(d)b(n/d)$ |

选择生成函数时，先观察问题里“组合两个部分”遵循什么规则。核函数选对了，原本复杂的卷积往往就变成普通乘法。

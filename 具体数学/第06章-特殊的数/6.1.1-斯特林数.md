# 【具体数学 Concrete Mathematics】6.1.1 斯特林数

> 对应《具体数学：计算机科学基础（第 2 版）》第 6 章 §6.1，书内第 214—223 页。本文沿用专栏三级编号，先讨论非负整数指标下的斯特林数。

把四个人分成两组，与把四个人安排在两张圆桌旁，是两种计数问题。前者只关心谁与谁同组；后者还要记录每桌的环形次序。两类斯特林数的区别，就从这里开始。

## 1. 子集与轮换：先分清数的是什么

第二类斯特林数记为

$$
S(n,k)=\left\{\begin{matrix}n\\k\end{matrix}\right\},
$$

表示将 $n$ 个不同元素划分成 $k$ 个**无标号、非空子集**的方法数。组内没有顺序，组与组之间也没有顺序。

例如 $S(4,2)=7$。按两组的大小分类：大小为 $3+1$ 时有 4 种；大小为 $2+2$ 时有 $\binom42/2=3$ 种，所以一共 7 种。

第一类斯特林数在本文采用无符号约定：

$$
c(n,k)=\left[\begin{matrix}n\\k\end{matrix}\right],
$$

它表示 $n$ 个元素的排列中，恰有 $k$ 个不相交轮换的排列数。轮换 $(1\,2\,3)$ 与 $(2\,3\,1)$ 相同，却与 $(1\,3\,2)$ 不同。轮换之间的书写次序不影响排列。

同样取 $n=4,k=2$：大小为 $3+1$ 时，选出单元素轮换有 4 种，另三个元素组成轮换有 $(3-1)!=2$ 种；大小为 $2+2$ 时仍有 3 种。因此

$$
c(4,2)=4\times2+3=11.
$$

这里不能把每个分组都统一乘一个相同的阶乘：不同组的大小会改变可安排的轮换数。

## 2. 递推式：只观察最后加入的元素

对第二类斯特林数，元素 $n$ 有两种去处：单独成组，或者加入已有的某一组。因此

$$
\boxed{S(n,k)=S(n-1,k-1)+kS(n-1,k).}
$$

对第一类斯特林数，元素 $n$ 也可以自成一个轮换。若不自成轮换，就把它插在已有 $n-1$ 个元素中的某一个后面。无论这些元素分布在几个轮换里，插入位置总共有 $n-1$ 个，所以

$$
\boxed{c(n,k)=c(n-1,k-1)+(n-1)c(n-1,k).}
$$

两个递推式的差别很具体：一个在选“已有的组”，一个在选“已有的元素后面”。

共同的边界条件是

$$
S(0,0)=c(0,0)=1,
$$

当 $n>0$ 时，$S(n,0)=c(n,0)=0$；当 $k<0$ 或 $k>n\ge0$ 时也定义为 0。空集合分成零组有一种方式，这个约定让递推从第一行就能成立。

| $n$ | $S(n,k)$，从 $k=0$ 开始 | $c(n,k)$，从 $k=0$ 开始 |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 0, 1 | 0, 1 |
| 2 | 0, 1, 1 | 0, 1, 1 |
| 3 | 0, 1, 3, 1 | 0, 2, 3, 1 |
| 4 | 0, 1, 7, 6, 1 | 0, 6, 11, 6, 1 |

对 $n\ge1$，还有 $S(n,1)=1$、$c(n,1)=(n-1)!$；对 $n\ge2$，两类数的倒数第二个非零值都是 $\binom n2$。

## 3. 为什么它们会出现在幂的变换中

记下降幂和上升幂为

$$
x^{\underline{k}}=x(x-1)\cdots(x-k+1),\qquad
x^{\overline{k}}=x(x+1)\cdots(x+k-1),
$$

空乘积都为 1。斯特林数给出三种多项式基底之间的转换：

$$
\boxed{x^n=\sum_{k=0}^n S(n,k)x^{\underline{k}},}
$$

$$
\boxed{x^{\overline n}=\sum_{k=0}^n c(n,k)x^k,\qquad
x^{\underline n}=\sum_{k=0}^n(-1)^{n-k}c(n,k)x^k.}
$$

第一个等式可以直接计数。设 $x$ 为正整数，把 $n$ 个不同对象映射到 $x$ 个有标号位置，共有 $x^n$ 个函数。若恰好用了 $k$ 个位置，先按相同函数值分成 $k$ 个非空块，再给这些块分配互不相同的位置，有

$$
S(n,k)\binom{x}{k}k!=S(n,k)x^{\underline{k}}
$$

种。对 $k$ 求和即得结果。两边都是多项式，因此也对任意实数或复数 $x$ 成立。

第二个等式可用归纳法证明：乘上新因子 $x+n-1$，系数恰好满足 $c(n,k)$ 的递推。把 $x$ 换成 $-x$，再整理符号，就得到下降幂的展开。

例如

$$
x^4=x^{\underline4}+6x^{\underline3}+7x^{\underline2}+x,
$$

$$
x^{\underline4}=x^4-6x^3+11x^2-6x.
$$

若其他资料使用带符号的第一类斯特林数 $s(n,k)$，它与本文的关系为 $s(n,k)=(-1)^{n-k}c(n,k)$。

## 4. 两次变换还原原式：斯特林反演

把下降幂的展开代入 $x^n$ 的展开，再比较 $x^m$ 的系数，得到

$$
\boxed{\sum_{k=m}^n S(n,k)(-1)^{k-m}c(k,m)=[n=m].}
$$

方括号表示条件成立时为 1，否则为 0。于是，若

$$
b_n=\sum_{k=0}^nS(n,k)a_k,
$$

则反向关系为

$$
a_n=\sum_{k=0}^n(-1)^{n-k}c(n,k)b_k.
$$

这与二项式反演很相似：转换矩阵的逆矩阵仍由熟悉的计数系数构成，只是需要交错符号。符号不能凭印象补上，应当跟随“从哪种基底换到哪种基底”来判断。

## 5. 有标号的盒子：容斥给出显式和式

把 $n$ 个不同对象放进 $k$ 个有标号的盒子，要求每盒非空，方法数为 $k!S(n,k)$。用容斥排除空盒，对 $n,k\ge0$ 有

$$
\boxed{k!S(n,k)=\sum_{j=0}^k(-1)^{k-j}\binom kj j^n.}
$$

这里为组合计数约定 $0^0=1$，因此空集合的边界也包含在内。例如

$$
3!S(5,3)=3^5-3\cdot2^5+3\cdot1^5=150,
$$

所以 $S(5,3)=25$。如果盒子没有标号，必须除以 $3!$；如果允许盒子为空，就直接是 $3^5$。这些条件比公式名称更重要。

## 6. Python：用枚举交叉检查递推

下面分别枚举满射和排列的轮换数。预期答案来自对象本身，而不是再运行一遍相同的递推。

```python
from functools import lru_cache
from itertools import permutations, product
from math import factorial

@lru_cache(None)
def S(n, k):
    if n == 0:
        return int(k == 0)
    if k <= 0 or k > n:
        return 0
    return S(n - 1, k - 1) + k * S(n - 1, k)

@lru_cache(None)
def c(n, k):
    if n == 0:
        return int(k == 0)
    if k <= 0 or k > n:
        return 0
    return c(n - 1, k - 1) + (n - 1) * c(n - 1, k)

def cycle_count(p):
    seen = set()
    count = 0
    for start in range(len(p)):
        if start not in seen:
            count += 1
            v = start
            while v not in seen:
                seen.add(v)
                v = p[v]
    return count

for n in range(7):
    counts = [0] * (n + 1)
    for p in permutations(range(n)):
        counts[cycle_count(p)] += 1
    assert counts == [c(n, k) for k in range(n + 1)]
    for k in range(n + 1):
        onto = sum(len(set(f)) == k
                   for f in product(range(k), repeat=n))
        assert onto == factorial(k) * S(n, k)

assert S(4, 2) == 7 and c(4, 2) == 11
print("两类斯特林数的独立枚举检查通过")
```

枚举只适合小规模验证。实际需要整张三角形时，用递推填表只需 $O(N^2)$ 次算术操作；若只保留上一行，额外空间为 $O(N)$，这里未计入大整数的位运算成本。

## 7. 读完应当能区分的三件事

子集数记录分组，轮换数记录排列的循环结构；给组加标号会多出一个 $k!$；下降幂展开使用带符号系数，而本文的 $c(n,k)$ 本身始终非负。

原书最后还把两类数延伸到负整数指标，并讨论它们的对偶关系。那是保持递推式的代数延拓，已超出上述集合计数含义，不能继续把负指标解释为“负数个元素”。

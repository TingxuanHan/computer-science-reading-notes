# 【具体数学 Concrete Mathematics】6.1.7 连项式

> 对应《具体数学：计算机科学基础（第 2 版）》第 6 章 §6.7，书内第 252—259 页正文部分。本文沿用专栏三级编号。

连分数层层嵌套，看起来不便直接计算。把它们的分子、分母分别展开，会反复出现同一种多项式：连项式（continuant）。它推广了斐波那契递推，也能记录欧几里得算法产生的商。

## 1. 从斐波那契递推增加一个系数

定义

$$
K()=1,\qquad K(x_1)=x_1,
$$

对 $n\ge2$，

$$
\boxed{K(x_1,\ldots,x_n)
=x_nK(x_1,\ldots,x_{n-1})+K(x_1,\ldots,x_{n-2}).}
$$

前几个展开式为

$$
K(x_1,x_2)=x_1x_2+1,
$$

$$
K(x_1,x_2,x_3)=x_1x_2x_3+x_1+x_3,
$$

$$
K(x_1,x_2,x_3,x_4)
=x_1x_2x_3x_4+x_1x_2+x_1x_4+x_3x_4+1.
$$

当所有变量都取 1，递推变成斐波那契递推，但初始值为 1、1，所以

$$
\boxed{K(\underbrace{1,\ldots,1}_{n\text{ 个}})=F_{n+1}.}
$$

空列表的值是 1，不是 0。这个边界会影响后面连分数分母的计算。

## 2. 用长度为 1 和 2 的砖解释每一项

把位置 $1,\ldots,n$ 铺成一个条带。单格砖覆盖位置 $i$ 时赋权 $x_i$；双格砖覆盖相邻两格时赋权 1。一个铺法的权重是其中所有单格权重的乘积。

按最后一块砖分类：最后是单格砖，就产生 $x_nK(x_1,\ldots,x_{n-1})$；最后是双格砖，就产生 $K(x_1,\ldots,x_{n-2})$。所以所有铺法的权重之和恰好是连项式。

例如覆盖四格的五种铺法，对应以下五项：

| 砖块长度序列 | 权重 |
|---|---|
| 1, 1, 1, 1 | $x_1x_2x_3x_4$ |
| 1, 1, 2 | $x_1x_2$ |
| 1, 2, 1 | $x_1x_4$ |
| 2, 1, 1 | $x_3x_4$ |
| 2, 2 | 1 |

如果所有变量取 $z$，含 $j$ 块双格砖的铺法有 $n-2j$ 块单格砖，总砖数为 $n-j$，于是

$$
\boxed{K(\underbrace{z,\ldots,z}_{n\text{ 个}})
=\sum_{j=0}^{\lfloor n/2\rfloor}\binom{n-j}{j}z^{n-2j}.}
$$

取 $z=1$，就得到 $F_{n+1}=\sum_j\binom{n-j}{j}$。

## 3. 反转和分割都可以从铺法看出来

把整个条带左右翻转，铺法一一对应，权重只是把变量顺序反过来。因此

$$
\boxed{K(x_1,\ldots,x_n)=K(x_n,\ldots,x_1).}
$$

所以连项式既可以从右端递推，也可以从左端递推。

再把长度为 $m+n$ 的条带在第 $m$ 格与第 $m+1$ 格之间切开，其中 $m,n\ge1$。铺法分为两类：没有双格砖跨过切口，或者恰有一块双格砖跨过切口。于是

$$
\begin{aligned}
K(x_1,\ldots,x_{m+n})
={}&K(x_1,\ldots,x_m)K(x_{m+1},\ldots,x_{m+n})\\
&+K(x_1,\ldots,x_{m-1})K(x_{m+2},\ldots,x_{m+n}).
\end{aligned}
$$

边界处出现空列表时使用 $K()=1$。将所有变量取 1，就得到斐波那契加法恒等式

$$
F_{m+n+1}=F_{m+1}F_{n+1}+F_mF_n.
$$

## 4. 矩阵给出广义卡西尼恒等式

令

```math
M(x)=\begin{pmatrix}x&1\\1&0\end{pmatrix}.
```

对于 $n\ge2$，直接归纳可得

$$
\prod_{i=1}^nM(x_i)=
\begin{pmatrix}
K(x_1,\ldots,x_n)&K(x_1,\ldots,x_{n-1})\\
K(x_2,\ldots,x_n)&K(x_2,\ldots,x_{n-1})
\end{pmatrix},
$$

乘积按从左到右的顺序排列。每个因子的行列式都是 $-1$，所以

$$
\begin{aligned}
&K(x_1,\ldots,x_n)K(x_2,\ldots,x_{n-1})\\
&\quad-K(x_1,\ldots,x_{n-1})K(x_2,\ldots,x_n)
=(-1)^n.
\end{aligned}
$$

取所有 $x_i=1$，就回到 $F_{n+1}F_{n-1}-F_n^2=(-1)^n$。矩阵把递推中的多个相邻量保存在一起，因此很适合寻找这种乘积差恒等式。

## 5. 连分数的分子、分母就是连项式

对整数 $a_0$ 和正整数 $a_1,\ldots,a_r$，记有限简单连分数为

$$
[a_0;a_1,\ldots,a_r]
=a_0+\cfrac1{a_1+\cfrac1{a_2+\cdots+\cfrac1{a_r}}}.
$$

它满足

$$
\boxed{[a_0;a_1,\ldots,a_r]
=\frac{K(a_0,a_1,\ldots,a_r)}{K(a_1,\ldots,a_r)}.}
$$

可以从最内层向外归纳，也可以使用上一节的矩阵乘积证明。

例如 $[2;3,1,4]$：

$$
K(2)=2,\quad K(2,3)=7,\quad
K(2,3,1)=9,\quad K(2,3,1,4)=43,
$$

而 $K(3,1,4)=19$，所以结果为 $43/19$。

若记第 $i$ 个渐近分数为 $p_i/q_i=[a_0;\ldots,a_i]$，则

$$
p_i=a_ip_{i-1}+p_{i-2},\qquad
q_i=a_iq_{i-1}+q_{i-2},
$$

初始值可统一设为

$$
p_{-2}=0,\ p_{-1}=1,\qquad q_{-2}=1,\ q_{-1}=0.
$$

相邻分数满足

$$
\boxed{p_iq_{i-1}-p_{i-1}q_i=(-1)^{i+1}\qquad(i\ge1).}
$$

所以每个 $p_i,q_i$ 都互素，相邻两个近似值的差的绝对值为 $1/(q_iq_{i-1})$。

## 6. 欧几里得算法如何把分数拆成部分商

对 $43/19$ 执行带余除法：

$$
43=2\cdot19+5,\quad
19=3\cdot5+4,\quad
5=1\cdot4+1,\quad
4=4\cdot1.
$$

商序列正是 $2,3,1,4$。逐步写成“整数部分加倒数”，便恢复 $[2;3,1,4]$。

更一般地，若正整数 $m>n$ 的欧几里得算法得到商 $q_1,\ldots,q_s$ 和最大公因子 $d$，从最后一步反向代入便有

$$
m=dK(q_1,\ldots,q_s),\qquad
n=dK(q_2,\ldots,q_s).
$$

商全尽可能小时，这个反向递推接近斐波那契递推。因而相邻斐波那契数会出现在欧几里得算法需要很多步的输入中；实际终止步骤的最后一个商至少为 2，需要一起计入边界。

有限连分数有尾项等价关系 $[\ldots,a]=[\ldots,a-1,1]$（$`a\ge2`$）。若需要唯一的标准形式，通常要求非整数连分数的最后一个部分商至少为 2。

## 7. 从有理数走向无限连分数

正无理数可以不断“取整数部分，再对小数部分取倒数”，得到无限的部分商序列。它的有限截断仍按同一套 $p_i,q_i$ 递推计算。

例如 $\varphi=1+1/\varphi$，所以

$$
\varphi=[1;1,1,\ldots],
$$

有限截断为 $1,2,3/2,5/3,8/5,\ldots$，恰是相邻斐波那契数的比值。

若 $\alpha=[a_0;a_1,\ldots]$ 为无理数，令 $t=[a_{i+1};a_{i+2},\ldots]>a_{i+1}$，则

$$
\alpha=\frac{p_it+p_{i-1}}{q_it+q_{i-1}}.
$$

利用相邻分数的行列式关系，对 $i\ge1$ 得到

$$
\left|\alpha-\frac{p_i}{q_i}\right|
=\frac1{q_i(q_it+q_{i-1})}
<\frac1{q_iq_{i+1}}.
$$

误差控制来自结构，并不只是观察小数位越来越接近。

原书还联系了 Stern–Brocot 树的左右路径，并以一个涉及 $\lfloor n\varphi\rfloor$、斐波那契数和无限连分数的生成函数恒等式收尾。理解那些进阶推导的起点，正是本篇的铺法解释、矩阵行列式和连分数分子分母递推。

## 8. Python：三种不同计算相互核对

```python
from fractions import Fraction
from itertools import product

def K(xs):
    previous, current = 0, 1
    for x in xs:
        previous, current = current, x * current + previous
    return current

def tiling_weight(xs):
    if not xs:
        return 1
    if len(xs) == 1:
        return xs[0]
    # 从左端枚举首块砖，与 K 的右端递推方向不同。
    return xs[0] * tiling_weight(xs[1:]) + tiling_weight(xs[2:])

def cf_nested(xs):
    value = Fraction(xs[-1])
    for a in reversed(xs[:-1]):
        value = a + 1 / value
    return value

def partial_quotients(m, n):
    answer = []
    while n:
        q, r = divmod(m, n)
        answer.append(q)
        m, n = n, r
    return answer

for length in range(7):
    for xs in product((-1, 0, 2), repeat=length):
        assert K(xs) == K(xs[::-1]) == tiling_weight(xs)
        if length >= 2:
            assert K(xs) * K(xs[1:-1]) - K(xs[:-1]) * K(xs[1:]) == (-1)**length

for m in range(1, 51):
    for n in range(1, 51):
        qs = partial_quotients(m, n)
        assert Fraction(K(qs), K(qs[1:])) == Fraction(m, n)
        assert cf_nested(qs) == Fraction(m, n)

assert partial_quotients(43, 19) == [2, 3, 1, 4]
assert K([2, 3, 1, 4]) == 43 and K([3, 1, 4]) == 19
print("连项式、行列式与连分数检查通过")
```

多项式恒等式允许变量取零或负数，所以前一组检查包含这些情况；连分数求值则要求嵌套分母非零，后一组检查使用正有理数的标准部分商。两组输入条件不能混在一起。

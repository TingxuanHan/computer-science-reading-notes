## 编号与阅读方法

文件名保留 CSDN 专栏的三级编号，例如 `4.1.6` 对应原书 §4.6。各篇开头注明原书节号与书内页码，章节目录也列出对应关系。

建议对照原书阅读推导，再运行文中的 Python 示例并完成自测。验证脚本使用有限枚举、精确有理数或高精度计算核对示例和部分恒等式；一般性证明、极限与收敛条件仍以推导为依据。

## 程序验证

在仓库根目录运行：

```sh
python 具体数学/verification/verify_all.py
```

使用 Python 3.10 或更新版本，依赖均为标准库。详细范围与生成的报告见[验证目录](verification/README.md)。
